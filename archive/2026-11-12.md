**🅰️ Claude 产品更新详解**

**Claude Fable 5.2 与 Claude Mythos 5.2**
- 功能介绍: Anthropic 正式发布 **Claude Fable 5.2** 与 **Claude Mythos 5.2** 两款新模型,其中 Fable 5.2 成为 Claude Code 的默认 Fable 模型,支持 1M 上下文。
- 效果: 面向创意写作、叙事生成与长文本理解场景;Fable 5.2 在 Claude Code 中作为默认模型后,开发者可直接获得更强的代码理解与长项目分析能力。定价 $8/$40 per Mtok,cache reads $0.20/Mtok。
- 使用限制: Claude Code 默认模型(需更新至 v2.1.321+);API 可用;具体档位与平台以 Anthropic 官方说明为准(推测)。
[原文](https://www.anthropic.com/claude-fable-and-mythos-5-2)

**Claude Code v2.1.322 — Vertex fast mode**
- 功能介绍: 在 Vertex 的 global、us、eu 区域新增 fast mode,若 Vertex 拒绝则回退到 standard speed。
- 效果: 使用 Vertex 通道的开发者可获得更快的响应速度,同时保留自动降级机制避免请求失败。
- 使用限制: Claude Code + Vertex 通道;区域限 global / us / eu。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)

**Claude Code v2.1.321 — Fable 5.2 默认 + remote-control settings**
- 功能介绍: 将 **Claude Fable 5.2**(claude-fable-5-2)设为默认 Fable 模型;为 **claude remote-control** 新增 **--settings ** 参数,可对每个启动的 session 应用指定 settings 文件;修复 MCP OAuth 请求在服务器重定向时把 refresh token 等 secrets 发给其他 host 的问题。
- 效果: 开发者无需手动指定模型即可使用 Fable 5.2;remote-control 的 settings 文件变更后需重启才生效,便于批量管理 session;OAuth 修复提升了 MCP 集成的安全性。
- 使用限制: Claude Code v2.1.321+;remote-control 功能;MCP OAuth 场景。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)

**Claude Code v2.1.319 — auto mode 行为调整**
- 功能介绍: 当 telemetry 或 feature flags 关闭(包括位于 LLM gateway 之后)时,auto mode 对服务器无法检查的调用改为询问或拒绝,不再回退到内置 classifier;设置 **CLAUDE_CODE_AUTO_MODE_SERVER=0** 可继续使用内置 classifier(Bedrock、Vertex、Foundry 不变);LLM gateway 后设置 **CLAUDE_CODE_AUTO_MODE_SERVER=1** 可强制开启服务器端检查。
- 效果: 提升 auto mode 在受限环境下的安全性与可控性,避免静默回退导致的行为不一致。
- 使用限制: Claude Code v2.1.319+;涉及 Bedrock / Vertex / Foundry / LLM gateway 环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)

**Claude Code v2.1.318 — mods 记录、assume_role、effort 选项**
- 功能介绍: 新增 session 中 Claude Code 请求开启其写入的 mods 时的回答记录;在 Claude apps gateway 的 mantle upstreams 上新增 **assume_role**,支持跨 AWS 账户角色与按开发者 AWS 成本归因;为 mod 的 **$.model.fork** 新增 **effort** 选项,允许快速 side job 以低 effort 运行;在 **claude auth status** 中新增 claude.ai 登录到期日期。
- 效果: 增强审计可追溯性、多云成本管理与 mod 子任务的资源控制,开发者可更精细地管理 session 与成本。
- 使用限制: Claude Code v2.1.318+;涉及 AWS 多账户、mod fork 场景。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)
