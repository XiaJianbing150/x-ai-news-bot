**🅰️ Claude 产品更新详解**

**Claude Code v2.1.305**
- 功能介绍: 新增 **sandbox.allowNestedUserNamespaces**,允许 Linux 上被沙箱化的命令创建用户命名空间(如 Chromium、rootless podman),从而绕过沙箱的文件保护;新增 **CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS**,让无人值守重试模式能在用量限制解除后及时感知,而不是等到重置周期结束。
- 效果: 解决沙箱环境跑浏览器/容器类工具时被文件保护卡住的问题;让长时间无人值守的 agent 任务在限额恢复后更快继续,减少空等。
- 使用限制: Claude Code CLI,所有档位可用;环境变量需自行配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.305)

**Claude Code v2.1.304**
- 功能介绍: 为 mod 系统新增多项能力:插件跳过 hook 时输出 transcript 行并注明事件与插件名;tool.check 新增 **decider: "person"** 选项(只有权限对话框或 host 回调能批准);tool.check 事件新增 **e.isReadOnly**;新增 **/auto-mode-setup** 引导式设置,读取项目后推荐配置。
- 效果: mod 开发者能更精细地控制权限审批流、识别只读工具调用;普通用户可用引导式命令快速完成 auto mode 配置。
- 使用限制: Claude Code CLI;mod 相关功能面向插件/扩展开发者。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.304)

**Claude Code v2.1.299**
