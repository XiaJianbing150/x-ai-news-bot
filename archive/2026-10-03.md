**🅰️ Claude 产品更新详解**

**Claude Code v2.1.284 — Claude Sonnet 5.5 上线**
- 功能介绍: 新增 **Claude Sonnet 5.5**(claude-sonnet-5-5),成为 Anthropic API 上的默认 Sonnet 模型,1M context。
- 效果: 定价 $2/$10 每 Mtok,cache reads $0.20/Mtok。同时 auto mode 在读取工作目录外文件前新增「Yes, but ask again next time」选项,允许单次读取但后续仍询问;/usage 和状态栏现在显示 Claude apps gateway 的美元消费额度(如 "$271.40 / $500.00 spent")。
- 使用限制: Claude Code,Anthropic API。默认 Sonnet 模型。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.284)

**Claude Code v2.1.287 — Claude Mods 与 You should know**
- 功能介绍: 新增 **Claude Mods**,插件现在可以修改更深层行为;内置 mod **You should know**,由一个 side agent 监控你的操作,标记你或 Claude 可能遗漏的事项。
- 效果: 用 `/plugin enable cc-plugin-you-should-know@builtin` 开启(需 first-party session 且 telemetry 开启)。agents view 新增 `n:` 过滤器,可匹配 session 名和任务,折叠区域也会显示匹配项,Enter 打开第一个匹配。
- 使用限制: Claude Code,插件系统。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.287)

**Claude Code v2.1.288 — UI selection 与 gh api 内置**
- 功能介绍: 新增 `$.ui.selection()` 供 mods 使用,返回全屏模式下最后选中的文本;当选中内容位于单个 transcript row 内时同时返回该行。新增内置 `gh api` 供镜像中无 GitHub CLI 的 cloud session 使用。
- 效果: 修复了内置工具向终端发送文件名、jq 过滤器或 GitHub 错误中的控制字符的问题;新增 Ctrl+C 清空 prompt 后的恢复机制——在空 prompt 上按 Up 可找回草稿(含粘贴文本)。
- 使用限制: Claude Code,mods 开发者。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.288)

**Claude Code v2.1.285 — WebFetch 开关与 desktop 启动**
- 功能介绍: 新增 `CLAUDE_CODE_DISABLE_WEB_FETCH` 环境变量关闭 WebFetch 工具;新增 `claude --desktop` 在当前目录打开 Claude 桌面应用,或配合 `--continue / --resume ` 打开指定 session。
- 效果: 新增 `claude plugin configure ` 查看插件选项及未设置项,或用 `--values-stdin` 从 stdin 保存新值;新增 `.=` 语法用于 `claude plugin install --config`。
- 使用限制: Claude Code,环境变量配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.285)

**Claude Code v2.1.286 — 权限提示计数与鼠标支持**
- 功能介绍: 多个权限请求堆叠时,权限提示新增计数(如 "2 of 5");全屏模式下列表的 "N more" 行新增鼠标支持,可点击跳转到列表末端,带 hover 和 pressed 状态。
- 效果: 修复了多个 Claude Code 进程和 IDE 扩展在 gcpAuthRefresh 或 awsAuthRefresh 凭证过期时各自打开登录浏览器的问题;修复 `claude --resume` 和 `--continue` 在 batch 后有时丢失所有 turn 的问题。
- 使用限制: Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.286)

**Claude Code v2.1.282 / v2.1.283 — 管理设置与 prose 宽度**
- 功能介绍: v2.1.282 新增 `maxProseWidth` 设置,在宽终端中限制 Claude 散文宽度,表格和代码块保持全宽;新增启动通知及 `/status`、`claude doctor` 条目,列出项目设置文件中被忽略或关闭 telemetry 的变量。v2.1.283 新增 `x-claude-code-prompt-id` 网关提示头(需 `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` 开启),让 LLM 网关能分组同一用户 prompt 的请求。
- 效果: v2.1.283 新增 `availableModelsMatch` 托管设置("exact" 时仅允许指定模型版本,新版本保持被阻止直到列入);新增 `deniedModels` 托管设置阻止特定模型;新增 `allowClaudeInChromeWithManagedMcp` 托管设置,允许 `claude --chrome` 与独占 managed-mcp.json 并存。
- 使用限制: Claude Code,企业托管环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.282)
