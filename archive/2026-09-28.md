[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.280)

**Auto mode 服务端分类器默认启用**
- 功能介绍: v2.1.278 起,Claude API 与 Enterprise 用户、Bedrock / Vertex / Foundry / 网关上的 auto mode 默认改用服务端分类器,不再对分类器开销计费。
- 效果: 减少本地分类器带来的 token 消耗与费用;若发生计费回退会给出警告;/status 新增 Auto mode server 行显示当前会话分类器运行位置。
- 使用限制: Claude Code;Bedrock / Vertex / Foundry / 网关用户可用 **CLAUDE_CODE_AUTO_MODE_SERVER=0** 退出(推测)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)

**网关提示头分组与模型管控设置**
- 功能介绍: v2.1.283 新增 **x-claude-code-prompt-id** 网关提示头,可让 LLM 网关按用户提示分组请求;新增 **availableModelsMatch** 与 **deniedModels** 托管设置。
- 效果: 网关侧可更精准地追踪单个用户提示产生的多次请求;模型管控上,exact 模式可阻止未列出的新版本模型,deniedModels 可显式封禁特定模型。
- 使用限制: Claude Code;需设置 **CLAUDE_CODE_GATEWAY_HINT_HEADERS=1** 启用提示头;托管设置面向企业/团队管理员。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.283)
