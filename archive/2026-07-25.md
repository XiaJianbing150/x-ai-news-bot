🅰️ **Claude 产品更新详解**

**Claude Opus 5 模型发布**
• 功能介绍：Anthropic 发布最新旗舰模型 Claude Opus 5，拥有 100 万 token 上下文窗口，启用快速模式，定价为输入 $10/Mtokens、输出 $50/Mtokens。现已作为 Claude Code 中的默认 Opus 模型上线。
• 效果：开发者可在复杂编程、长文档分析、多步代理任务中获得更强推理能力和更大上下文处理空间，快速模式显著降低长任务的等待时间。
• 使用限制：API 与 Claude Code 均可使用，按 token 计费；Pro/Max 订阅用户可在 claude.ai 体验（推测）；全平台可用。
[原文](https://www.anthropic.com/news/claude-opus-5)

**Claude Code /fork 会话分叉与 /subtask 子任务**
• 功能介绍：/fork 命令现在将当前对话复制到独立的后台会话（在 claude agents 中显示为新行），不打断当前工作流；原来在会话内启动的子代理命令改为 /subtask。
• 效果：用户可以随时从当前上下文中派生新会话继续探索，实现并行开发；/subtask 可当场分配子任务处理特定问题，提升多任务效率。
• 使用限制：Claude Code（需 API key），所有平台。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**/code-review 改用后台子代理运行**
• 功能介绍：/code-review 命令改为后台子代理运行，审查结果不再写入主对话，并保持当前堆叠的斜杠命令作为审查目标。
• 效果：代码审查不再占据对话历史，你可以在审查进行中继续发出后续指令，保持开发心流。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.218)

**提示输入 emoji 快捷补全**
• 功能介绍：在 Claude Code 提示输入框中输入 :heart: 直接插入 ❤️，输入 :hea 弹出建议列表。可通过 emojiCompletionEnabled 设置关闭。
• 效果：快速插入 emoji 辅助提示组织，尤其实用于用符号标记优先级或情感。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.217)

**沙箱网络严格白名单与文件系统禁用**
• 功能介绍：新增 sandbox.network.strictAllowlist 设置，拒绝非白名单主机连网；新增 sandbox.filesystems.disabled 设置，可跳过文件系统隔离而保留网络出站控制。
• 效果：为安全敏感环境提供更细粒度的命令沙箱策略，允许严格限定外部连通性，或简化仅需网络控制的工作流。
• 使用限制：Claude Code 启用沙箱时可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.219) [原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.216)

**DirectoryAdded 挂钩与 MCP 错误报告**
• 功能介绍：新增 DirectoryAdded 挂钩，当 /add-dir 或 SDK 注册新工作目录时触发；headless stream-json 的 init 事件新增 mcp_server_errors 字段，列出 MCP 配置中的错误服务器。
• 效果：自动化流程可感知目录变化并应答；无头模式调试 MCP 配置更直接。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)

**对话内 WebSearch 调用次数上限与自动模式重置**
• 功能介绍：新增会话级 WebSearch 工具调用上限（默认 200 次），可通过 CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION 调整；新增 claude auto-mode reset 命令将自动模式恢复为默认。
• 效果：防止搜索循环消耗大量配额；快速重置自动审批等安全设置，便于多项目切换。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**向 Claude 询问 Anthropic 经济指数**

• 效果：研究人员和公众用自然语言即可获取 AI 对劳动力市场影响的追踪数据，便于快速洞察。
• 使用限制：推测在 claude.ai 上可用，具体用户范围未公布。
[原文](https://www.anthropic.com/news/anthropic-economic-index-connector)

🅾️ **OpenAI 产品更新详解**

**ChatGPT 健康功能 (Health in ChatGPT)**
• 功能介绍：符合条件的美国用户现在可以安全地连接医疗记录与 Apple Health，让 ChatGPT 提供更个性化的健康洞察和健康理解。
• 效果：用户可分析个人健康数据获得趋势总结与建议，辅助日常健康管理。
• 使用限制：目前仅限符合资格的美國用户使用，需连接医疗记录或 Apple Health；推测在 ChatGPT 应用 (Web/iOS/Android) 中逐步推出，可能免费或 Plus 用户均可使用。
[原文](https://openai.com/index/health-in-chatgpt)

**OpenAI Presence 企业 AI 代理平台**
• 功能介绍：OpenAI Presence 是经过验证的企业级 AI 代理平台，帮助企业部署可信任的语音与聊天代理，用于客户服务和内部工作流。
• 效果：企业可快速构建合规安全的 GPT 驱动客服机器人与内部助手，整合现有系统。
• 使用限制：面向企业客户，需联系 OpenAI 获取定价与部署细节。
[原文](https://openai.com/index/introducing-openai-presence)

**ChatGPT 小企业计划**
• 功能介绍：OpenAI 启动 ChatGPT for Small Business 计划，帮助创业者学习 AI 技能、自动化工作并借助 ChatGPT Work 成长。
• 效果：小企业主可获得针对性资源和培训，以更低门槛导入 AI 提升运营效率。
• 使用限制：小企业主可申请加入，可能关联 ChatGPT Work 新定价层（推测）。
[原文](https://openai.com/index/introducing-chatgpt-small-business-program)
