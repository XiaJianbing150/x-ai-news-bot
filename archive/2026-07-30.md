🅰️ **Claude 产品更新详解**

**Claude Opus 5**
• 功能介绍: Anthropic 发布最新旗舰模型 Claude Opus 5，具备 100 万 token 上下文窗口，支持快速模式，在复杂推理、代码生成和长文理解上显著提升。
• 效果: 面向需要最高质量输出的高难度任务，如科研分析、大型代码库重构、多步代理工作流。在内部基准测试中明显超越前代 Opus，且保持与 Sonnet 系列不同的“深思熟虑”特性。
• 使用限制: 即日起通过 Anthropic API 提供，Claude Code、Workbench 及所有 Pro/Max/Team/Enterprise 套餐均可使用。快速模式定价为 $10/$50 每百万 token (输入/输出)。[原文](https://www.anthropic.com/news/claude-opus-5)

**Claude Code v2.1.217–v2.1.219 累积更新**
• 功能介绍: 连续三个版本在终端开发环境中新增 Claude Opus 5 默认支持、沙箱网络严格白名单、目录监听 Hook、emoji 自动补全、后台代码审查子代理等多个实用功能与可靠性修复。
• 效果: 开发者可以无需切换即可使用 Opus 5 的自省式推理；/code-review 改为后台子代理后不再占用主对话配额，更适合长链路开发；emoji 自动补全 (如 :heart: 插入 ❤️) 优化交互体验；sandbox.network.strictAllowlist 提升沙箱安全性；DirectoryAdded hook 可在运行时感知新目录。Bug 修复涵盖 Windows 路径损坏、MCP 内存泄漏、转录写入失败警告等，整体稳定性增强。
• 使用限制: 通过 Claude Code 终端工具使用 (需 API 密钥)，Opus 5 受相应 API 价格限制，其他功能对所有用户开放。v2.1.220 仅含错误修复，未引入新功能。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)

**Anthropic Economic Index Connector**
• 功能介绍: 发布“向 Claude 询问 Anthropic 经济指数”的官方连接器，使 Claude 能直接调取 Anthropic Economic Index 的实时数据并回答就业、自动化影响等经济问题。
• 效果: 研究人员、分析师可直接在对话中交叉验证经济指标，免去手动检索。Claude 可引用权威来源数据，提升分析可信度。
• 使用限制: 推测为 MCP 插件形式，需在 Claude 应用或 API 中配置连接器，目前免费提供。[原文](https://www.anthropic.com/news/anthropic-economic-index-connector)

🅾️ **OpenAI 产品更新详解**

**GPT-5.6 API 双设置提升 ARC-AGI-3 成绩三倍**
• 功能介绍: 通过启用推理过程保留 (reasoning retention) 与上下文压缩 (compaction) 两个 API 参数，GPT-5.6 在 ARC-AGI-3 抽象推理基准上分数提升至原来的 3 倍，同时提高效率。
• 效果: 开发者可针对复杂推理任务精细控制模型内部思考链的保留与压缩策略，用更低的成本获得更高的推理质量，特别适用于需要多步逻辑推导的代理型应用。
• 使用限制: 面向 API 用户，具体参数名和取值需查阅最新文档，可能仅限部分模型版本。[原文](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores)

**Health in ChatGPT**
• 功能介绍: 在美国上线“健康”功能，允许用户安全连接医疗记录和 Apple Health 数据，获得更个性化的健康洞见与问答。
• 效果: 用户可将可穿戴设备数据、就诊记录接入 ChatGPT，询问趋势、药物提醒、生活方式建议等。ChatGPT 可在隐私合规前提下提供上下文感知的健康信息解读。
• 使用限制: 仅限符合条件的美国用户，需在 ChatGPT 应用内完成授权连接，初期可能仅支持 Plus/Pro 用户。[原文](https://openai.com/index/health-in-chatgpt)

**OpenAI Presence 企业 AI 代理平台**
• 功能介绍: 推出经过验证的企业级 AI 代理平台 Presence，帮助企业部署可信赖的语音和聊天代理，用于客户服务和内部工作流。
• 效果: 企业可快速构建面向客户的语音助手或内部问答机器人，具备安全护栏、监控集成与低代码编排能力，区别于传统聊天机器人，提供更主动的代理式执行。
• 使用限制: 面向企业客户，需联系销售或通过 Azure 集成，定价未公开。[原文](https://openai.com/index/introducing-openai-presence)
