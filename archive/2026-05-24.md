🅰️ **Claude 产品更新详解**

**/code-review 命令替换 /simplify**
• 功能介绍: Claude Code 将 /simplify 重命名为 /code-review，可按努力程度（如 /code-review high）检查代码正确性，并使用 --comment 将发现作为内联 GitHub PR 评论发表；旧的清理‑修复行为已移除。
• 效果: 开发者可在提交前获得不同深度级别的自动审查，快速定位逻辑错误并直接留在 PR 上，替代人工初步 review。
• 使用限制: Claude Code 终端中使用，支持所有套餐；执行 /code-review 需有仓库上下文。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**背景会话常驻与恢复**
• 功能介绍: 在 claude agents 中用 Ctrl+T 固定后台会话使其空闲时保持存活，重启时可原地更新；/resume 支持后台会话，子代理完成时显示耗时（如“3h 2m 5s”）；新增 claude agents --json 以 JSON 导出会话列表。
• 效果: 长任务可跨终端/重启持续运行，适合 tmux-resurrect 或状态栏集成，避免断连丢失进度。
• 使用限制: Claude Code 终端，适用于所有计划；通过 worktree.bgIsolation 可调整隔离级别。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**/usage 分类用量细分**
• 功能介绍: /usage 命令现在按 skills、subagents、plugins 以及每个 MCP 服务器分别展示 Token 消耗与限制。
• 效果: 精准定位哪个组件消耗最多上下文，方便优化工作流和控制成本，尤其适合重度 MCP/插件用户。
• 使用限制: Claude Code 中按 /usage 查看，适用所有套餐，需连接 MCP 才能看到分服务器数据。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**插件依赖管理与上下文成本预览**
• 功能介绍: claude plugin disable 会阻止禁用被其他已启用插件依赖的插件并提示；claude plugin enable 自动启用传递依赖。在 /plugin 市场浏览界面中，现在展示每个插件的预估每轮/每次调用 Token 成本。
• 效果: 防止误禁用导致工作流中断，同时让用户提前了解插件开销，选择更经济的工具组合。
• 使用限制: Claude Code 插件系统，/plugin discover 和 browse 中可见，适用所有用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.143)

**企业 MCP 云连接器集中管理**
• 功能介绍: 新增 managed setting *allowAllClaudeAiMcps*，允许将 claude.ai 云端 MCP 连接器与 managed-mcp.json 一同加载，集中下发给企业用户。
• 效果: IT 管理员可批量启用经过审核的云 MCP 连接器，无需每个开发者自行配置，保证安全与合规。
• 使用限制: Claude Code Enterprise 版，通过 managed settings 下发。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**界面与操作小优化**
• 功能介绍: /diff 详情支持键盘滚动（方向键、j/k、PgUp/PgDn 等）；Markdown 输出渲染 GFM 任务列表复选框（- [ ] / - [x]）；/model 现在仅改变当前会话模型，按 d 可设置未来会话默认；/plugin 浏览界面新增显示插件命令、代理、技能及最后更新时间。
• 效果: 日常交互更顺滑，代码差异审查、任务清单跟踪、模型切换均获得体验提升。
• 使用限制: Claude Code 终端，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)
