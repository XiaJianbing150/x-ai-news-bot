🅰️ **Claude 产品更新详解**

**Claude Code v2.1.169: 安全模式与 /cd 命令**
• 功能介绍: 新增 `--safe-mode` 启动参数（及环境变量 `CLAUDE_CODE_SAFE_MODE`），可在故障排查时一键禁用所有自定义项（CLAUDE.md、插件、技能、钩子、MCP 服务器）。新增 `/cd` 命令，可在不破坏提示缓存的情况下将会话切换到新的工作目录。
• 效果: 当本地配置导致异常时，可快速进入纯净环境定位问题；`/cd` 让用户在同一会话中改变项目目录而无需重新进行大量上下文加载，显著改善长会话中的目录切换体验。
• 使用限制: Claude Code CLI，需升级到 v2.1.169 版本。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)

**Claude Code v2.1.166: 备用模型链与全局 deny 规则增强**
• 功能介绍: 新增 `fallbackModel` 设置，可配置最多三个备用模型，当主模型过载或不可用时按顺序自动切换（`--fallback-model` 现在也适用于交互式会话）。deny 规则的 `tool-name` 位置支持 glob 模式（`*` 表示禁止所有工具）；allow 规则拒绝非 MCP 的 glob，且对未知工具名会输出启动警告。加强了跨会话消息传递的安全性：其他 Claude 会话通过 SendMessage 转发的消息现在不再覆盖被转发方的自主设定。
• 效果: 开发者可在高峰期自动降级到轻量模型，保障服务可用性；更精细的安全策略控制，可彻底禁用某类工具或屏蔽潜在风险操作。
• 使用限制: Claude Code v2.1.166，需编辑配置文件或使用命令行参数。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.166)

**Claude Code v2.1.163: 版本锁定、插件管理与会话增强**
• 功能介绍: 新增 `requiredMinimumVersion` / `requiredMaximumVersion` 托管设置，若 Claude Code 版本不在允许范围则拒绝启动并引导用户升级至指定版本。新增 `/plugin list` 命令，支持 `--enabled` / `--disabled` 过滤器。`/btw` 回答新增 “c to copy” 快捷键，将原始 markdown 复制到剪贴板，保留格式。Hooks 改进：Stop/SubagentStop 钩子现在可以返回消息，用于在停止时给出解释或提示。
• 效果: 企业或团队可集中管控工具版本，防止不兼容；插件管理更直观；`/btw` 的结果可直接粘贴到文档或 PR 中而无需重新排版；停止子代理时能提供反馈，改善协作安全性。
• 使用限制: Claude Code v2.1.163，版本管理需管理员配置托管设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.163)

**Claude Code v2.1.162: agents 状态可见性与 /effort 持久化**
• 功能介绍: `claude agents --json` 输出新增 `waitingFor` 字段，显示等待中的会话具体被什么阻塞（如权限提示）。明确列出 Grep/Glob 工具的 `--tools` 选项现在在原生版本中会提供专用的嵌入式搜索工具。`/effort` 现在会确认所选的任务努力程度将作为新会话的默认值持久化。点击斜杠命令的自动补全菜单现在会将其填入提示词而非立即执行。
• 效果: 监控并发会话时能快速发现哪个 agent 在等用户输入；开发人员可获得更高效的代码搜索体验；`/effort` 设置可跨会话保留，减少重复调整；补全行为更安全，避免误触发。
• 使用限制: Claude Code v2.1.162，部分功能仅限原生构建（带嵌入式搜索）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.162)

**Claude Code v2.1.161: 可观测性增强与并行取消策略**
• 功能介绍: `OTEL_RESOURCE_ATTRIBUTES` 的值现作为数据点标签输出，可按团队或仓库等自定义维度分片度量使用量。`claude agents rows` 展示已完成/总任务数，peek 显示运行时间最长的项。`/mcp` 界面对从未登录过的 claude.ai 连接器默认折叠。并行工具调用中，单个 Bash 命令失败不再取消同批次的其他调用。
• 效果: 团队可更细粒度地追踪 API 成本；agent 工作进度一目了然；MCP 连接器列表更简洁；并行执行任务时，一个脚本报错不会导致其他独立任务功亏一篑。
• 使用限制: Claude Code v2.1.161，OTEL 需要自行配置后端。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.161)

**Claude Code v2.1.160: 写入保护与编辑流程优化**
• 功能介绍: 在写入 shell 启动文件（.zshenv, .bash_login 等）或 ~/.config/git/ 前会先请求确认，防止意外命令执行。`acceptEdits` 模式下写入构建工具配置文件（如 .npmrc, bunfig.toml 等）之前也会提示。Edit 操作在使用 grep 查看文件后不再需要单独的 Read 步骤，可以直接编辑。
• 效果: 防御性编程，避免 AI 代理无意中破坏开发环境；编辑流程更顺畅，减少来回请求。
• 使用限制: Claude Code v2.1.160。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.160)
