**Claude Code v2.1.310**
- 功能介绍: 在 Bedrock、Vertex、Foundry 上新增 Monitor 工具与插件监控支持;当遥测或非必要流量被禁用时,长时间前台 sleep 也会被阻止

- 使用限制: Claude Code CLI,全平台;自动重试无需配置
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.310)

**Claude Code v2.1.309**
- 功能介绍: 修复 macOS/Linux 沙箱 Bash 命令在沙箱外执行 shell 启动文件的问题;修复 denyWrite glob 模式经符号链接路径时不生效;沙箱命令与自动接受编辑不再能修改 --mcp-config 传入的 MCP 配置文件
- 效果: 沙箱隔离更可靠,防止越权写入和 MCP 配置被意外篡改,对依赖沙箱做安全边界的工作流更可信
- 使用限制: Claude Code CLI,macOS / Linux
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.309)

**Claude Code v2.1.307**

- 效果: 开发者能统一迁移到最新 API 版本;安全事件可观测性大幅提升,便于审计和调试自动审批链路
- 使用限制: Claude Code CLI;修复了 CLAUDE_CODE_DISABLE_1M_CONTEXT 与 [1m] 后缀别名(如 opus[1m])组合时的 model-not-found 错误
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.307)
