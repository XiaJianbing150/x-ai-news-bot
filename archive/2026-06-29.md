🅰️ **Claude 产品更新详解**

**Claude Tag**
• 功能介绍: Anthropic 推出全新团队协作功能 Claude Tag，允许团队通过标签对 Claude 工作内容进行分类和组织，提升知识管理与检索效率。
• 效果: 团队成员可以为对话、项目、输出打上自定义标签，在多项目并行时快速定位上下文，解决“海量对话难回溯”的痛点，尤其适合知识型团队的长期协作。
• 使用限制: (推测) 面向 Team / Enterprise 计划，预计在 Web 端和桌面应用优先上线。
[原文](https://www.anthropic.com/news/introducing-claude-tag)

**Claude Code v2.1.185**
• 功能介绍: 将流式响应停滞提示从"无响应 · 正在重试"改为"等待 API 响应 · 将在…后重试"，并将判定无响应的静默时间从 10 秒延长至 20 秒。
• 效果: 减少因网络波动造成的误报，用户等待时获得更准确、更友好的反馈，不会过早中断生成过程。
• 使用限制: Claude Code CLI，所有用户更新即可生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.185)

**Claude Code v2.1.186**
• 功能介绍: 新增 `claude mcp login ` / `claude mcp logout ` 命令，支持通过 `--no-browser` 和 stdin 重定向在 SSH 中完成 MCP 服务器认证；`/workflows` agent 详情视图增加按状态过滤 (按 `f`)；`/plugin` 已安装页新增 Skills 分类；新增 `teammateMode: "iterm2"` 设置在找不到 it2 CLI 时给出警告。
• 效果: 远程开发与自动化更顺畅，无需浏览器即可管理 MCP 认证；工作流和插件管理更直观，对依赖 iTerm2 的环境提供清晰指引。
• 使用限制: Claude Code CLI，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.186)

**Claude Code v2.1.187**

• 效果: 提升沙盒安全性，防止敏感凭证泄露；组织管理员可以精细管控模型使用；鼠标操作体验更完整。

**Claude Code v2.1.191**
• 功能介绍: 新增 `/rewind` 命令，支持从 `/clear` 之前的对话状态恢复；修复滚动条在流式响应期间跳到底部的问题；后台 agent 停止后不再自动复活，调整为永久停止；`/voice` 在因组织策略禁用时显示明确说明；修复 `/login` URL 在部分环境截断的缺陷。
• 效果: 错误清屏后可以找回对话上下文，避免精力浪费；后台任务管理更可靠，语音和登录的提示更友好。

**Claude Code v2.1.193**
• 功能介绍: 新增 `autoMode.classifyAllShell` 设置，让所有 Bash/PowerShell 命令都经过自动模式分类器；自动模式拦截原因会写入记录、拦截 toast 和 `/permissions recent denials`；新增 OpenTelemetry 日志事件 `claude_code.assistant_response`，需设置 `OTEL_LOG_ASSISTANT_RESPONSES=1` 才记录模型响应全文。

**Claude Code v2.1.195**
• 功能介绍: 新增环境变量 `CLAUDE_CODE_DISABLE_MOUSE_CLICKS`，在全屏模式下禁用鼠标点击/拖拽/悬停，但保留滚轮滚动；修复带连字符的 hook matcher (如 `code-reviewer`、`mcp__brave-search`) 误触发子串匹配的问题，现改为精确匹配，并支持 `mcp__brave-search__.*` 通配符；修复 macOS 语音听写在长时间会话因默认输入设备变化而采集静音的 bug。
• 效果: 在全屏终端场景避免误触中断 Clobber 操作；hook 触发更精确，定制化工作流的可靠性提升；语音交互长时间使用也不易中断。
• 使用限制: Claude Code CLI，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.195)
