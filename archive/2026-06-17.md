🅰️ **Claude 产品更新详解**

**Claude Fable 5 与 Mythos 5 发布**
• 功能介绍：Anthropic 推出 Claude Fable 5（安全通用版）与 Claude Mythos 5（政府特许版）。Fable 5 能力超越以往所有公开模型，为 Mythos 级模型的安全公开版本；Mythos 5 面向最高安全许可的政府场景。Fable 5 在 Claude Code 中可直接使用，自带 1M 上下文。
• 效果：用户可在 Pro/Max/Team/Enterprise 等付费计划中体验超越以往的推理与代码能力；Fable 5 将高能力与安全对齐结合，向大众开放。Mythos 5 面向机密场景。
• 使用限制：Fable 5 在 Claude Code 中面向付费计划可用（Pro/Team 使用 Sonnet 级别，Max/Team Premium/Enterprise 可用 Opus 级别），默认 1M 上下文。Mythos 5 需政府特许。
[原文](https://www.anthropic.com/news/claude-fable-5-mythos-5)

**Claude Code v2.1.169–179 功能汇总**
• 功能介绍：两个小版本密集带来多项更新：引入 —safe-mode 标志一键禁用所有自定义（CLAUDE.md、插件、技能、钩子、MCP）用于排障；新增 /cd 命令可在会话中切换工作目录且不破坏提示缓存；支持操作权限的参数匹配 Tool(param:value)，可用通配符精细控制子代理（如 Agent(model:opus) 仅允许 Opus 子代理）；子代理可嵌套生成子代理（最深 5 层）；新增 enforceAvailableModels 强制模型白名单；支持多语言自动生成会话标题；鼠标滚轮加速可关闭；修复 mid-stream 连接断开导致 spinner 卡死、WSL2 下滚动、大目录 sandbox 规则使描述爆炸等问题。
• 效果：开发者能更安全地排查自定义干扰，灵活管理代理权限和模型可选项，享受更稳定的交互体验。嵌套子代理使复杂任务自动拆解更彻底。
• 使用限制：Claude Code v2.1.169–179 适用于所有 Claude Code 安装，Pro/Max/Team/Enterprise 计划下可用相应模型。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.178)
