🅰️ **Claude 产品更新详解**

**Claude Opus 5**  
• 功能介绍: Anthropic 发布最新旗舰模型 Claude Opus 5，拥有 1M 上下文窗口，并默认接入 Claude Code 与 API。  
• 效果: 在复杂推理、长文档处理与代码生成任务上显著超越前代 Opus，1M 上下文可直接吞下整本书或数十页科研论文，适合需要深度分析与跨文件理解的开发者/研究者场景。  
• 使用限制: 通过 Anthropic API（$10/1M tokens 输入，$50/1M tokens 输出）及 Claude 订阅计划（Pro/Max/Team/Enterprise）使用；Claude Code 中已设为默认 Opus 模型。速率限制以官方最新文档为准。  
[原文](https://www.anthropic.com/news/claude-opus-5)

**Claude Code v2.1.215 – v2.1.220 更新汇总**  
• 功能介绍: 过去一周发布的六个版本带来多项增强：默认 Opus 模型切换为 Opus 5；/code-review 改为后台子代理处理，支持堆叠命令审查；添加 emoji 短码自动补全（输入 :heart: 即插入 ❤️）；新增 sandbox.filesystem.disabled 与 sandbox.network.strictAllowlist 控制沙箱行为；支持 DirectoryAdded hook 与转录失败警报；为 --ax-screen-reader 模式加入删除文本的屏幕阅读播报；修复长时间会话中消息归一化的二次方性能问题及 Windows 路径损坏等关键 bug。  
• 效果: 开发者可立即使用 Opus 5 的巨大上下文进行代码重构；代码审查不再阻塞主会话，流程更顺畅；emoji 补全与屏幕阅读器支持改善交互体验；沙箱设置增强安全性与网络管控；转录失败警告防止静默丢失工作记录；性能优化让长会话响应速度重回正常。  
• 使用限制: 适用于 Claude Code 终端用户（所有订阅计划），更新后生效；部分设置通过 .claude/settings.json 配置；沙箱与 hook 功能需按需开启。  
[原文（各版本发布页）](https://github.com/anthropics/claude-code/releases)

🅾️ **OpenAI 产品更新详解**

**Health in ChatGPT**  
• 功能介绍: ChatGPT 正式内建健康功能，允许符合条件的美国用户安全连接自己的医疗记录与 Apple Health 数据，以获取个性化健康洞察。  
• 效果: 用户可以询问健康趋势、症状解读、用药提醒等问题，ChatGPT 结合个人健康档案提供定制化建议，类似随身健康顾问。  
• 使用限制: 目前仅限美国地区符合资格的用户，需通过 ChatGPT（Web/iOS/Android）授权连接，功能可能逐步扩大开放范围。  
[原文](https://openai.com/index/health-in-chatgpt)

**Introducing OpenAI Presence**  
• 功能介绍: 推出企业级 AI 代理平台 OpenAI Presence，帮助组织部署可信的语音与聊天代理，用于客服及内部工作流。  
• 效果: 企业可快速构建自然的语音对话机器人或文字助手，处理客户咨询与员工支持，实现安全合规的全天候自动服务，降低运营成本。  
• 使用限制: 面向 Enterprise 客户，需联系销售获取；底层依赖 GPT 系列模型与语音技术，定价按企业协议确定。  
[原文](https://openai.com/index/introducing-openai-presence)
