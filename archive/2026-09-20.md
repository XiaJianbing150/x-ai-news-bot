**🅰️ Claude 产品更新详解**

**Claude Code v2.1.278 — Auto mode 计费策略调整**
- 功能介绍: Claude API 与 Enterprise 用户,以及 Bedrock / Vertex / Foundry / 网关上的 auto mode,默认改用服务端分类器,不再收取分类器开销费用;若回退到计费模式会发出警告。
- 效果: 降低 auto mode 使用成本,消除此前客户端分类器带来的额外计费;用户可在 /status 中查看当前会话 auto mode 分类器运行位置。
- 使用限制: Claude API / Enterprise / Bedrock / Vertex / Foundry / 网关;Claude Code CLI。Bedrock / Vertex / Foundry / 网关可用 CLAUDE_CODE_AUTO_MODE_SERVER=0 退出。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)

**Claude Code v2.1.277 — AGENTS.md 支持与网关代理增强**
- 功能介绍: 无 CLAUDE.md 的项目现在自动读取 AGENTS.md 作为项目指令;新增 CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1 供仅出口为正向代理的网关使用;网关 upstream 支持静态 headers。
- 效果: 与通用 agent 生态对齐,迁移到 Claude Code 时无需重写项目指令;代理环境下 DNS 解析交由代理处理,适配更复杂的网络拓扑。
- 使用限制: AGENTS.md 支持暂未覆盖 Bedrock / Vertex / Foundry;Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)

**Claude Code v2.1.275 — 网关登录确认与 send-now 快捷键**
- 功能介绍: Claude apps 网关登录时显示已登录账号,保存凭证前需确认;/status 可见。新增 send-now 键(ctrl+enter 或 ctrl+x ctrl+s),可中断当前回合并一次性发送所有排队消息。
- 效果: 网关场景下账号可见性更清晰,避免误存凭证;send-now 让用户能主动打断模型思考并立即提交积压输入,交互更可控。
- 使用限制: Claude Code CLI;网关功能需 Claude apps gateway。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.275)

**Claude Code v2.1.274 — 内存压力警告与 MCP 启动等待控制**
- 功能介绍: 内存使用达临界值时显示可见警告并给出释放或安全重启步骤;新增 CLAUDE_CODE_MCP_STARTUP_WAIT_MS 限制首个非交互回合等待 MCP server 连接的时间(0 = 不等待);OTel trace 增加 effort 属性。
- 效果: 长会话内存耗尽前提前预警,减少崩溃;MCP 启动慢时不再无限阻塞,可观测性增强。
- 使用限制: Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.274)

**Claude Code v2.1.273 — 网关提示头与 MCP 断连通知**
- 功能介绍: 新增 x-claude-code-request-class、x-claude-code-agent-type 等请求头供 LLM 网关使用(CLAUDE_CODE_GATEWAY_HINT_HEADERS=1 开启);MCP server 会话中断连且自动重连放弃时给出通知并指向 /mcp;支持从 Claude app fork 由 --remote-control 启动的会话。
- 效果: 网关可基于请求类型做更细粒度路由/计费;MCP 断连不再静默失败,用户能及时感知并处理。
- 使用限制: Claude Code CLI;网关功能需相应配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.273)
