🅰️ **Claude 产品更新详解**

**Claude for Teachers**
• 功能介绍：Anthropic 推出面向教师的专用计划 Claude for Teachers，为教育工作者提供适用于备课、个性化反馈、课堂管理的 Claude 体验，内置学生安全护栏与教学场景优化。
• 效果：教师可利用 Claude 生成差异化练习题、批量批改作文、设计项目式学习方案，并确保学生交互符合隐私与适龄约束，显著降低准备时间，提高教学互动质量。
• 使用限制：独立计划，预计需教育邮箱验证（推测）；初期在 Web 与桌面应用提供，是否收费未公布，首批可能邀请制。
[原文](https://www.anthropic.com/news/claude-for-teachers)

**Claude Code：emoji 自动补全**
• 功能介绍：在 Claude Code 命令行 prompt 输入中新增 emoji 快捷码自动补全，输入 `:heart:` 自动插入 ❤️，输入 `:hea` 弹出建议列表。
• 效果：开发者撰写提词、提交信息时快速插入表情符号，提升表达清晰度和趣味性；可通过 `emojiCompletionEnabled` 设置关闭。
• 使用限制：Claude Code v2.1.217 起，所有 Claude Code 用户均可享用，需搭配 Anthropic API 使用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.217)

**Claude Code：转录写入警告与内存泄漏修复**
• 功能介绍：当 Claude Code 会话转录写入失败（如磁盘满）或因环境变量意外关闭会话保存时，现在会明确告警，防止无声丢失记录；同时修复了 MCP 工具输出截断后，完整结果仍留在内存中导致内存泄漏的问题。
• 效果：避免长时间会话后才发现对话历史未保存，开发调试更省心；内存占用稳定，大量工具调用场景下不再因残余数据撑满内存。
• 使用限制：v2.1.217 起自动启用，所有 Claude Code 实例生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.217)

**Claude Code：沙盒文件系统隔离可关闭**
• 功能介绍：新增 `sandbox.filesystem.disabled` 设置项，允许开发者跳过文件系统隔离，仅保留网络出口控制。
• 效果：在信任的运行环境中提升执行效率，减少因沙盒带来的 I/O 开销，方便本地深度开发与测试；网络安全性仍保持。
• 使用限制：v2.1.216 起，仅限用户显式启用，需要理解安全影响。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.216)

**Claude Code：长会话性能修复**
• 功能介绍：修复了超长会话中消息规范化计算量随对话轮次呈平方增长的问题，消除了多轮对话下的数秒卡顿和缓慢恢复。
• 效果：在数百轮交互的复杂开发任务中，响应速度稳定，不再出现“卡住”的感觉。
• 使用限制：v2.1.216 起自动生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.216)

**Claude Code：/verify 与 /code-review 技能改为手动触发**
• 功能介绍：Claude 不再自主运行 `/verify` 和 `/code-review` 技能；需要在需要时手动输入 `/verify` 或 `/code-review` 调用。
• 效果：减少不必要的后台分析，节约 token 与时间，开发者对代码检查时机有完全控制。
• 使用限制：v2.1.215 起，所有 Claude Code 会话均改变行为。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.215)

**Claude Code：多项权限与安全修复**
• 功能介绍：修复了单段目录允许规则（如 `Edit(src/**)`）错误地自动批准写入树中同名目录的问题，以及 Windows PowerShell 权限检查绕过、Bash 命令重定向解析偏差、过长命令的判断错误等。
• 效果：文件操作权限更严谨，特别是在 Windows 环境和复杂 shell 命令下，减少误批准风险。
• 使用限制：v2.1.214 起完成修复，直接增强安全性。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.214)

**Claude Code：/fork 改为后台会话与 /subtask 替代**
• 功能介绍：`/fork` 现在会将对话复制到新的后台会话（在 `claude agents` 中可见独立行），原会话继续工作；之前的会话内子代理由新命令 `/subtask` 承担。
• 效果：可在不打断当前流的情况下分叉多个探索分支，后台会话持久化，方便对比和复用；子任务调用更语义化。
• 使用限制：v2.1.212 起提供，需使用 Claude Code 的 claude agents 视图管理。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**Claude Code：自动模式重置与 WebSearch 上限**
• 功能介绍：新增 `claude auto-mode reset` 命令可将自动模式配置恢复默认值，带确认提示；为 WebSearch 工具调用设置每会话上限（默认 200 次，可环境变量调整），防止搜索死循环。
• 效果：自动审批配置可快速复原，搜索费用和时长可控，避免因无限循环消耗大量 API 调用。
• 使用限制：v2.1.212 起，所有 Claude Code 会话均享受此管控。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**Claude Code：--forward-subagent-text 标志与权限预览修复**
• 功能介绍：新增 `--forward-subagent-text` 标志及环境变量，可将子代理文本和思考过程包含在 stream-json 输出中；修复了权限预览中 Unicode 双向覆盖、零宽字符和相似引号可能视觉欺骗批准的漏洞；并修正自动模式下 PreToolUse 挂钩忽略 ask 决定的问题。
• 效果：对需要审计子代理完整输出的工作流更友好，权限提示更安全，自定义安全策略能正确阻断。
• 使用限制：v2.1.211 起，适用于集成了 stream-json 输出的高级开发。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.211)

**Claude Code：耗时计时器与权限规则告警**
• 功能介绍：工具执行摘要行新增实时耗时计数器，长时间运行的工具调用可视显示已用时间；对 `Write(path)`、`NotebookEdit(path)` 等权限规则启动时给出警告，推荐使用 `Edit(path)` 或 `Read(path)`。
• 效果：长时间任务不再看起来僵死，开发者感知运行状态；减少错误权限配置。
• 使用限制：v2.1.210 起默认提供。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.210)

**Claude Code：屏幕阅读模式与 Vim 改进**
• 功能介绍：新增屏幕阅读器模式，通过 `--ax-screen-reader` 或设置 `axScreenReader: true` 启用纯文本渲染；增加 `vimInsertModeRemaps` 设置，可将如 `jj` 的双键序列映射为 Escape；新增 `CLAUDE_CODE_PROCESS_WRAPPER` 环境变量，使所有 Claude Code 子进程通过定制启动器执行，适应企业管控。
• 效果：视障开发者可用屏幕阅读器流畅操作；Vim 用户插入模式退出更顺手；企业 IT 可将 Claude Code 纳入统一进程管理。
• 使用限制：v2.1.208 起，所有 Claude Code 用户可配置使用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.208)
