🅰️ **Claude 产品更新详解**

**Agent View & /goal 命令 (Claude Code v2.1.139)**
• 功能介绍: 新增 Agent View（研究预览），可在单一列表中查看所有 Claude Code 会话（运行中、等待用户、已完成）。新增 /goal 命令，为 Claude 设定完成条件后自动跨多轮持续工作直到达成目标，交互式、-p 模式和远程控制均可用；同时新增 /scroll-speed 命令调节终端鼠标滚轮速度。
• 效果: Agent View 解决多会话管理痛点，用户无需来回切换终端窗口即可监控所有任务；/goal 让 Claude 真正实现"设定目标就不再管"的自主代理模式，叠加轮次、耗时、Token 实时统计，大幅提升长时间任务的可靠性。
• 使用限制: Claude Code CLI，运行 *claude agents* 启动；/goal 适用于交互式、-p 和远程控制模式；均为研究预览阶段。(推测)
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.139)

**Fast Mode 默认升级 Opus 4.7 & Agent 派遣增强 (Claude Code v2.1.142)**
• 功能介绍: Fast Mode 默认模型从 Opus 4.6 升级为 Opus 4.7（可设环境变量回退）。新增 *claude agents* 多个标志位（--add-dir、--settings、--mcp-config 等），允许在派遣后台会话时指定目录、设置、MCP 配置、权限模式、模型和 effort 等级。插件中根级 SKILL.md 无 skills/ 子目录时自动浮现为技能。
• 效果: Fast Mode 用户默认获得更强模型能力，多代理协作更灵活——可精细控制每个后台会话的配置；SKILL.md 自动发现降低插件开发门槛。
• 使用限制: Claude Code CLI；设置 *CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1* 可锁定使用 Opus 4.6。(推测)
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.142)

**插件依赖强制执行 & 上下文成本预估 (Claude Code v2.1.143)**
• 功能介绍: 插件依赖关系现在被强制执行——当一个启用的插件依赖目标插件时，*claude plugin disable* 会拒绝操作并给出可复制的解除命令。插件市场浏览面板新增每轮/每次调用的预估 Token 消耗。新增 *worktree.bgIsolation: "none"* 设置，允许后台会话直接编辑工作副本。
• 效果: 避免用户误禁用被依赖插件导致环境崩溃，操作更安全；Token 预估帮助开发者在安装插件前评估成本；bgIsolation 可选关闭隔离，适合信任的后台任务直接操作文件。
• 使用限制: Claude Code CLI；bgIsolation 适用后台会话场景。(推测)
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.143)

**终端通知支持 & workspace 身份联合 (Claude Code v2.1.141)**
• 功能介绍: Hook JSON 输出新增 *terminalSequence* 字段，可发送桌面通知、窗口标题和响铃。新增 *ANTHROPIC_WORKSPACE_ID* 环境变量用于 workload identity 联合，将令牌范围限定到特定工作区。新增 *CLAUDE_CODE_PLUGIN_PREFER_HTTPS* 支持无 SSH key 环境下通过 HTTPS 克隆插件。
• 效果: 长时间任务完成时可通过桌面通知提醒用户；企业环境中高权限令牌可精确限定作用域，安全合规；HTTPS 克隆方便 CI/CD 等无 SSH 环境。
• 使用限制: Claude Code CLI；workspace 功能需 Anthropic 企业账户配置联邦规则。(推测)
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.141)

**Agent 匹配容错 & /goal 修复 (Claude Code v2.1.140)**
• 功能介绍: Agent 工具子代理类型匹配现在大小写和分隔符不敏感（如 "Code Reviewer" 可识别为 code-reviewer）。更新代理调色板。修复了 */goal* 在禁用所有 Hooks 时无响应的问题，现在会显示明确提示；修复了符号链接设置文件热重载时误触发变更事件的问题。

• 使用限制: Claude Code CLI。(推测)
