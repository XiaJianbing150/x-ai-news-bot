🅰️ **Claude 产品更新详解**

**Claude Opus 4.8**
• 功能介绍：发布迄今最高智能的 Claude 模型，深度推理与长上下文能力大幅提升，在 Claude Code 中成为默认模型并启用“高努力”模式，支持新的动态工作流与快速推理变体。
• 效果：可处理以往需要多步规划、跨越数百个代理的复杂编程与业务任务；高努力模式（/effort xhigh）专攻最难问题；快速模式以 2 倍标准速率、2.5 倍速度运行，成本仅为原高努力模式的一小部分。
• 使用限制：Claude Code v2.1.154 起可用，需 Pro / Max / 企业版或 API 额度；快速模式额外计费。Web / 移动端支持需等后续公告 (推测)。
[原文](https://www.anthropic.com/news/claude-opus-4-8)

**Claude Code 动态工作流（Dynamic workflows）**
• 功能介绍：用户可要求 Claude 创建“工作流”，模型会在后台自动协调数十到数百个子代理并行处理大型任务，不再需要手动拆解步骤。
• 效果：一次对话即可发起跨文件、跨仓库的复杂重构、代码迁移或测试生成，任务完成后通过 /workflows 命令查看所有运行记录，显著提升开发吞吐。
• 使用限制：需 Claude Code v2.1.154，依赖 Opus 4.8 或高努力模式；Pro / Max / 企业用户可用，大规模代理调用会消耗更多 Token。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.154)

**/code-review 与自动修复**
• 功能介绍：原 /simplify 命令重命名为 /code-review，支持指定努力级别（如 /code-review high），--fix 选项可在评审后直接将优化、简化与效率建议应用到工作树中，无需手动合并。
• 效果：可一键获得针对正确性 Bug 的报告（/code-review high），并自动实施修复；/simplify 现在内部调用 /code-review --fix，代码质量反馈闭环更短。
• 使用限制：Claude Code v2.1.147 起可用，需在交互式会话中运行，当前支持的编程语言以 JavaScript/TypeScript/Python 为主 (推测)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**资源用量透明度与键盘操作增强**
• 功能介绍：/usage 新增按技能、子代理、插件和每 MCP 服务器成本分类的消耗明细；/diff 详情视图支持键盘滚动（方向键、j/k 等）；Markdown 输出支持 GFM 任务列表复选框。
• 效果：开发者可精准定位哪部分最耗 Token，调试代理成本；在审查长差异时无需鼠标即可快速浏览。
• 使用限制：Claude Code v2.1.149 起可用；/usage 分类需会话中有子代理或插件调用才会显示数据。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**后台会话固定与会话 JSON 输出**
• 功能介绍：后台会话支持固定（Ctrl+T），空闲时不再自动销毁，更新时原地重启；新增 claude agents --json 直接输出当前所有 Claude 会话的 JSON，用于 tmux-resurrect 等工具；OTEL 跟踪新增 agent_id 和 parent_agent_id 属性，正确嵌套后台子代理调用链。
• 效果：可在终端多任务中保持长期运行的 agent 存活；将 Claude Code 的会话信息集成到自定义状态栏、脚本和可观测性系统中，构建更复杂的开发自动化。
• 使用限制：Claude Code v2.1.147 及以上；固定会话受系统内存压力影响，内存不足时按非固定会话优先释放。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.145)
