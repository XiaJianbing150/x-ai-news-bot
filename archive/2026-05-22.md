🅰️ **Claude 产品更新详解**

**Claude for Small Business**
• 功能介绍：Anthropic 正式推出面向小型企业的 **Claude for Small Business** 计划，为企业提供 Claude 的高级功能，简化 AI 采用路径。
• 效果：小型团队可直接使用 Claude 进行内容写作、数据分析、客户服务等，无需定制化部署，降低使用门槛。
• 使用限制：具体定价与用量上限未公开，推测为付费订阅制，面向小型企业团队（不含 Enterprise 级管理功能）。
[原文](https://www.anthropic.com/news/claude-for-small-business)

**Claude Code：后台会话持久化与 /resume 恢复**
• 功能介绍：Pinned 后台会话（Ctrl+T 启动）现在空闲时不会退出，且会在 Claude Code 更新后原地重启，仅在内存严重不足时释放；同时新增 **/resume** 支持后台会话恢复，并在后台子代理完成通知中显示耗时（如“Agent completed · 3h 2m 5s”）。
• 效果：长时间运行的后台代理任务不再因空闲丢失，工作流更可靠；可随时恢复会话查看状态。
• 使用限制：Claude Code v2.1.144 / v2.1.147 起可用，需使用 claude agents 管理后台会话。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**Claude Code：/code-review 取代 /simplify 并集成 GitHub PR**
• 功能介绍：**/simplify** 重命名为 **/code-review**，支持指定审查努力程度（如 /code-review high），并可通过 **--comment** 将发现以行内评论形式发布到 GitHub PR。原有的“清理并修复”行为已移除。
• 效果：代码评审时可直接定位正确性 bugs 并贴入 PR，与开发流程深度集成。
• 使用限制：Claude Code v2.1.146+，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**Claude Code：插件系统增强（依赖强制、成本预测、浏览优化）**
• 功能介绍：启用插件依赖强制——若某插件被其他插件依赖则禁止禁用（并提示依赖链）；/plugin 浏览窗显示**预计上下文成本**（每次轮次与每次调用 tokens 估计）、插件命令/代理/技能列表及最后更新时间；插件详情页改进。
• 效果：更安全地管理插件依赖、提前量化 token 开销，方便在市场中评估插件价值。
• 使用限制：Claude Code v2.1.143 / v2.1.145 引入，所有用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.143)

**Claude Code：Fast mode 默认升级至 Opus 4.7**
• 功能介绍：Claude Code 的 **Fast mode** 现在默认使用 **Opus 4.7**（此前为 Opus 4.6）。如需继续使用 Opus 4.6，可设置环境变量 CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1。
• 效果：快速模式直接获得最新 Opus 版本的性能提升，无需手动切换。
• 使用限制：Claude Code v2.1.142，所有用户；可通过环境变量回退。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.142)

**Claude Code：新 claude agents 配置标志**
• 功能介绍：**claude agents** 新增 **--add-dir, --settings, --mcp-config, --plugin-dir, --permission-mode, --model, --effort, --dangerously-skip-permissions** 等标志，可在创建分派的后台会话时直接配置各项参数。
• 效果：无需交互即可定制后台代理的运行环境、模型选择、权限控制等，适合脚本化与自动化。
• 使用限制：Claude Code v2.1.142，命令行使用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.142)

**Claude Code：钩子系统支持终端通知**
• 功能介绍：钩子 JSON 输出新增 **terminalSequence** 字段，允许插件发出桌面通知、设置窗口标题或响铃。
• 效果：后台代理任务完成时可通过桌面通知提醒开发者，无需盯着终端。
• 使用限制：Claude Code v2.1.141，需插件主动利用该字段。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.141)

**Claude Code：工作树隔离可关闭 & 背景会话直接编辑**
• 功能介绍：新增 **worktree.bgIsolation: "none"** 设置，允许后台会话直接编辑当前工作副本，绕过隔离工作树（EnterWorktree）。
• 效果：简化某些无需隔离的工作流，避免额外的工作树切换开销。
• 使用限制：Claude Code v2.1.143，需明确配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.143)

**Claude Code：新增环境变量（HTTPS 克隆插件 & 工作负载身份）**
• 功能介绍：**CLAUDE_CODE_PLUGIN_PREFER_HTTPS** 强制通过 HTTPS 克隆 GitHub 插件（适用于无 SSH 环境）；**ANTHROPIC_WORKSPACE_ID** 用于工作负载身份联合，可将令牌限定到特定工作区。
• 效果：简化无 SSH 的设置，增强企业级部署的安全性。
• 使用限制：Claude Code v2.1.141，环境变量配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.141)

**Claude Code：会话 JSON 输出与 OTEL 跟踪改进**
• 功能介绍：**claude agents --json** 以 JSON 格式列出活动会话，便于 tmux-resurrect、状态栏等脚本集成；OTEL spans 现在包含 **agent_id** 和 **parent_agent_id**，并修复了后台子代理的 trace 父子关系。
• 效果：方便构建自定义会话管理工具，提升可观测性与调试效率。
• 使用限制：Claude Code v2.1.145，需配合 OTEL 采集器。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.145)
