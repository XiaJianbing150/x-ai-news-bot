**Claude Haiku 5.5 上线**
- 功能介绍: **Claude Code** v2.1.293 新增 **claude-haiku-5-5**,现已成为 Anthropic API 上的默认 Haiku 模型,支持 1M context。
- 效果: 轻量级任务(快速代码补全、简单问答、大规模批处理)成本更低、上下文更长,适合作为默认快速模型嵌入自动化流程。

[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.293)

**Claude Mods 与 You should know 内置 mod**
- 功能介绍: **Claude Code** v2.1.287 引入 **Claude Mods**,插件现在可以修改更深层行为;同时新增内置 mod「**You should know**」,由一个 side agent 在后台观察并标记你或 Claude 可能遗漏的问题。
- 效果: 开发者可以深度定制 Claude Code 行为;「You should know」相当于一个实时审查副驾驶,在编码过程中主动提示风险。
- 使用限制: Claude Code;「You should know」需通过 `/plugin enable cc-plugin-you-should-know@builtin` 开启,且仅限开启 telemetry 的第一方会话。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.287)

**Hook 失败阻断与 Program Status Protocol**
- 功能介绍: **Claude Code** v2.1.295 为 command 和 HTTP hooks 新增 `onFailure: "block"`,hook 无法启动、超时或异常退出时直接阻断动作而非放行;同时新增 **Program Status Protocol (OSC 7501)** 支持,终端可显示 Claude Code 正在工作、等待输入或已完成。
- 效果: 安全策略更可靠——关键 hook 失败不再静默放行;终端状态可视化让长任务进度一目了然。
- 使用限制: Claude Code;OSC 7501 需终端实现该协议。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.295)

**Agent tool 新增 effort 参数**
- 功能介绍: **Claude Code** v2.1.292 为 Agent tool 增加 `effort` 参数,可指定 sub-agent 的运行努力级别。
- 效果: 开发者能按任务复杂度分配计算资源——简单子任务用低 effort 省 token,复杂子任务用高 effort 保证质量。
- 使用限制: Claude Code;需通过 Agent tool 调用 sub-agent 时指定。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.292)

**Claude Code 其他版本更新(2.1.286–2.1.294)**
