🅰️ Claude 产品更新详解

**Claude Opus 4.8 发布**
• 功能介绍：**Claude Opus 4.8** 正式发布，作为 Anthropic 最新一代旗舰模型上线。
• 效果：为最高难度任务设定新基准，在推理、编码、复杂指令遵循方面较前代有显著提升。与 **Claude Code** 深度集成，默认启用高努力模式（high effort），并引入动态工作流能力，可协调数十到上百个后台 agent 并行处理大规模复杂任务。
• 使用限制：通过 **Anthropic API**、**Claude Code**（v2.1.154+）、**claude.ai** 提供。Fast 模式（2倍速）按标准费率的 2 倍计费。Bedrock / Vertex / Foundry 用户需设置环境变量启用 Auto mode。具体档位暂未在博文中详列。
[原文](https://www.anthropic.com/news/claude-opus-4-8)

**Claude Code v2.1.154: 动态工作流与 Opus 4.8 深度适配**
• 功能介绍：随 **Opus 4.8** 发布，**Claude Code** 推出**动态工作流（Dynamic Workflows）**，用户可通过自然语言要求 Claude 创建复杂工作流，系统在后台自动将工作分发至数十到上百个 agent 执行。新增 **/workflows** 命令查看运行状态，**/effort xhigh** 解锁最高努力级别。
• 效果：用户可处理以往单 agent 难以完成的超大规模任务（如跨仓库重构、全栈系统搭建）。后台协调的工作流模式解放了开发者注意力，只需等待最终结果。
• 使用限制：**Claude Code** 用户立即可用。输入 **/workflows** 查看运行中的工作流。Opus 4.8 默认高努力模式，/effort xhigh 用于最难任务；Fast 模式按 2 倍标准费率提供 2.5 倍速度（推测为 Opus 4.8 专属）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.154)

**Plugin 系统自动加载与 scaffolding**
• 功能介绍：**Claude Code v2.1.157** 起，存放在 **.claude/skills** 目录下的插件会被自动加载，无需通过 marketplace。新增 **claude plugin init ** 命令可脚手架式创建新插件。添加了 **/plugin** 参数的自动补全支持。
• 效果：开发者可立即开始编写和加载本地工作区插件，无需前置发布步骤，大幅降低插件开发门槛，方便团队沉淀和共享内部自动化技能。
• 使用限制：**Claude Code** 用户立即可用。使用 **claude plugin init ** 在 .claude/skills 下生成插件模板。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.157)

**托管版本约束与 /plugin list 命令**
• 功能介绍：**v2.1.163** 新增托管设置 **requiredMinimumVersion** 和 **requiredMaximumVersion**，当 **Claude Code** 版本不在允许范围内时拒绝启动并引导用户安装批准版本。新增 **/plugin list** 命令，支持 --enabled / --disabled 过滤器查看已安装插件。
• 效果：企业管理员可精确管控团队使用的 **Claude Code** 版本，确保合规与稳定性。/**plugin list** 方便用户快速了解当前会话启用的工具集。
• 使用限制：**Claude Code** 企业管理场景。版本约束通过 settings.json 配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.163)

**/btw “c 复制”快捷方式**
• 功能介绍：**v2.1.163** 为 **/btw**（Bug Triage Workflow）命令添加了按 **c** 即可复制的快捷键，将原始 markdown 答案复制到剪贴板，保留格式以便粘贴到 issue tracker 或文档中。
• 效果：开发者在诊断完 bug 后，可一键将结构化分析报告粘贴至 GitHub Issues 等工具，保持格式不失真。
• 使用限制：**Claude Code** 用户立即可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.163)

**Auto mode 扩展至 Bedrock / Vertex / Foundry**
• 功能介绍：**v2.1.158** 将 Auto mode（自动模式）支持扩展到 **Bedrock、Vertex AI 和 Foundry** 平台，适用于 Opus 4.7 和 Opus 4.8。通过设置环境变量 **CLAUDE_CODE_ENABLE_AUTO_MODE=1** 开启。
• 效果：使用云平台部署 **Claude Code** 的企业用户也能享受自动执行多步操作而无需频繁手动确认，提升云端开发效率。
• 使用限制：仅限 Opus 4.7 / 4.8 模型。需手动设置环境变量启用（推测仍为实验性或需要管理员审批）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.158)

**Shell 敏感文件写入保护与 acceptEdits 安全强化**
• 功能介绍：**v2.1.160** 新增在写入 shell 启动文件（.zshenv, .bash_login 等）和 git 配置文件前的确认提示。acceptEdits 模式下写入构建工具配置文件（.npmrc, .yarnrc*, bunfig.toml 等，可能执行代码）前也会要求确认。
• 效果：防止 AI 意外或恶意修改可能导致命令执行的敏感配置，提升自动化编辑环节的安全性。
• 使用限制：**Claude Code** 用户立即可用，安全确认环节不可跳过。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.160)

**OTEL 自定义标签与并行工具调优**
• 功能介绍：**v2.1.161** 支持将 **OTEL_RESOURCE_ATTRIBUTES** 的值作为标签注入指标数据点，可按团队或仓库等维度切片用量。并行工具调用中，一个 Bash 命令失败不再取消同批次其他调用。
• 效果：DevOps 团队可在可观测性平台中按自定义维度（团队、项目、仓库）精细分析 Claude Code 的 token 消耗。并行任务更健壮，一个环节出错不影响其他独立任务。
• 使用限制：**Claude Code** 用户可配置 OTEL 相关环境变量。并行行为变更自动生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.161)
