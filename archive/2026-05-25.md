**Claude Code /code-review 命令（v2.1.146 / v2.1.147）**
• 功能介绍：原 /simplify 命令重命名为 /code-review，可指定审查强度（如 /code-review high），专注发现代码正确性问题；通过 --comment 可将审查结果以行内评论形式发布到 GitHub PR。
• 效果：开发者可以按需对代码进行多层级的正确性审查，替代原先的清理修复行为，更贴合深度代码评审场景。支持直接注入 GitHub PR，让审查意见直接落到对应代码行。
• 使用限制：在 Claude Code 终端中使用；适用于所有 Claude Code 用户（Free / Pro / Max / Team / Enterprise 对应的 API 消费模式）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.146)

**Claude Code 后台会话固定与恢复（v2.1.144 / v2.1.147）**
• 功能介绍：CTRL+T 进入 agent view 的会话现在可通过「固定」（pinned）保持存活，空闲时不自动退出，更新 Claude Code 后可原地重启；/resume 列表现支持后台会话（bg 标记），恢复后继续工作；子 agent 完成通知增加耗时显示（如“3h 2m 5s”）。
• 效果：长期运行的后台编码任务、子代理不会被意外杀死，适合跨天大型重构或持续监控任务；后台会话恢复让上下文不中断，显著降低重启成本。
• 使用限制：Claude Code 终端内使用，固定会话在内存压力下仍会优先保留；需 v2.1.144+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.144)

**Claude Code /model 默认设置（v2.1.144）**
• 功能介绍：/model 命令现在只改变当前会话的模型；在模型选择器中按 d 键可设置新会话的默认模型。
• 效果：用户可在不改变全局默认的前提下临时切换模型进行对比测试，避免污染偏好设置。
• 使用限制：Claude Code 终端内使用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.144)

**Claude Code /usage 用量分类明细（v2.1.149）**
• 功能介绍：/usage 命令现展示每类用量明细，按技能（skills）、子代理（subagents）、插件（plugins）、每个 MCP 服务器等维度细分消耗的 token 或成本。
• 效果：帮助用户精准定位出 Claude Code 会话中哪个组件消耗最多资源，便于优化提示或控制开销。
• 使用限制：Claude Code 终端内使用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

• 效果：高级用户和开发者可将 Claude Code 会话状态集成进自己的终端工作流，实现自动保存、面板展示等定制。
• 使用限制：命令行操作，需 Claude Code v2.1.145+。
