**Reflect with Claude — 反思你的使用模式**
• 功能介绍：Claude 新增「反思」功能，根据你的对话历史生成个性化使用分析，帮助你理解自己如何与 Claude 协作、发现可优化的工作模式。
• 效果：用户可借此识别低效提示习惯、重复任务场景，从而调整提问方式，提升长期使用效率；相比对家单纯提供用量统计，这更像是「元认知教练」。
• 使用限制：面向 Web 端用户逐步推送，支持所有套餐（Free / Pro / Max / Team / Enterprise），不需要等候名单。

**Claude Code v2.1.202–v2.1.207 近一周累积更新**
• 功能介绍：一周内连续六个版本发布，主要改进包括：Auto mode 在 Bedrock / Vertex AI / Foundry 上默认可用，无需环境变量；**/cd** 命令增加目录路径建议；**/doctor** 新增检查项，可修剪提交的 CLAUDE.md 中冗余内容；新增动态工作流规模设置，用户可在 /config 中调优 agent 分派数量（small/medium/large 三级）；**/commit-push-pr** 自动授权 push 到已配置的远端仓库；登录即将过期时给出警告横幅；手动权限模式下状态栏显示 ⏸ 徽章；会话附加工 作目录会被加入 MCP roots/列表，并随目录变化发送通知；修复终端在输出超长列表/表格/代码块时冻结和按键延迟等问题；修复 Windows 上工作树删除可能误删外部文件的安全问题。
• 效果：整体提升了 Claude Code 的自动化稳定性、跨平台兼容性以及大文件处理性能，尤其是 Auto mode 免 opt-in 和高级推送自动化让 CI/CD 场景更顺畅。
• 使用限制：Claude Code 需安装最新 npm 包，Auto mode 的企业控制项可通过 disableAutoMode 禁用；支持所有 Claude API 计费账户（含 Bedrock / Vertex AI / Foundry），无额外等候名单。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.207)

**GPT-5.6 模型发布 — 前沿智能为核心工作加码**

**ChatGPT Work — 可自主执行多应用、跨文件任务的持久代理**
• 功能介绍：ChatGPT Work 是全新推出的代理型产品，能主动操作你的应用与文件，持续跟随一个项目数小时，将目标直接转化为成品，无需用户逐个步骤确认。
• 效果：适用于调研报告、数据处理、代码库维护等需要长时间跨度的任务，用户只需给出最终目标，Work 会自行规划、执行并在异常时请求介入。
• 使用限制：面向 ChatGPT Pro / Max 和 Team 用户开放，初期 Web 和桌面客户端可用，每日会话时长与操作频率设有上限（具体数值见产品内说明）。
[原文](https://openai.com/index/chatgpt-for-your-most-ambitious-work)

**GPT-Live — 新一代语音模型驱动自然对话**
• 功能介绍：GPT-Live 作为新语音模型，专为高度自然的人机语音交互设计，现已成为 ChatGPT Voice 的底层引擎，支持更低延迟、更丰富的情感表达和更准确的实时纠错。
• 效果：用户在语音对话中感受到几乎无等待的响应，模型能自主调整语速、语气，甚至处理中途打断或多轮背景噪音下的交互，逼近真人对话体验。
• 使用限制：集成在 ChatGPT Voice 中，对 Plus / Pro / Max / Team / Enterprise 用户开放，免费版可能限制单次时长或每日用量（推测）；API 端暂未同步开放实时语音。
[原文](https://openai.com/index/introducing-gpt-live)
