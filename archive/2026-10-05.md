**🅰️ Claude 产品更新详解**

**Claude Sonnet 5.5 上线（claude-sonnet-5-5）**
- 功能介绍: Claude Code v2.1.284 引入 **Claude Sonnet 5.5**,成为 Anthropic API 上新的默认 Sonnet 模型,支持 1M context。
- 效果: 定价 $2/$10 per Mtok,cache reads 仅 $0.20/Mtok,适合长上下文、大批量代码任务;相比旧 Sonnet 在同等价位下提供更强能力,是 API 用户升级默认模型的直接受益点。
- 使用限制: Anthropic API 默认 Sonnet 模型;Claude Code 内可直接调用。具体速率限制未在版本说明中列出(推测沿用 Sonnet 档位)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.284)

**Claude Mods 插件系统 + "You should know" 内置 mod**
- 功能介绍: Claude Code v2.1.287 新增 **Claude Mods**,允许插件修改更深层行为;同时推出内置 mod **"You should know"**,一个 side agent 会在后台观察并标记你或 Claude 可能遗漏的问题。
- 效果: 开发者可以深度定制 Claude Code 行为;"You should know" 相当于多一个实时审查者,适合长会话、复杂重构时防止遗漏关键约束或错误。
- 使用限制: Claude Code;启用命令 `/plugin enable cc-plugin-you-should-know@builtin`,需 first-party sessions 且开启 telemetry。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.287)

**Claude Code 多项小功能更新（v2.1.285–v2.1.289）**
- 功能介绍: 近一周连续发布 5 个版本,包括: `CLAUDE_CODE_DISABLE_WEB_FETCH` 环境变量关闭 WebFetch 工具;`claude --desktop` 打开桌面应用;`claude plugin configure` 查看/配置插件选项;`$.ui.selection()` 供 mods 获取最后选中的文本;内置 `gh api`;Ctrl+C 清空 prompt 后按 Up 可恢复草稿;agents view 新增 `n:` 过滤器;权限提示堆叠时显示 "2 of 5" 计数;修复了 deny/ask 规则在嵌套 shell 命令、symlink 文件、终端冻结等多个问题。
- 效果: 面向重度 Claude Code 用户的操作体验优化——更细粒度的网络访问控制、更顺手的 prompt 恢复、更直观的权限管理,以及 mods 开发者可读取用户选中文本做上下文增强。
- 使用限制: Claude Code(CLI / IDE 扩展);部分功能仅限 fullscreen mode 或特定平台(如 VSCode 的 symlink 修复)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.289)
