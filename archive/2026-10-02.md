**🅰️ Claude 产品更新详解**

**Claude Sonnet 5.5 上线**
- 功能介绍: **Claude Code v2.1.284** 新增 **claude-sonnet-5-5** 模型,现已成为 Anthropic API 上的默认 Sonnet 模型,支持 1M 上下文。
- 效果: 开发者无需改配置即可在 **Claude Code** 中默认使用新一代 Sonnet,长上下文任务(大型代码库、长文档)处理能力显著提升;缓存读取价格低至 $0.20/Mtok,适合高频迭代场景。
- 使用限制: Anthropic API 可用;输入 $2/Mtok、输出 $10/Mtok、缓存读取 $0.20/Mtok;通过 **Claude Code** 默认启用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.284)

**Claude Mods 插件系统**
- 功能介绍: **Claude Code v2.1.287** 新增 **Claude Mods**,允许插件修改更深层行为;内置首个 mod「You should know」,由一个 side agent 在后台观察并标记你和 Claude 可能遗漏的问题。
- 效果: 相当于给 **Claude Code** 加了一个"第二双眼睛",在长会话或复杂任务中主动提示风险与遗漏;插件机制让社区可以深度定制 Claude 的行为逻辑。
- 使用限制: **Claude Code**;「You should know」需通过 `/plugin enable cc-plugin-you-should-know@builtin` 开启,且仅限 first-party 会话且 telemetry 开启时可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.287)

**模型管控与网关增强**
- 功能介绍: **Claude Code v2.1.283** 新增 `availableModelsMatch` 托管设置(设为 "exact" 时仅允许指定模型版本,新版本需显式列入才可用)和 `deniedModels` 托管设置(显式封禁特定模型);新增 `x-claude-code-prompt-id` 网关提示头(需 `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` 开启)。
