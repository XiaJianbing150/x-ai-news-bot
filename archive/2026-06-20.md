🅰️ **Claude 产品更新详解**

**Claude Code v2.1.183 — 自动模式安全防护强化**
• 功能介绍：在自动模式下自动拦截破坏性 Git 操作（git reset --hard / checkout -- . / clean -fd / stash drop）和未授权的 git commit --amend，同时阻止未明确指定堆栈的 terraform destroy 等基础设施销毁命令；新增模型弃用或自动升级时的警告提示。
• 效果：防止 Agent 误删本地代码或修改非自己生成的提交，降低误操作风险，保护关键基础设施，让开发者在自动模式下更放心地交给 Claude Code 执行任务。
• 使用限制：所有 Claude Code 用户（Pro / Max / Team / Enterprise / API）均可使用，开启自动模式后自动生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.183)

**Claude Code v2.1.181 — 新增 /config 命令、沙盒 Apple Events 与推送抑制**
• 功能介绍：新增 /config key=value 语法，可在交互、-p 及 Remote Control 中直接修改任何设置；新增 sandbox.allowAppleEvents 选项，允许沙盒命令在 macOS 上发送 Apple Events；新增 CLAUDE_CLIENT_PRESENCE_FILE 环境变量，指向标记文件后可在机器前使用时自动抑制移动端推送通知；Bun 运行时升级至 1.4。
• 效果：无需退出会话即可快速调整 thinking 开关等参数，macOS 自动化工作流更顺畅，减少多端使用时的通知干扰。
• 使用限制：Claude Code 全平台，/config 和沙盒选项面向所有用户；推送抑制需设置环境变量，适用于 Pro / Max / Team / Enterprise / API 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.181)

**Claude Code v2.1.178 — 工具参数匹配权限与嵌套目录技能/Agent 优先级**
• 功能介绍：权限规则新增 Tool(param:value) 语法，支持通配符匹配工具输入参数，例如可配置 Agent(model:opus) 阻止 Opus 子 Agent；嵌套 .claude/skills 目录的技能现在会在操作对应文件时自动加载，名称冲突时显示为 <dir>:<name>；嵌套 .claude/ 目录下的 Agent、工作流、输出样式现在遵循就近优先原则，项目 Agent 可通过 /agents 在嵌套目录中使用。
• 效果：更精细的权限控制（例如按模型限制子 Agent 调用），多级项目结构中的技能和 Agent 不再互相覆盖，大型 monorepo 或多团队协作更易管理。
• 使用限制：Claude Code 全用户，技能与 Agent 优先级规则自动生效，权限新语法需手动配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.178)

**Claude Code v2.1.176 — 会话标题本地化、页脚链接徽章与 Bedrock 凭证缓存优化**
• 功能介绍：会话标题现在按对话语言自动生成，可通过 language 设置固定语言；新增 footerLinksRegexes 设置，支持在页脚行用正则匹配显示链接徽章；改善 Bedrock 凭证缓存，来自 awsCredentialExport 的凭证现在缓存至其过期时间，而非固定 1 小时。
• 效果：多语言用户获得更自然的会话列表，企业用户可通过页脚定制内部链接，AWS Bedrock 用户减少频繁重新授权。
• 使用限制：Claude Code 全用户，标题语言、页脚链接和 Bedrock 缓存均为可选设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.176)

**Claude Code v2.1.175 — 强制可用模型列表管理设置**
• 功能介绍：新增 enforceAvailableModels 管理设置，启用后 availableModels 允许列表同时约束 Default 模型（若 Default 解析为禁用的模型则回退至列表中的第一个模型），且用户或项目设置无法扩大管理的可用模型范围。
• 效果：企业管理员可以严格锁定组织内可用的模型，防止成员通过别名或本地配置使用未经批准的模型，强化合规与成本控制。
• 使用限制：面向 Team / Enterprise 管理员，在 managed settings 中配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.175)

**Claude Code 其他近期修复与改进（v2.1.174 / v2.1.173 / v2.1.179）**
• 功能介绍：修复 /model 选择器在不同计划下隐藏默认模型系列的问题，Opus 在 Max/Team Premium/Enterprise 中现可正确显示；去除 Fable 5 模型名称的多余 [1m] 后缀；修复 WSL2 下鼠标滚轮滚动异常、中流连接断开时界面卡死、沙盒 denyRead/allowRead 在大目录树中导致会话不可用等多个稳定性问题，并新增 wheelScrollAccelerationEnabled 设置用于禁用全屏滚轮加速。
• 效果：模型切换体验更准确，界面响应更流畅，连接中断不再丢失已有输出，大型代码库下的沙盒使用恢复正常。
• 使用限制：对所有 Claude Code 用户生效，wheelScrollAccelerationEnabled 为可选设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.174)
