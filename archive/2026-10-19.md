- 效果: 无人值守场景下避免长时间挂起;vim 用户编辑 prompt 更高效;mod 开发者可获得更丰富的输入控件

**Claude Code v2.1.300 — mod 装饰与 OpenTelemetry 缓存指标**
- 功能介绍: mod 的 prompt decorations 新增 **virtualText**(在输入框绘制的文本,不会进入草稿或提交的 prompt);OpenTelemetry api_request 事件新增 **cache_creation_5m_tokens** 和 **cache_creation_1h_tokens**,按生命周期拆分缓存写入;mod 新增 **$.ui.view({ agentId })** 可在主视图展示 agent 转录;mod 的 Text 新增 dir 属性支持从右到左文本
- 效果: mod 开发者可做更丰富的 UI 提示;可观测性更细粒度;agent 转录查看更灵活

**Claude Code v2.1.299 — 闲置压缩 + 文件提及控制**
- 功能介绍: 新增 **CLAUDE_CODE_DISABLE_FILE_MENTIONS** 环境变量,Claude 获取 @ 文件提及的路径后用文件工具读取,而非直接拿内容;终端新增 **idle compaction**:200K+ token 的对话闲置约 54 分钟后,在 1 小时 prompt cache 过期前自动压缩,避免下一条消息重新处理全部内容;新增 **CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS** 调整 200K 阈值
- 效果: 长对话闲置后继续使用时响应更快、成本更低;@ 文件提及行为更可控
