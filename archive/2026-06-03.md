🅰️ **Claude 产品更新详解**

**Claude Opus 4.8 发布**
• 功能介绍：Anthropic 正式推出旗舰模型 **Claude Opus 4.8**，在深度推理、复杂任务处理与代码生成方面实现重大升级。首次引入动态工作流支持，允许模型在后台协调数十至上百个 agent 并行完成任务。
• 效果：开发者与研究者可直接处理此前需要多次拆解的长链推理任务，复杂代码库重构与长文档分析效率显著提升；Claude Code 中默认以高 effort 模式运行，支持 /effort xhigh 提升极致任务表现。
• 使用限制：面向 Claude.ai（Pro/Max/Team/Enterprise）、API 及 Claude Code（v2.1.154+）用户；动态工作流能力由 Claude Code 调度，消耗对应 API 配额；Fast mode 在 Opus 4.8 上为标准费率的 2 倍，提供 2.5 倍速度。
[原文](https://www.anthropic.com/news/claude-opus-4-8)

**Claude Code v2.1.152–v2.1.161 综合更新**
• 功能介绍：一周内连续多个版本带来 Opus 4.8 深度适配、动态工作流控制（/workflows 查看运行状态）、本地技能目录自动加载插件（.claude/skills）、安全写入提示（shell 启动文件、.npmrc 等构建配置）、/code-review --fix 自动应用审查建议、Auto mode 扩展至 Bedrock/Vertex/Foundry 等平台，以及 OTEL 指标增强与并行工具调用容错改进。
• 效果：开发者可在多环境（Bedrock、Vertex、Foundry）启用 Auto mode 自动化编程，通过插件系统无痛复用技能，并减少误操作带来的安全风险；/code-review --fix 能直接将审查建议落地到工作树，提高代码质量闭环效率。
• 使用限制：所有更新通过 Claude Code 包分发，部分功能（如 Auto mode 在云平台）需设置环境变量 CLAUDE_CODE_ENABLE_AUTO_MODE=1；动态工作流和插件系统依赖 Claude Code 运行环境，需 Opus 4.7/4.8 模型支持。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.154)

**OpenAI 前沿模型与 Codex 正式登陆 AWS**
• 功能介绍：OpenAI 宣布其 **前沿模型**（含 GPT‑5 系列）和 **Codex** 在 AWS 上正式普遍可用，企业可通过 AWS Marketplace 和控制台直接调用，无需跳离 AWS 环境。
• 效果：使用 AWS 的企业能以现有采购流程、安全控制与基础设施集成 OpenAI 能力，缩短从评估到生产的周期；金融机构、医疗等受监管行业可更便捷地在私有网络中部署 GPT 能力。
• 使用限制：通过 AWS 账户订阅，具体模型可用性可能受区域限制；计费纳入 AWS 账单体系，同时受 OpenAI 与 AWS 双重合规约束。
