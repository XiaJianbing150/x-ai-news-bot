🅰️ **Claude 产品更新详解**

**Focus view（VSCode 专注视图）**
• 功能介绍: 在 Claude Code 的 VSCode 扩展中新增 Focus view，切换后隐藏工具执行的“流水账”，改为展示每轮对话的可折叠摘要，并带有实时工具运行指示器。
• 效果: 开发者可以避开频繁滚动的工具输出，以更清爽的界面追踪对话进展，适合需要关注逻辑而非操作的场景。
• 使用限制: Claude Code VSCode 扩展，快捷键 Ctrl+Alt+F（或命令面板），推测面向所有 Claude Code 用户，无需额外订阅。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)

**沙箱凭据文件 mask 模式**
• 功能介绍: 在 Linux/WSL 上新增 mode: "mask" 选项，沙箱内命令读取凭据文件的“哨兵副本”，沙箱代理在外发时替换为真实值；支持全文件或通过正则提取部分字段。
• 效果: 使用沙箱执行敏感操作时，凭据不会直接暴露给沙箱内的代码，提升安全隔离性。
• 使用限制: Claude Code 沙箱功能，需在设置中配置，推测适用于 Team/Enterprise 等高安全需求环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)

**/teleport 会话迁移提示**
• 功能介绍: 云端会话中新增 /teleport 提示，告知用户可以通过 claude --teleport <session id> 将云端工作接续到本地 Claude Code。
• 效果: 用户在网页/移动端启动任务后，可无缝切换至本地终端继续，适合需要更强终端控制或本地文件访问的场景。
• 使用限制: Team、Enterprise 计划的云端会话，本地需安装 Claude Code 并登录。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)

**自托管运行器（Self-hosted runner）**
• 功能介绍: 新增 claude self-hosted-runner 命令，可将用户自己的机器或容器注册为 Claude Code web、移动和桌面会话的执行节点。
• 效果: 企业用户可以在内部基础设施上运行 Claude Code 工作负载，满足合规与数据驻留需求，同时享受多云端的统一体验。
• 使用限制: Team 和 Enterprise 计划专属，需配置自托管运行器并接入 Anthropic 平台。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)

**归档插件源（Archive plugin source）**
• 功能介绍: 支持通过 HTTPS 下载 .zip 包安装插件，无需依赖 git 或 npm，并可附加 SHA-256 校验值进行完整性验证。
• 效果: 简化了离线环境或受限网络中的插件分发，提升了供应链安全性。
• 使用限制: Claude Code 2.1.224 及以上，推测所有用户可用，但插件管理需符合团队设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)

**网关用量限制支持**
• 功能介绍: 用量警告中显示网关配置的限额、重置时间及管理员消息，帮助团队清晰掌握预算余量。
• 效果: 管理员设置网关限额后，开发者在接近或达到限额时会收到明确通知，避免意外停机或超额消费。
• 使用限制: 需配合 2.1.225 及以上版本的网关，适用 Enterprise 等集中管理计费的环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.225)

**工作区信任提示**
• 功能介绍: 在不受信目录中启动 claude agents 时，弹出工作区信任提示，行为与 claude 命令保持一致。
• 效果: 防止代理在未确认的环境下自动执行，增强操作安全性。
• 使用限制: Claude Code 2.1.225 及以上，所有用户均受影响。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.225)
