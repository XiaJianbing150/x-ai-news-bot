**🅰️ Claude 产品更新详解**

**Claude Sonnet 5.5 上线**
- 功能介绍: **Claude Code** v2.1.284 引入 **claude-sonnet-5-5**,现已成为 Anthropic API 上的默认 Sonnet 模型,拥有 1M 上下文窗口。
- 效果: 定价为每百万 token 输入 $2 / 输出 $10,缓存读取仅 $0.20/Mtok。相比前代 Sonnet,在同等价位下提供更大的上下文和更新的能力,适合长代码库理解和复杂项目维护。
- 使用限制: 通过 **Anthropic API** 和 **Claude Code** 可用;作为默认 Sonnet 模型自动生效,无需额外配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.284)

**Claude Mods 插件系统**
- 功能介绍: **Claude Code** v2.1.287 新增 **Claude Mods**,允许插件修改更深层的行为;同时内置一个名为 **You should know** 的 mod,由 side agent 监视你的会话并标记你或 Claude 可能遗漏的问题。
- 效果: 开发者可以深度定制 Claude Code 的工作方式;内置 mod 相当于多了一个"第二双眼睛",在长时间编码任务中帮助发现遗漏的边界情况或潜在错误。
- 使用限制: 通过 **Claude Code** 使用。内置 mod 需在开启遥测的一方会话中用 `/plugin enable cc-plugin-you-should-know@builtin` 启用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.287)

**Claude Code 桌面应用入口**
- 功能介绍: **Claude Code** v2.1.285 新增 `claude --desktop` 命令,可在当前目录打开 **Claude 桌面应用**,或通过 `--continue` / `--resume ` 在指定会话中打开。
- 效果: 让习惯桌面 GUI 的用户可以从终端无缝切换到桌面应用继续工作,兼顾 CLI 的灵活性和桌面端的可视化体验。
- 使用限制: **Claude Code** CLI,需已安装 Claude 桌面应用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.285)

**WebFetch 禁用开关**
- 功能介绍: **Claude Code** v2.1.285 新增环境变量 `CLAUDE_CODE_DISABLE_WEB_FETCH`,可完全关闭 WebFetch 工具。
- 效果: 适用于对网络访问有严格合规要求的企业环境,或希望 Claude 只基于本地代码库工作的场景。
- 使用限制: **Claude Code**,通过环境变量配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.285)

**插件配置命令增强**
- 功能介绍: **Claude Code** v2.1.285 新增 `claude plugin configure ` 查看插件选项及未设置项,并支持通过 `--values-stdin` 从标准输入保存新值;安装时可用 `.=` 语法直接传配置。
- 效果: 简化了插件的批量配置和自动化部署流程,尤其适合团队统一分发插件配置。
- 使用限制: **Claude Code** CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.285)

**模型管控设置**
- 功能介绍: **Claude Code** v2.1.283 新增 `availableModelsMatch` 托管设置(设为 "exact" 时只允许指定版本)和 `deniedModels` 设置(可屏蔽特定模型)。
- 效果: 企业管理员可以精确控制团队可用哪些模型版本,新版本发布后默认保持锁定,直到管理员明确放行。
- 使用限制: **Claude Code** 托管环境(managed settings)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.283)

**权限提示计数与鼠标支持**
- 功能介绍: **Claude Code** v2.1.286 在多个权限请求堆叠时显示"2 of 5"计数;全屏模式下列表的"N more"行支持鼠标点击跳转。
- 效果: 权限审批更直观,长列表导航更快捷,减少键盘操作负担。
- 使用限制: **Claude Code** 全屏模式。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.286)

**UI 选区 API 与命令恢复**
- 功能介绍: **Claude Code** v2.1.288 为 mods 新增 `$.ui.selection()` 返回全屏模式下最后选中的文本;Ctrl+C 清空的提示词可通过按上箭头恢复草稿。
- 效果: 插件开发者可以基于用户选中的代码片段做上下文感知操作;误清空提示词不再需要重写。
- 使用限制: **Claude Code** 全屏模式及 mods 开发。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.288)
