🅰️ **Claude 产品更新详解**

**Claude Code v2.1.139 — Agent View 与 /goal 命令发布**
• 功能介绍: 新增 Agent View (Research Preview) 统一面板,一览所有 Claude Code 会话(运行中/等待输入/已完成);新增 /goal 命令,设定完成条件后 Claude 会跨轮次持续工作直到达成,并实时显示耗时/轮次/Token 使用量;新增 /scroll-speed 命令调节鼠标滚轮速度。
• 效果: 多会话管理从分散走向集中,适合同时跑多个 agent 任务的开发者;/goal 让 Claude Code 从单轮辅助升级为持续执行的"目标导向 agent",类似 IDE 里的持续运行任务,自动推进工作流;/scroll-speed 改善终端内长输出翻阅体验。
• 使用限制: Claude Code (终端),agent view 标记为 Research Preview;支持交互模式、-p 模式和 Remote Control。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.139)

**Claude Code v2.1.140 — Agent 匹配优化与 Bug 修复**
• 功能介绍: Agent tool 的 subagent_type 匹配改为大小写和分隔符不敏感(如 "Code Reviewer" 自动匹配 code-reviewer);修复 /goal 在特定 hook 设置下静默挂起的问题;修复符号链接 settings 文件导致的误触 ConfigChange hook 热重载问题。
• 效果: 提升 agent 配置的容错率,开发者不需要记精确名称;/goal 可靠性提升,settings 热重载更稳定。
• 使用限制: Claude Code 通用更新。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.140)

**Claude Code v2.1.141 — Hook 增强与环境变量新增**
