**Claude Sonnet 5 正式发布**
• 功能介绍：新一代前沿模型 **Claude Sonnet 5** 正式推出，在编程、智能体任务和大规模专业工作中达到前沿性能。配合 **Claude Code v2.1.197**，Sonnet 5 成为该工具中的默认模型，原生支持 1M token 上下文窗口，到 8 月 31 日前享受促销价 $2/$10 每百万 token（输入/输出）。同时 v2.1.201 已移除了 Sonnet 5 会话中的 harness 提醒机制，使交互更干净。
• 效果：开发者可直接在 **Claude Code** 中用上更强大的编程模型，长上下文可一次性处理大型代码库或完整项目文档；代理任务中上下文保持能力增强，减少遗忘；促销定价大幅降低大规模使用的成本。
• 使用限制：已向所有用户开放。在 **Claude Code** 中默认启用（需更新至 v2.1.197+）；通过 API 也可调用，支持 **Max、Team、Enterprise** 档位及按量计费。促销定价持续至 2026‑08‑31，之后恢复标准价格。（推测）

• 使用限制：面向安全社区和合作伙伴，Fable 5 重新部署后由授权渠道访问；框架文档公开可阅。并非终端用户 ChatGPT/Claude 直接使用，属于安全基础设施层面。

**Claude Science：面向科学家的 AI 工作台**
• 功能介绍：**Claude Science** 全新上线，这是一个可定制的科学工作台应用，集成研究者常用的工具和软件包，产出可审计的工件，并提供灵活的计算资源访问。它让科学家能够将数据分析、建模、文献整合等工作流直接嵌入 Claude 中运行。
• 效果：研究人员无需在多个工具间切换，可借助 Claude Science 端到端地完成实验设计、数据处理、结果复现及报告撰写，所有操作留有可审计痕迹，便于学术合规与协作。
• 使用限制：目前面向科研团队和企业客户，需要通过 Anthropic 开通；可能采用 **Team/Enterprise** 或特定学术合作通道。（推测）

**Claude Code 多项体验与工作流更新**
• 功能介绍：近期 **Claude Code**（v2.1.198‑v2.1.204）密集集成了多项新特性：子代理默认后台运行（v2.1.198），完成后主动通知，并新增 `agent_needs_input`/`agent_completed` 钩子；新增 **/dataviz** 技能，提供图表和仪表板设计指导，并附带可运行的颜色调色板验证器（v2.1.198）；**Chrome 环境中的 Claude Code** 全面可用（v2.1.198）；在 `/config` 中可设置动态工作流规模（小/中/大代理数量，v2.1.202）；支持斜杠技能叠加调用（最多 5 个，v2.1.199）；手动权限模式下状态栏增加灰色 ⏸ 标识（v2.1.203）；登录即将过期时显示警告（v2.1.203）；以及 AskUserQuestion 弹窗默认不再自动继续，默认权限模式改为 Manual，支持组织默认模型设置（v2.1.200, v2.1.196）。还修复了 macOS 后台会话卡顿、SSL 错误提示优化等问题。
• 效果：开发者可获得更流畅的后台代理体验，多个子任务可并行执行，减少等待；数据可视化技能让分析结果更直观；权限模式的改进和状态可见性提升让操作更安全可控；动态工作流建议有助于资源规划；组织管理员可通过控制台统一配置模型。
• 使用限制：全部更新已在 **Claude Code** v2.1.204 中默认生效，支持 macOS/Windows/Linux 终端及 VS Code、JetBrains 扩展。组织模型设置需在 org console 中由管理员配置。Chrome 版为一般可用。无需额外等候名单，更新客户端即可。
