🅰️ **Claude 产品更新详解**

**Reflect with Claude / 使用反思功能**
• 功能介绍：Claude 新增“反思”体验，用户可查看自己与 Claude 交互的总结与趋势，回顾提问方式、使用习惯等。
• 效果：帮助用户更了解自身思维模式，优化后续与 Claude 的协作；不是功能性的工具，而是一种“元认知”辅助。
• 使用限制：推测当前在 claude.ai 网页端逐步推送，所有登录用户可用（免费/Pro/Max/Team/Enterprise）。
[原文](https://www.anthropic.com/news/reflect-with-claude)

**Claude Code v2.1.198：Subagents 默认后台运行、Claude in Chrome 全面上线、/dataviz 技能**
• 功能介绍：子代理（subagent）执行任务时现在默认在后台运行，Claude 主会话可继续其他工作；Claude in Chrome 结束逐步灰度，向所有用户开放；新增 /dataviz 技能，提供图表与仪表板设计指导，内含可运行的颜色调色板验证器；后台代理完成或需要输入时触发 Notification hook。
• 效果：多任务并行效率大幅提升，不会因子任务阻塞主流程；浏览器中可直接使用 Claude 上下文辅助；数据可视化从设计到颜色校验均可由 Claude 一句指令完成。
• 使用限制：Claude Code 终端/VS Code/JetBrains 插件，版本 ≥2.1.198。Chrome 版本需在 Chrome 网上应用店安装。需要 Claude 订阅（Pro/Max/Team/Enterprise 或 API key），无额外等候名单。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.198)

**Claude Code v2.1.199：堆叠斜杠技能、SSL 错误快速提示、流式响应保持已输出部分**
• 功能介绍：现在可以在一行中依次调用多个斜杠技能（如 /skill-a /skill-b …），最多同时加载 5 个技能；TLS 检查代理或缺少 NODE_EXTRA_CA_CERTS 导致的 SSL 证书错误不再消耗重试次数，而是立即给出修复引导；API 返回中断错误时，已产生的流式输出会被保留，不再全部丢弃。
• 效果：组合多个技能模板更顺手；网络配置问题一目了然，不需无端等待；长输出中途报错也不再浪费已生成内容，减少 token 浪费。
• 使用限制：Claude Code ≥v2.1.199，API 模式同样受益。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.199)

**Claude Code v2.1.200：权限确认默认手动、AskUserQuestion 不自动继续**
• 功能介绍：默认权限模式改为“Manual”，用户需显式同意每项操作；AskUserQuestion 对话框默认不再自动继续，可以在 /config 中设置空闲超时；修复了因 claude.json 配置参数为非数组值导致的崩溃等问题。
• 效果：安全性优先，避免无意识自动批准；提问交互更可控，防止误操作跳过确认。
• 使用限制：Claude Code ≥v2.1.200，新安装/新建会话即应用。可手动切回自动模式。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.200)

**Claude Code v2.1.201：Sonnet 5 会话清理系统提醒**
• 功能介绍：使用 Claude Sonnet 5 模型时，不再在对话中间插入系统角色的“安全提醒”提示。
• 效果：对话更干净流畅，减少打断，特别适合长文档生成或持续编码。
• 使用限制：Claude Code ≥v2.1.201，当底层模型为 Sonnet 5 时生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.201)

**Claude Code v2.1.202：动态工作流规模设置、OTel 属性增强**
• 功能介绍：在 /config 中新增“Dynamic workflow size”（小/中/大代理数）设置，作为工作流规模的指导意见（非硬性限制）；工作流产出的 telemetry 中加入 workflow.run_id 和 workflow.name 两个 OpenTelemetry 属性。
• 效果：用户可根据任务复杂度调整并行能力，避免过度消耗；OTel 数据中可按工作流重构活动，便于监控与审计。
• 使用限制：Claude Code ≥v2.1.202。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.202)

**Claude Code v2.1.203：登录过期提醒、手动模式状态徽章、MCP 工作目录通知**
• 功能介绍：当登录凭证即将过期时给出警告；底部状态栏手动模式时新增灰色 ⏸ 徽章，当前模式随时可见；会话的附加工作目录会推送到 MCP roots/list，并发送通知。
• 效果：避免后台会话因登录过期中断；权限状态一目了然；MCP 服务器可感知工作目录变化，集成更顺滑。
• 使用限制：Claude Code ≥v2.1.203，使用 MCP 功能需相关服务器支持。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.203)

**Claude Code v2.1.204：修复 headless 会话钩子流传输**
• 功能介绍：修复非交互式（headless）会话中 SessionStart 钩子事件无法流式输出的问题，防止远程工作进程在钩子执行期间被误判为空闲而终止。
• 效果：自动化/CI 场景下钩子稳定运行，不会因无输出被回收。
• 使用限制：Claude Code ≥v2.1.204。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.204)

**Claude Code v2.1.205：会话文件防篡改、JSON Schema 及消息丢失修复**
• 功能介绍：新增 auto mode 规则禁止篡改会话转录文件；--json-schema 因无效 schema 或使用 format 关键字而被拒绝时，现在会立即报错，不再静默输出非结构化内容；修复了达到 --max-turns 限制时发送的消息丢失等问题。
• 效果：提升 auto mode 执行的审计可信度；JSON 结构化输出更加可靠；长会话控制更精准。
• 使用限制：Claude Code ≥v2.1.205。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.205)

**Claude Code v2.1.206：/cd 路径建议、/doctor 检查 CLAUDE.md、自动推送**
• 功能介绍：/cd 命令现在提供目录路径自动建议，与 /add-dir 行为一致；新增 /doctor 检查，可建议修剪检入的 CLAUDE.md 文件内容；/commit-push-pr 在仓库配置了 push remote（或仅有一个远程仓库）时，自动允许 git push。
• 效果：导航更快；避免 CLAUDE.md 冗余内容膨胀；提交-推送流程更自动化。
• 使用限制：Claude Code ≥v2.1.206；/commit-push-pr 的自动推送需仓库设置满足条件。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.206)

**Claude Code v2.1.207：Auto mode 免配置覆盖主流云平台、终端性能修复**
• 功能介绍：Auto mode 在 Amazon Bedrock、Google Cloud Vertex AI、Palantir Foundry 上不再需要设置 CLAUDE_CODE_ENABLE_AUTO_MODE 环境变量即可直接使用；修复了流式响应包含长列表/表格/代码块时终端冻结与按键滞后；修复了远程托管设置在非交互模式下静默跳过安全同意对话框的问题。
• 效果：更多云平台开箱即用 Auto mode；长输出体验流畅；远程配置安全管控合规。
• 使用限制：Claude Code ≥v2.1.207，使用对应平台插件。

**ChatGPT Work：可跨应用行动的长时间代理**
• 功能介绍：ChatGPT Work 是一款能直接操作用户应用和文件的代理（agent），可跟随一个项目运行数小时，从目标出发自主完成工作流。
• 效果：适合跨 PDF、Sheets、Notion 等多工具的调研、报表生成、代码重构等持续任务，无需人力看管。
• 使用限制：逐步向 ChatGPT Pro 和 Team 用户推送，后续开放至 Enterprise；初期在 Web 和桌面应用可用。

• 效果：响应更快、更自然，支持更复杂的情感与语调变化，接近真人对话流畅度。
• 使用限制：ChatGPT 移动端/桌面端，需 Plus/Pro/Team/Enterprise 订阅（推测），逐步发布中。
