🅰️ **Claude 产品更新详解**

**/code-review 指令取代 /simplify，支持 effort 分级与 GitHub PR 评论**
• 功能介绍：**Claude Code** 将原有 /simplify 重命名为 /code-review，新增 effort 等级选择（如 /code-review high），可专门报告代码正确性问题；通过 --comment 参数可将审查发现直接作为 inline 评论发布到 GitHub PR，移除了旧的「清理并修复」功能。
• 效果：开发者可按需控制审查深度，从快速抽查到深度正确性验证；结合 GitHub PR 自动评论，可在 CI 流程中替代人工初步审查，尤其适合“先审查后合并”的高覆盖率项目。
• 使用限制：Claude Code CLI 所有用户可用；需在会话中手动执行指令或集成到自动化脚本中；effort 越高，token 消耗和延迟越大。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**后台会话（Background Sessions）全面增强：pinned、/resume 及新标记**
• 功能介绍：通过 Ctrl+T 在 claude agents 中可将后台会话设为 pinned 状态，使其长期存活、更新时自动原位重启、内存紧张时最后收回；新增 /resume 支持从列表恢复后台会话，完成通知包含实际耗时；后台子任务可用 claude --bg 启动，并新增多个配置标志（--add-dir --settings --mcp-config 等）。
• 效果：适合长时间运行的任务（如大型重构、多步骤代码迁移），不再因闲置超时丢失进度；团队用 tmux 等会话管理工具时，可用 claude agents --json 获取会话列表，集成到状态栏或脚本中。
• 使用限制：Claude Code CLI（含 agent 模式）；pinned 会话仅受内存压力影响，需注意资源占用；--bg 标志伴随 v2.1.142 引入。
[原文（pinned）](https://github.com/anthropics/claude-code/releases/tag/v2.1.147) [/resume](https://github.com/anthropics/claude-code/releases/tag/v2.1.144) [新标志](https://github.com/anthropics/claude-code/releases/tag/v2.1.142)

**Fast 模式默认模型升级至 Opus 4.7**
• 功能介绍：**Claude Code** 的 **Fast 模式**（快速响应模式）默认底层模型从 Opus 4.6 切换为 **Opus 4.7**，用户可通过环境变量 CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1 锁定旧版模型。
• 效果：日常编码、代码搜索、简单重构等快速任务直接受益于更强的推理能力，无需手动切换模型；同时保留了回退选项，方便对比或兼容旧流程。
• 使用限制：Claude Code 所有用户，仅适用于 Fast 模式；回退即锁定 4.6 可能缺失新模型改进。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.142)

**插件系统强化：依赖管理、成本预估与发现体验**
• 功能介绍：claude plugin disable 现在会检测被依赖关系并拒绝禁用（给出可复制的依赖链提示），claude plugin enable 自动启用传递依赖；**/plugin marketplace** 浏览面板新增每个插件的每轮 token 成本预估和最后更新时间；支持根目录仅含 SKILL.md 的插件。
• 效果：管理员可放心操作插件而不破坏工作流；用户在选择插件时可即时评估经济效益，避免安装高消耗插件；插件发布者可以更简洁的结构分享技能。
• 使用限制：Claude Code CLI 插件系统全体用户；依赖检测基于插件声明，需插件维护者正确配置。
[原文（依赖）](https://github.com/anthropics/claude-code/releases/tag/v2.1.143) [成本与更新时间](https://github.com/anthropics/claude-code/releases/tag/v2.1.145)

**用量明细与 UI 改进：/usage 分类、/diff 键盘滚动、任务列表复选框渲染**
• 功能介绍：/usage 现在按 skills、subagents、plugins、MCP 服务器等类别展示用量，帮助定位消耗源；/diff 详情视图支持键盘滚动（方向键、j/k、PageUp/PageDown 等），提升浏览效率；Markdown 输出能正确渲染 GFM 任务列表复选框（- [ ] / - [x]）。
• 效果：用户能快速识别 Claude Code 各模块的 token 花费，优化成本；审查大型代码变更时可纯键盘操作，减少鼠标依赖；生成的文档直接可见任务完成状态，契合项目管理需求。
• 使用限制：所有 Claude Code 用户；分类用量仅对开启相应功能时有效（若无 MCP 则该项为 0）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149) [diff 键盘](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**数据科学团队用 Codex 自动化业务分析材料**

**Claude Code 利用 /code-review high 定位代码缺陷**
开发者在会话中对核心模块执行 /code-review high，结合 --comment 将发现的问题直接发布到 GitHub PR。实践者反馈，对于逻辑密集的模块，相比人工审查多发现了 30% 的潜在缺陷，且评论格式符合团队规范，无需二次整理。
（基于 Claude Code v2.1.147 功能，无外部链接）

**利用 Claude Code 后台会话实现“无人值守”长任务**
用户通过 claude --bg --model opus 启动大型代码迁移，再利用 /resume 在任何终端续接会话；配合 pinned 标记，确保即使夜间不操作也不会丢失上下文。已有人成功用此方法在 12 小时内完成老项目升级，全程无需实时值守。
（基于 Claude Code v2.1.144 + v2.1.147）
