**Claude Code v2.1.269:插件评测与输出样式切换**
- 功能介绍: 新增 **claude plugin eval** 命令,可对插件运行评测套件并输出可复现的 JSON + HTML 评分报告;新增 **/output-style [name]** 命令,可在 Remote Control、云端及 headless 会话中列出并切换输出样式;当 Bash 工具处理文件编辑时,结果中会附带被修改文件的 diff。
- 效果: 插件开发者能拿到标准化评分来验证插件质量;远程和无人值守场景下也能灵活调整 Claude 的回复风格;开发者可直接在工具结果里看到 Bash 命令改动了哪些文件,减少手动比对。
- 使用限制: Claude Code 全平台,需升级至 v2.1.269;插件评测与输出样式切换对所有 Claude Code 用户开放(推测)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.269)

- 效果: 企业管理员能让 /cost 和遥测数据与实际计费精确对齐,消除费率不一致的困惑;公网暴露风险会被主动提示,降低误配置导致的安全隐患。
