**📰 Anthropic & OpenAI 速报 · 2026-08-09 Sunday**

过去一周，**Claude Code** 连续发布 6 个版本，带来自托管运行器、Focus view、Gateway 消费限制提示等一批新功能；**OpenAI** 则推出 GPT‑5.6 Sol 升级、Luna 免费开放以及教育插件、连续语音 **GPT‑Live** 等多项产品更新。

🅰️ **Claude 产品更新详解**

**Claude Code v2.1.226 · 稳定性修复**
• 功能介绍：修复若干错误，提升整体可靠性。
• 效果：减少意外中断或异常，日常使用更稳定。
• 使用限制：所有 Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.226)

**Gateway spend‑limit 提示增强**
• 功能介绍：到达网关设置的消费上限后，提示信息会显示额度上限、重置时间以及运营方消息（需网关版本 2.1.225）。
• 效果：用户和团队能清晰知道何时恢复用量，避免盲目等待。
• 使用限制：Claude Code，需要配合新版网关（推测 Team/Enterprise 计划）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.225)

**工作区信任提示与 OAuth 修复**
• 功能介绍：对新目录启动 `claude agents` 时弹出信任提示（对齐 `claude` 行为）；修复了短暂的 401 错误导致长期令牌被短期令牌覆盖、无头会话中断的问题；修复 MCP OAuth 相关问题。
• 效果：增强安全性，避免未信任目录执行代码；保障长时间自动化会话的稳定性。
• 使用限制：Claude Code，所有用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.225)

**自托管运行器（Self‑Hosted Runner）**
• 功能介绍：新增 `claude self-hosted-runner`，可将自有机器或容器作为 Claude Code Web、移动端、桌面端的运行环境。
• 效果：团队可以在私有基础设施上执行工作负载，满足数据驻留与合规需求。
• 使用限制：Claude Code，Team 与 Enterprise 计划。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)

**从 HTTPS 安装插件**
• 功能介绍：支持通过 ZIP + HTTPS 安装插件，无需 Git 或 npm，可选 SHA‑256 校验。
• 效果：简化插件分发，在企业内网或受限环境中更易部署。
• 使用限制：Claude Code，所有用户（推测）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)

**指令变更确认与 Bedrock 区域前缀**
• 功能介绍：当粘贴内容因源不可用而会修改命令文本时，增加“取消并确认”步骤；新增 `ANTHROPIC_BEDROCK_REGION_PREFIX` 环境变量用于 Bedrock 集成。
• 效果：防止意外修改重要命令，方便指定 Bedrock 区域。
• 使用限制：Claude Code，所有用户；Bedrock 环境变量需使用 Amazon Bedrock 后端（推测 Team/Enterprise 或 API 用户）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)

**市场仓库通配符与受限模型警告**
• 功能介绍：新增 `owner/*` 通配符，可一次允许或禁止 GitHub 组织下所有市场仓库；当工作流代理、复刻技能等请求的子代理模型受限时显示警告。
• 效果：简化市场管理策略，明确模型降级运行情况。
• 使用限制：Claude Code，管理员设置（推测 Team/Enterprise）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)

**/teleport 云会话本地续接**
• 功能介绍：在云会话中新增 `/teleport` 提示，显示如何使用 `claude --teleport ` 将远程会话拉回本地继续。
• 效果：无缝切换工作环境，避免上下文丢失。
• 使用限制：Claude Code，所有会话类型。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)

**会话隔离与自动钩子修复**
• 功能介绍：修复工作树隔离会话可对主检点执行破坏性 Git 操作的问题；修复 PreToolUse 自动允许钩子在后台代理任务（摘要、压缩、重命名）中绕过工具限制的问题；修复 /usage-credits 请求被驳回后重复提示的显示错误。
• 效果：消除安全漏洞，确保权限控制在所有任务类型中一致生效。
• 使用限制：Claude Code，所有用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.222)

**VSCode Focus view**
• 功能介绍：新增聊天菜单中可切换的 Focus view，将工具执行细节折叠为每轮摘要，仅显示实时运行工具指示器，快捷键 `Ctrl+Alt+F` 或命令面板唤起。
• 效果：减少干扰，专注对话内容，适合需要清洁界面的开发者。
• 使用限制：Claude Code VSCode 扩展，所有用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)

**沙箱凭据掩码模式**
• 功能介绍：Linux/WSL 上新增 `mode: "mask"`，沙箱命令读取哨兵副本，仅代理出口时用真实凭据替换；macOS 文件映射机制类似。
• 效果：在沙箱内安全使用凭据，避免明文泄露。
• 使用限制：Claude Code，沙箱场景（Linux/WSL/macOS）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)
