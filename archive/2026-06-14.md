🅰️ **Claude 产品更新详解**

**Claude Fable 5 模型发布**
• 功能介绍: Anthropic 发布了新模型 Claude Fable 5,这是一款 Mythos 级模型,被认为是其有史以来能力最强的公开发布模型。Claude Code v2.1.170 版本开始支持该模型,Fable 5 默认提供 1M token 上下文窗口。
• 效果: 任何超出此前所有公开发布模型的能力,用于一般用途,在复杂代码生成、长文本理解和推理等任务上体验显著提升。
• 使用限制: 通过 Claude Code 或 API 使用。需更新至 v2.1.170 及以上版本。Fable 5 是公开发布,但可能有速率或配额限制 (推测)。
[原文](https://www.anthropic.com/news/claude-fable-5-mythos-5)

**Claude Code v2.1.172: 子代理深度扩展**
• 功能介绍: 子代理 (Sub-agents) 现在可以生成它们自己的子代理,目前支持最多 5 层嵌套深度。这允许 Claude Code 处理更大规模和更分层的编程任务。
• 效果: 用户可以处理以前因任务结构过于复杂而难以完成的软件工程工作,通过多级并行工作流提高整体效率。
• 使用限制: Claude Code。为 Max/Team Premium/Enterprise 计划提供更强的并行处理能力 (推测)。深层嵌套可能消耗更多 token 和用量。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.172)

**Claude Code v2.1.169: 安全模式与工作目录迁移**
• 功能介绍: 新增 --safe-mode 启动标志,开启后禁用所有自定义项(CLAUDE.md、插件、技能、钩子、MCP 服务器),用于故障排查;新增 /cd 命令,可以在会话中途将工作目录迁移到新位置而不中断提示缓存。
• 效果: 快速诊断启动或运行问题,排查自定义项导致的异常;在不丢失对话上下文的前提下灵活切换项目目录。
• 使用限制: Claude Code,适用于所有用户。--safe-mode 也支持通过环境变量 CLAUDE_CODE_SAFE_MODE 设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)

**Claude Code v2.1.175: 模型允许列表收紧**
• 功能介绍: 新增 enforceAvailableModels 托管设置,启用后 availableModels 白名单也会限制默认模型;如果默认模型在白名单中被禁止,系统会自动回退到白名单中允许的第一个模型,用户或项目设置不能再扩大白名单范围。
• 效果: 为企业管理员提供更严格的模型使用管控,防止团队成员通过修改设置使用组织未批准的模型。
• 使用限制: Claude Code,主要面向 Team/Enterprise 的托管环境,用于管理安全策略。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.175)

**Claude Code v2.1.174: 模型选择器完善**
• 功能介绍: 新增 wheelScrollAccelerationEnabled 设置用于禁用全屏模式下的鼠标滚轮加速;修正 /model 选择器内默认模型不可见的问题,现在 Opus 在 Max/Team Premium/Enterprise 计划中显示为单独行,修复了硬编码的 Sonnet 版本标签和 Fable 5 非活动/无信用提示等问题。
• 效果: 改善全屏模式下的列表浏览体验;确保用户能看到并选择所有实际可用的模型,避免界面层面的混淆。
• 使用限制: Claude Code,所有版本。管理模型可见性的设置主要用于团队/企业环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.174)

**Claude Code v2.1.176: 会话标题本地化与 Bedrock 凭证缓存**
• 功能介绍: 会话标题现在会根据对话语言自动生成;可设置 footerLinksRegexes 以通过正则匹配在底部行显示链接 badge;改善了 Amazon Bedrock 凭证缓存,从固定 1 小时过期改为使用凭证本身的 Expiration 时间字段。
• 效果: 非英语用户可获得更友好的会话列表;为托管/合规集成提供定制 footer 链接的能力;Bedrock 用户减少频繁重新认证。
• 使用限制: Claude Code。Bedrock 改进适用于通过 Amazon Bedrock 使用 Claude 的用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.176)

🅾️ **OpenAI 产品更新详解**

**OpenAI 收购 Ona**
• 功能介绍: OpenAI 宣布计划收购 Ona,这是一家专注于安全、持久云环境的技术公司。这次收购旨在扩展 Codex,为其增加长时间运行的 AI 代理以及跨企业工作流程所需的持久计算环境。
• 效果: Codex 将不再局限于短暂的代码生成,而是能管理长期任务,如数小时甚至数天的自动化工作流、在安全环境中执行和监控代码,直接对标 GitHub Copilot 的代理模式和企业级自动化平台。
• 使用限制: Codex。具体发布时间和对现有 Codex 用户的集成方式尚未公布 (推测),可能首先向 API 和企业版开放。
[原文](https://openai.com/index/openai-to-acquire-ona)

**Oracle Cloud 集成 OpenAI 模型与 Codex**
• 功能介绍: 用户现在可以通过 Oracle Cloud 基础设施使用现有的云承诺支出访问 OpenAI 模型和 Codex,具备企业级安全性和治理能力。
• 效果: 使已签约 Oracle Cloud 的大型企业能直接调用 OpenAI API,无需额外签订合同或更改采购流程,降低了合规门槛。适合需要私有网络、数据驻留和内部安全审核的行业。
• 使用限制: OpenAI API,包括 Codex;需要 Oracle Cloud 帐号和承诺使用合同。具体可用区域和模型系列将逐步开放 (推测)。
[原文](https://openai.com/index/openai-on-oracle-cloud)

**OpenAI 发布 Codex 和 GPT-5.5 实战案例系列**
• 功能介绍: OpenAI 官方博客发布了多个企业的 Codex 应用案例,包括天体物理学家使用 Codex 模拟黑洞 (Chi-kwan Chan)、Nextdoor 工程师使用 Codex 和 GPT-5.5 调查难以复现的 Bug、Notion 使用 Codex 单次生成规格并构建 AI Voice Input Web 版。这些不算产品新功能,但展示了官方认证的工作流。
• 效果: 提供了可复用的场景参考 —— 科学模拟、多平台构建、语音输入集成,表明 GPT-5.5 已融入 Codex 生产环境。
• 使用限制: Codex 和 GPT-5.5 (推测 API 已可用)。Notion 案例提及赋能小团队倍增工程产能。
[原文(黑洞)](https://openai.com/index/using-codex-to-simulate-black-holes) · [原文(Nextdoor)](https://openai.com/index/nextdoor) · [原文(Notion)](https://openai.com/index/notion)
