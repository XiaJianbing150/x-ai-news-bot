🅰️ **Claude 产品更新详解**

**Claude Code v2.1.221 · Focus 视图与沙盒凭证 mask 模式**
• 功能介绍：在 VS Code 中新增 Focus 视图（`Ctrl+Alt+F` 切换），将工具执行细节折叠为每回合可展开的摘要，并显示实时运行的工具指示器。同时为 Linux / WSL 上的沙盒凭证文件加入 `mask` 模式，沙盒命令读取一份哨兵副本，代理在出口处替换真实凭证。
• 效果：Focus 视图让开发者专注于对话主线，避免被大量工具日志淹没；`mask` 模式在不暴露真实密钥的前提下安全执行沙盒命令，适合在共享环境或录制演示中使用。
• 使用限制：Claude Code 所有版本，Focus 视图仅 VS Code 环境可用，`mask` 模式需 Linux 或 WSL，macOS 支持方式不同（具体见文档）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)

**Claude Code v2.1.222 · 工作树隔离与预工具使用钩子修复**
• 功能介绍：修复了工作树隔离会话及子代理可对主仓库执行破坏性 git 命令的问题，现在所有会话类型的文件编辑与 Bash 命令均受到隔离保护。同时修复了预工具使用自动允许钩子（PreToolUse auto-allow hooks）在后台代理任务中绕过工具限制的漏洞，以及 `/usage-credits` 在 Team / Enterprise 中错误拦截成员新请求的问题。
• 效果：显著提升多仓库协同开发时的安全性，避免子代理越权修改主干代码；后台任务不会再意外触发未授权的工具调用，用量信用请求流程恢复正常。
• 使用限制：Claude Code 所有版本，Team 与 Enterprise 用户受 `/usage-credits` 修复直接影响。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.222)

**Claude Code v2.1.223 · Marketplace 组织级通配符与 /teleport 云端提示**
• 功能介绍：在 `strictKnownMarketplaces` 与 `blockedMarketplaces` 托管设置中新增 `owner/*` 通配符条目，可一次性允许或阻止某 GitHub 组织下的所有市场仓库。当工作流代理、fork 技能、斜杠命令或恢复的后台代理请求的子代理模型受限，而父模型代替运行时，会弹出警告。此外，在云会话中加入 `/teleport` 提示，展示如何通过 `claude --teleport ` 在本地继续工作。
• 效果：管理员可批量管理市场来源，降低繁琐的逐个仓库配置成本；子模型回退的透明警告帮助用户理解行为变更；`/teleport` 让从云端会话无缝迁移到本地成为可能，提升混合开发体验。
• 使用限制：Claude Code 所有版本，组织级通配符需 Enterprise 托管设置，云会话 `/teleport` 功能需已登录的 Cloud 会话支持。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)
