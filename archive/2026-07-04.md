• 功能介绍：推出新一代模型 **Sonnet 5**，在编程、智能体及规模化专业工作上达到前沿水平，是 Claude Code 的全新默认模型。
• 效果：开发者可直接获得更强大的代码生成、长文档理解和复杂 agent 任务能力；原生支持 1M token 上下文窗口，处理大型项目无需拆解。
• 使用限制：通过 **Claude Code** 及以上版本使用；促销价 $2/$10 每百万 token 输入/输出，持续至 2026‑08‑31；API 与 Anthropic 控制台均已提供。
