**🅰️ Claude 产品更新详解**

**Claude Code v2.1.305–v2.1.312(连续 8 个版本)**
- 功能介绍: 过去 7 天 Claude Code 密集迭代,关键新增包括:OIDC 网关支持 **oidc.user_id_claim**(可用 Microsoft Entra ID 的 oid 等非 sub 声明识别用户);全屏模式下点击排队消息的 "to send now" 提示即可立即发送;新增 **Monitor 工具**与插件监控(覆盖 Bedrock / Vertex / Foundry,且在遥测关闭时仍可用);新增 **/claude-api api-version** 命令将 Claude API 代码迁移到 2026-10-21 版本;新增 **claude_code.safety_event** OpenTelemetry 事件,记录每次工具调用被权限规则、自动模式、安全检查、hook 或沙箱拦截/放行的情况;新增 **sandbox.allowNestedUserNamespaces** 允许 Linux 沙箱内创建用户命名空间(Chromium、rootless podman 可用);新增 **--hold-idle-file** 与 **--max-hold-min** 让 self-hosted-runner 保持空闲会话。
- 效果: 面向企业网关(Entra ID 等)、自托管 runner、沙箱安全与可观测性场景;修复了 VS Code 扩展登录后托管策略不刷新、超大 CLAUDE.md 导致启动/读写卡顿、MCP 服务器无响应时中断延迟、Vertex/Bedrock 上工具 schema 被拒导致全量请求失败、以及 [1m] 别名模型在禁用 1M 上下文时报 model-not-found 等一系列稳定性问题。
- 使用限制: Claude Code(CLI / VS Code 扩展);Monitor 工具与插件监控在 Bedrock / Vertex / Foundry 及遥测关闭时可用;OIDC 声明配置面向企业网关管理员。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.312)
