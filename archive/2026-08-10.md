🅰️ **Claude 产品更新详解**

**Claude Code v2.1.224 — 自托管运行环境**
• 功能介绍: 新增 claude self-hosted-runner 功能，支持 Team/Enterprise 用户将自有机器或容器注册为运行节点，供 **Claude Code** Web、移动端和桌面端会话远程执行。同时新增从 HTTPS zip 包安装插件的能力，支持可选的 SHA-256 校验码固定。
• 效果: 企业用户可以在内部基础设施上运行 Claude Code 任务，解决合规与数据驻留需求；插件安装不再依赖 git 或 npm，部署更灵活安全。
• 使用限制: Team / Enterprise 档位；平台为 Claude Code CLI；自托管功能需配合企业网关。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)

**Claude Code v2.1.221 — VS Code Focus 视图 + 沙盒凭证模式**
• 功能介绍: VS Code 扩展新增 Focus 视图，可将工具活动折叠为按轮次的可展开摘要，仅显示运行中工具指示器（快捷键 Ctrl+Alt+F）。同时在 Linux / WSL 上新增 "mask" 沙盒凭证模式，沙盒命令读取哨兵副本，出口代理替换真实凭证值。
• 效果: 开发者可以专注于对话本身，降低工具执行带来的视觉干扰；凭证安全处理机制让沙盒内的敏感操作更安全，避免真实凭证泄露到沙盒环境。
• 使用限制: Focus 视图为 VS Code 扩展功能；mask 模式支持 Linux / WSL（macOS 支持方式不同）。需 Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)

**Claude Code v2.1.225 — 网关消费限额支持**
• 功能介绍: Claude Code 的使用量警告现已支持网关消费限额。达到限额时，消息会明确显示限额名称、重置时间和操作者备注。同时修复了长期 OAuth token 被短期 token 替换导致无头会话中断的问题，以及 MCP OAuth 相关问题。
• 效果: 企业管理员可通过网关精确控制团队消费，用户也能清晰了解限额状态和时间窗口。无头会话稳定性得到修复。
• 使用限制: 需配合网关 v2.1.225；Team / Enterprise 档位。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.225)

**Claude Code v2.1.223 / v2.1.222 — 安全强化与 marketplace 管理**
• 功能介绍: v2.1.223 为 strictKnownMarketplaces 和 blockedMarketplaces 托管设置新增 owner 通配符（"owner/*"），可批量允许或阻止某 GitHub 组织下所有 marketplace 仓库。v2.1.222 修复了 worktree 隔离会话和子代理可能执行破坏性 git 命令的问题，以及后台代理任务中 PreToolUse 钩子绕过的工具限制漏洞。
• 效果: 企业 IT 管理大规模 Claude Code 部署时，可精细化控制第三方 marketplace 来源。安全隔离的增强确保多任务并行时不会误操作主工作区。
• 使用限制: Team / Enterprise 档位（托管设置）；需 Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)

**GPT-5.6 Sol 升级 · Luna 免费开放**
