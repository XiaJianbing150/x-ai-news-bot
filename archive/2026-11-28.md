**Claude Code v2.1.332**
- 功能介绍: 新增从 MCP 服务器加载 skills 的 beta 支持,在 / 菜单中显示为 server:skill 格式;新增 PreSkillShellCommand hook 事件,可在 skill 或命令的内联 shell 命令加载时拒绝执行;为其他会话的 held messages 提示词加入 "Always deliver" 选项;flagged message 切换模型时新增常驻 footer 提示行。
