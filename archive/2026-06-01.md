🅰️ **Claude 产品更新详解**

**Claude Opus 4.8 发布**
• 功能介绍: Anthropic 发布最新旗舰模型 **Claude Opus 4.8**，在推理、编码、指令遵循等能力上全面提升，成为目前最强 Claude 模型。
• 效果: 用户可将其用于高难度分析、大规模代码库理解和复杂多步规划，相比 Opus 4.7 和 Sonnet 系列在自主性和准确性上有显著跃升。Claude Code 内可搭配动态工作流、高努力模式（/effort xhigh）完成超大规模任务。
• 使用限制: 通过 Anthropic API、Claude Code、claude.ai 面向所有用户逐步开放；计费按标准 API 价格，高速度 Fast 模式为原价 2 倍，具体速率视账户等级而定。
[原文](https://www.anthropic.com/news/claude-opus-4-8)

**Claude Code v2.1.154：动态工作流 + Opus 4.8 深度集成**
• 功能介绍: Claude Code 默认切换到 **Opus 4.8**，并引入「动态工作流」：用户只需描述目标，Claude 会自主编排十到数百个 agent 在后台协同，处理大规模复杂任务。同时，新增 **/effort xhigh** 获得最高推理强度，Fast 模式提速 2.5x 而成本降至标准价 2 倍。
• 效果: 开发者可以用一句指令让 Claude 跨仓库重构、生成测试、对比方案，大幅减少人工拆分任务的成本。搭配 **/workflows** 查看执行历史，方便复盘。
• 使用限制: Claude Code 所有版本均可用；API 需支持 Opus 4.8，Fast 模式额外计费。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.154)

**Claude Code v2.1.158：Auto 模式扩展至 Bedrock / Vertex / Foundry**
• 功能介绍: 自动执行模式（Auto mode）现可在 AWS Bedrock、Google Vertex AI 和 Foundry 平台上的 **Opus 4.7 与 Opus 4.8** 开启。
• 效果: 企业用户可以在自托管或云市场环境中启用 Claude Code 全程自主执行，无需人工确认每一步，适合 CI/CD 流水线和批量处理。
• 使用限制: 需设置环境变量 CLAUDE_CODE_ENABLE_AUTO_MODE=1 主动加入，仅限 Opus 4.7/4.8。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.158)

**Claude Code v2.1.157：本地技能插件自动加载 + agent 配置增强**
• 功能介绍: 放置在 .claude/skills 目录下的插件现在会**自动加载**，无需连接市场；新增 **claude plugin init** 快速脚手架新技能；并支持 **/plugin** 参数的智能补全。同时，agent 分派的会话现在会读取 settings.json 中的 agent 字段，并可用 **--agent <name>** 覆盖。
• 效果: 团队可以离线管理内部技能库，一键生成插件模板，分派子任务时精准指定 agent 配置，便于多角色协作。
• 使用限制: Claude Code v2.1.157+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.157)

**Claude Code v2.1.152：代码审查自动修复 + 技能工具约束**
• 功能介绍: **/code-review --fix** 审查后会将重构建议、简化、效率改进直接应用到工作目录；**/simplify** 命令现等同于 /code-review --fix。技能和斜杠命令可在 frontmatter 中设置 **disallowed-tools** 暂时禁用部分工具，增强安全性。
• 效果: 审查完即可看到改动生效，减少手动改代码；限制技能运行时可用工具，防止误删文件或执行危险操作。
• 使用限制: Claude Code v2.1.152+，技能文件需自行添加 frontmatter。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.152)
