🅰️ **Claude 产品更新详解**

**Claude Opus 4.8 发布**
• 功能介绍: Anthropic 最新旗舰模型，在复杂推理、代码生成和长上下文任务上实现显著提升。
• 效果: 面向高强度推理场景，深度专业用户可在数学证明、大型代码库重构、多步逻辑推演中获得更精准的响应；相比前代在指令遵循和事实一致性上进一步优化。
• 使用限制: 推测面向 API 和 Claude Pro/Max 用户，Claude Code 中已默认启用高努力模式；Web 端和 API 均可使用。
[原文](https://www.anthropic.com/news/claude-opus-4-8)

**Claude Code v2.1.157: 插件自动加载与 /plugin 命令补全**
• 功能介绍: **.claude/skills** 目录下的插件现已自动加载，无需额外的 marketplace 配置；新增 **claude plugin init** 脚手架命令; **/plugin** 参数支持自动补全。
• 效果: 开发者可零配置启用本地技能插件，补全功能加速插件调用，降低上手门槛。
• 使用限制: Claude Code 终端环境，所有版本。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.157)

**Claude Code v2.1.154: Opus 4.8 集成与动态工作流**
• 功能介绍: 正式接入 **Opus 4.8**，默认高努力模式；新增 **/effort xhigh** 应对最困难任务；推出 **动态工作流 (Dynamic Workflows)**，Claude 可在后台编排数十到上百个 agent 协同处理大型复杂任务。
• 效果: 用户可通过单次指令发起大规模多代理并行任务；快速模式 (Fast mode) 成本仅标准模式 2 倍，速度提升 2.5 倍。
• 使用限制: Claude Code v2.1.154+；动态工作流可通过 /workflows 查看运行状态；精简系统提示词现为默认。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.154)

**Claude Code v2.1.152: /code-review --fix 与技能级工具限制**
• 功能介绍: **/code-review --fix** 在代码审查后自动将复用、简化、效率建议应用到工作树；**/simplify** 现已整合为该命令；技能和斜杠命令可通过前置元数据设置 **disallowed-tools** 来限制模型可用工具；新增 **/reload-skills** 热重载技能。
• 效果: 代码审查可直接落地修改，技能作者能更精细控制模型行为边界，迭代技能无需重启会话。
• 使用限制: Claude Code v2.1.152+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.152)

**Claude Code v2.1.149: /usage 用量细分与键盘滚动 diff**
• 功能介绍: **/usage** 现展示每类别用量驱动因素——技能、子代理、插件、每个 MCP 服务器的成本；diff 详情视图支持键盘滚动（方向键、j/k、PageUp/PageDown 等）。
• 效果: 用户可精确定位高消耗环节并优化成本；代码审查浏览体验更流畅。
• 使用限制: Claude Code v2.1.149+；Enterprise 版新增 allowAllClaudeAiMcps 管理设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**Claude Code v2.1.147: 固定后台会话与 /code-review 重命名**
• 功能介绍: 固定后台会话 (Ctrl+T) 在空闲时保持存活，更新后自动原位重启，仅当内存压力大时才降级；**/simplify** 更名为 **/code-review**，可按努力级别报告正确性缺陷，支持 **--comment** 将发现以行内评论提交到 GitHub PR。
• 效果: 长期运行的后台代理工作流更稳定；代码审查能力从“清理”进化为发现潜在缺陷。
• 使用限制: Claude Code v2.1.147+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)
