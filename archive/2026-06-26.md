🅰️ **Claude 产品更新详解**

**Claude Tag — 团队协作新范式**
• 功能介绍：Anthropic 为团队版 Claude 推出全新的 Claude Tag 功能，让团队能以更结构化的方式与 Claude 一起工作。
• 效果：团队可将 Claude 的输出、对话片段或操作记录打上标签进行分类、回溯和共享。解决团队协作时"信息散落在各段对话中"的痛点，把 Claude 变成可索引的团队知识加速器。
• 使用限制：目前仅面向 **Team 和 Enterprise** 档位开放。平台推测为 Web（Claude.ai）。（注：此文为产品概念宣发，具体入口和操作细节尚未在变更日志中体现。）
[原文](https://www.anthropic.com/news/introducing-claude-tag)

**Claude Code v2.1.193 — 全量自动模式分类与响应日志**
• 功能介绍：新增 autoMode.classifyAllShell 设置，可将所有 Bash/PowerShell 命令（而不只是任意代码执行模式）统一路由到自动模式分类器审批。同时新增 OpenTelemetry 日志事件记录模型完整响应文本。
• 效果：管理员可精确区隔"安全命令"与"破坏性操作"，减少自动模式下误拦截的概率。开发者通过 OTEL 日志获取模型原始回复，用于调试、合规审计和效果评测。
• 使用限制：Claude Code CLI，需开启 auto-mode。完整的模型响应文本默认被脱敏（redacted），需设置环境变量 OTEL_LOG_ASSISTANT_RESPONSES=1 方可明文记录。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.193)

**Claude Code v2.1.191 — 对话回溯与语音策略修复**
• 功能介绍：新增 /rewind 指令，支持在 /clear 之后恢复被清空的对话。修复全屏模式下滚动阅读历史输出时自动跳到底部的困扰，以及后台 agent 在被停止后"死而复生"的 bug。
• 效果：误操作 /clear 的后悔药终于来了，开发者不必再因为手滑丢掉上下文。滚动修复解决流式输出阅读体验的痛点；/voice 被组织禁用时不再给出模糊报错，责任归属一目了然。
• 使用限制：Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.191)

**Claude Code v2.1.186 — MCP CLI 免交互登录与多 TTY 模式**
• 功能介绍：新增 claude mcp login <name> 和 logout 指令，支持从命令行直接认证 MCP 服务器（支持 SSH 上的 --no-browser stdin 重定向）。新增 teammateMode: "iterm2" 支持多窗口协同。

**Claude Code v2.1.185 — 流中断提示语优化**
• 功能介绍：API 流静默超时提示从"No response from API · Retrying in …"改为"Waiting for API response · will retry in …"，触发时间从 10s 延长到 20s。
• 效果：用户感知从"出错了"变成"正在等模型处理"，减少焦虑。20s 窗口更适配复杂推理请求的正常耗时。
• 使用限制：Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.185)

**Claude Code v2.1.183 — 自动模式安全加强：拦截破坏性命令**
• 功能介绍：自动模式下 git reset --hard、git checkout -- .、git clean -fd、git stash drop 等破坏性 git 命令，以及未明确请求时的 terraform/pulumi/cdk destroy 全部被拦截。git commit --amend 若目标提交不是当次对话 agent 所创建，则也禁止。
• 效果：杜绝自动模式"说毁就毁"——尤其是没让你丢代码时 agent 却执行 hard reset 这种灾难。基础设施即代码的 destroy 操作必须有明确用户意图，防止误删整个云栈。
• 使用限制：Claude Code CLI 的 auto-mode。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.183)

**Claude Code v2.1.181 — 命令行直接改配置与沙箱 Apple Events 开关**
• 功能介绍：新增 /config key=value 语法（如 /config thinking=false），支持在交互、-p 模式和远程控制中即时改任何设置。新增 sandbox.allowAppleEvents opt-in，允许沙箱命令在 macOS 上发送 Apple Events。新增 CLAUDE_CLIENT_PRESENCE_FILE 环境变量，指向标记文件时可抑制移动端推送。
• 效果：开发者无需翻 settings.json 就能热切换 thinking 模式。macOS 自动化场景（如让沙箱脚本操作其他应用）可选开放。多端使用时坐在 Mac 前就不会被手机上重复推送打扰。
• 使用限制：Claude Code CLI（macOS 相关功能仅限 Mac）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.181)

**Codex-maxxing 长程项目方法**
• 玩法：Jason Liu 分享使用 Codex 进行"Codex-maxxing"——通过精心设计的上下文保留策略，让 Codex 在超长执行链中保持对复杂项目状态的追踪，使工作跨越单次 prompt 的边界持续进行。
• 效果：解决大型代码库重构或多文件改动时上下文窗口不够用的问题，让 AI 代理像资深开发者一样"记住昨天写到哪了"。
• 关联产品：OpenAI Codex。
[原文](https://openai.com/index/codex-maxxing-long-running-work)

**推理模型辅助诊断罕见儿童遗传病**
• 玩法：研究人员使用 OpenAI 推理模型分析未确诊儿童患者的基因组与临床数据，在之前未解决的病例中新确诊 18 种罕见遗传病。
• 效果：模型在跨模态（基因序列+病历文本+医学文献）的复杂关联推理中，找到人类医生遗漏的致病突变与表型关联。
