🅰️ **Claude 产品更新详解**

**Claude Opus 4.8**
• 功能介绍：Anthropic 正式发布最新旗舰模型 **Claude Opus 4.8**，同时在 Claude Code 中将其设为默认模型，并引入“动态工作流”等配套能力。
• 效果：在 Claude Code 中，Opus 4.8 默认为高努力模式，可通过 /effort xhigh 应对最困难任务；新增动态工作流，允许 Claude 在后台协调数十到上百个 agent 并行处理大型复杂项目，用户通过 /workflows 查看运行状态；快速模式成本降至标准费率的 2 倍，速度提升 2.5 倍。
• 使用限制：Claude Code 用户即日起可体验；Opus 4.8 在 API 中预计按一贯的定价层级提供（推测）；动态工作流为 Claude Code 内置功能，不限平台。
[原文](https://www.anthropic.com/news/claude-opus-4-8)

**Claude Code v2.1.154 – 动态工作流与 Opus 4.8 集成**
• 功能介绍：伴随 Opus 4.8 发布，Claude Code 引入动态工作流、快速模式与精益系统提示词，大幅提升复杂任务处理效率。
• 效果：可以通过对话直接要求 Claude 创建工作流，其后自动调度多 agent；/workflows 可视化查看执行情况；精益系统提示词成为默认，降低 token 消耗；快速模式成本大幅降低。
• 使用限制：所有 **Claude Code** 用户均可使用，需升级至 v2.1.154+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.154)

**Claude Code v2.1.157 – 插件自动加载与 agent 调度增强**
• 功能介绍：**.claude/skills** 目录下的插件现可自动加载，无需市场；新增 claude plugin init  命令快速创建插件；agent 字段支持调度会话。
• 效果：开发者存放于技能目录中的自定义工具被自动识别，搭配 /plugin 自动补全与参数提示；调度 agent 时可指定名称，实现更精细化的子任务分发。
• 使用限制：**Claude Code** v2.1.157，需要手动创建 **.claude/skills** 目录。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.157)

**Claude Code v2.1.158 – Auto mode 扩展至 Bedrock/Vertex/Foundry**
• 功能介绍：在 Amazon Bedrock、Google Vertex AI 和 Azure Foundry 上使用 Opus 4.7/4.8 时，现可开启自动模式。
• 效果：通过设置 CLAUDE_CODE_ENABLE_AUTO_MODE=1，企业用户在自己的云环境中也能让 Claude Code 自主执行多步操作，无需人工逐步确认。
• 使用限制：仅限 **Bedrock/Vertex/Foundry** 上的 Opus 4.7 与 Opus 4.8 模型，需手动开启环境变量。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.158)

**Claude Code v2.1.152 – /code-review --fix 与技能工具限制**
• 功能介绍：新增 /code-review --fix，审查后直接应用修改建议；技能和斜杠命令可通过 frontmatter 设置 **disallowed-tools**，限制模型可调用的工具。
• 效果：/code-review --fix 将复用、简化与效率建议直接写入工作树；技能可安全地屏蔽危险工具，提高自动化信任度。
• 使用限制：**Claude Code** v2.1.152，相关 frontmatter 配置需 YAML 格式。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.152)

• 效果：前沿 AI 被定向用于增强社会抵御生物威胁的能力，支持疫苗开发、病原体分析等关键任务。
