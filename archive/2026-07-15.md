**Claude Code v2.1.202–v2.1.210 关键更新合集**

**实时耗时计数器** (v2.1.210)
• 功能介绍：在工具调用摘要行新增实时耗时指示，长时间运行的工具会显式计时，而不再出现“卡住”的视觉假象。
• 效果：开发者在长时间构建、测试或网络请求期间能直观看到进度，避免误以为 agent 失去响应。
• 使用限制：**Claude Code** 所有交互会话（含终端、IDE 集成）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.210)

**权限规则启动警告** (v2.1.210)
• 功能介绍：对 Write(path)、NotebookEdit(path)、Glob(path) 等权限规则在启动时发出警告，建议改用更精细的 Edit(path) 或 Read(path)。
• 效果：帮助用户收紧文件系统权限，降低 agent 误改文件的风险，提升安全配置的正确性。
• 使用限制：**Claude Code** 启动时对配置文件的静态检查。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.210)

**修复 /model 等对话框在后台会话阻塞** (v2.1.209)
• 功能介绍：修复了 /model 命令及其他对话框在 **Claude agents** 后台会话中被过度拦截、无法弹出的问题。
• 效果：在后台运行的 agent 会话中可正常切换模型或确认对话框，不再因强保护而中断交互。
• 使用限制：**Claude Code** 后台 agent 会话。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.209)

**屏幕阅读器模式** (v2.1.208)
• 功能介绍：新增无障碍屏幕阅读器模式，通过 claude --ax-screen-reader、环境变量 CLAUDE_AX_SCREEN_READER=1 或在设置中添加 "axScreenReader": true 启用纯文本渲染。
• 效果：依赖屏幕阅读器的开发者可获得无干扰的线性输出，显著提升 **Claude Code** 的可访问性。
• 使用限制：**Claude Code** 终端界面，需主动开启。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.208)

• 效果：企业 IT 可在 **Claude Code** 上施加公司级启动控制、审计或网络代理策略。
