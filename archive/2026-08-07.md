🧰 **Claude / GPT 实战玩法**

**启用两项 API 设置，ARC-AGI-3 得分提升三倍**
OpenAI 工程师发现，在 API 调用中开启 **推理保留（retain reasoning）** 与 **上下文压缩（compaction）** 两项设置后，GPT‑5.6 在 ARC-AGI-3 基准上的成绩提升了三倍。具体操作：请求中加入 retain_reasoning=true 使模型在多次调用中保持连贯推理链；同时启用 compaction_enabled=true 自动压缩历史 token 以容纳更长上下文。这一配置不需要修改模型权重或额外微调，开发者可立即在 API 中尝试。官方还公开了详细的参数组合与性能曲线。
[原文](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores)
