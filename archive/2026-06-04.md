🅰️ **Claude 产品更新详解**

**Claude Opus 4.8**
• 功能介绍：正式发布最新旗舰模型 Opus 4.8，推理能力与指令遵循全面提升，在 Claude Code 中默认采用高专注模式（high effort），并引入动态工作流（dynamic workflows）并行调度大量 agent。
• 效果：可承担更复杂、更大规模的任务，如自动跨文件重构、多 agent 协作；新增快速模式（Fast mode），以约 2 倍标准速率运行，成本仅为基础模型的 2 倍；可结合 /effort xhigh 将专注度进一步提升以应对极难任务。
• 使用限制：API（含 Bedrock、Vertex、Foundry）、Claude Code；推测所有付费档位（Pro / Max / Team / Enterprise）均可使用，Fast mode 按独立速率与费率计费。
[原文](https://www.anthropic.com/news/claude-opus-4-8)
