**🅰️ Claude 产品更新详解**

**Claude Opus 5.5 上线 Claude Code**
- 功能介绍: Claude Code v2.1.280 新增 **claude-opus-5-5** 模型,成为默认 Opus 模型,支持 1M 上下文。
- 效果: 定价 $4/$20 每 Mtok,缓存读取 $0.20/Mtok。适合超长代码库理解与复杂重构场景,相比旧 Opus 在长上下文任务上性价比更高。
- 使用限制: Claude Code 内可用,API 计费;需更新至 v2.1.280 及以上版本。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.280)

**AGENTS.md 支持**
- 功能介绍: Claude Code v2.1.277 起,项目中没有 CLAUDE.md 时会自动读取 **AGENTS.md** 作为项目指令。
- 效果: 与业界通用 agent 指令文件兼容,团队可在多工具间复用同一份项目规范,减少重复配置。
- 使用限制: 可在 /config 的 "Project instructions" 中切换;暂不支持 Bedrock、Vertex、Foundry 环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)

**Auto mode 服务端分类器默认启用**
- 功能介绍: v2.1.278 将 Claude API 与 Enterprise 用户及 Bedrock/Vertex/Foundry/gateway 的 auto mode 默认改为服务端分类器,不再对分类器开销计费。
- 效果: 降低 auto mode 使用成本,避免本地分类器带来的额外 token 消耗;/status 新增 Auto mode server 行显示分类器运行位置。
- 使用限制: 可用 **CLAUDE_CODE_AUTO_MODE_SERVER=0** 在 Bedrock/Vertex/Foundry/gateway 上退出;计费回退时会警告。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)

**maxProseWidth 设置**
- 功能介绍: v2.1.282 新增 **maxProseWidth**,在宽终端中限制 Claude 正文宽度,表格和代码块保持全宽。
- 效果: 解决超宽终端下长段落难以阅读的问题,提升终端内长文本可读性。
- 使用限制: Claude Code 设置项,适用于所有终端环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.282)

**send-now 快捷键**
- 功能介绍: v2.1.275 新增 **ctrl+enter**(或 ctrl+x ctrl+s)立即中断当前回合并一次性发送所有排队消息。
- 效果: 多步操作排队后一键全部提交,减少等待;已发送与排队消息在模型接收前以灰色显示。
- 使用限制: Claude Code 交互模式。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.275)

**Claude apps gateway 增强**
- 功能介绍: v2.1.281 为 Claude apps gateway 增加 Bedrock upstream 的 **assume_role** 支持(通过 STS 跨账号代入 IAM 角色),以及 Bedrock guardrail 配置;v2.1.275 增加 gateway 登录账号确认。
- 效果: 企业可在多 AWS 账号间安全路由 Bedrock 请求,按开发者分配会话角色,并应用 Amazon Bedrock guardrail 策略。
- 使用限制: Claude apps gateway 企业部署场景。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.281)

**内存临界警告**
- 功能介绍: v2.1.274 在内存使用达到临界值时显示可见警告,并给出释放内存或安全重启的步骤。
- 效果: 防止长时间会话因内存耗尽而崩溃或丢失上下文。
- 使用限制: Claude Code 所有环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.274)
