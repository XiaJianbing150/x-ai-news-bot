**Claude Code v2.1.278 — Auto mode 计费策略调整**
- 功能介绍: 针对 Claude API 和 Enterprise 用户,以及在 Bedrock、Vertex、Foundry 和各类网关上运行的场景,auto mode 默认改用服务端分类器,不再对分类器开销计费;若发生计费回退会给出警告。
- 效果: 用户在网关/云平台上跑 Claude Code 时,auto mode 的分类器消耗不再悄悄计入账单,成本更可控;/status 中新增 Auto mode server 行,可查看当前会话分类器运行位置。
- 使用限制: Claude API / Enterprise 用户;Bedrock / Vertex / Foundry / gateways 平台;可用 CLAUDE_CODE_AUTO_MODE_SERVER=0 选择退出(推测仅限上述云平台)。
