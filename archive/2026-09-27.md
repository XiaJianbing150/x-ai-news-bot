**🅰️ Claude 产品更新详解**

**Claude Opus 5.5 上线 Claude Code**
- 功能介绍: Claude Code v2.1.280 新增 **claude-opus-5-5**,成为默认 Opus 模型,上下文 1M。
- 效果: 定价 $4/$20 每 Mtok,缓存读取 $0.20/Mtok;面向长上下文重度编码场景,替代旧 Opus 成为默认选择。
- 使用限制: Claude Code,API 用户可用;需升级到 v2.1.280 及以上。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.280)

**AGENTS.md 支持**
- 功能介绍: Claude Code v2.1.277 起,项目无 CLAUDE.md 时自动读取 **AGENTS.md** 作为项目指令。
- 效果: 与业界通用 agent 指令文件兼容,迁移项目无需重写指令;可在 /config 的 "Project instructions" 中切换。
- 使用限制: Claude Code;暂不支持 Bedrock / Vertex / Foundry 后端。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)

**Auto mode 服务端分类器默认启用**
- 功能介绍: v2.1.278 将 Claude API 与 Enterprise 用户的 auto mode 默认切到服务端分类器,不再对分类开销计费。
- 效果: 降低 auto mode 使用成本;billed fallback 时给出警告。Bedrock / Vertex / Foundry / gateways 可用 **CLAUDE_CODE_AUTO_MODE_SERVER=0** 退出。
- 使用限制: Claude API、Enterprise;Bedrock / Vertex / Foundry / gateways 默认启用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)

**Managed settings 新增 availableModelsMatch 与 deniedModels**
- 功能介绍: v2.1.283 新增 **availableModelsMatch: "exact"** 与 **deniedModels** 托管设置。
- 效果: exact 模式下 availableModels 只放行指定模型版本,新版本在显式列入前保持封锁;deniedModels 可在 availableModels 允许范围内单独拉黑特定模型。企业可精细管控模型版本。
- 使用限制: Claude Code 托管环境(managed settings)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.283)

**Gateway hint headers 与 MCP 描述长度配置**
- 功能介绍: v2.1.283 新增 **x-claude-code-prompt-id** 网关提示头(需 **CLAUDE_CODE_GATEWAY_HINT_HEADERS=1** 开启);v2.1.280 新增 **CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH** 调整 MCP 工具描述 2048 字符上限。
- 效果: LLM 网关可按 prompt 聚合请求,便于计费与追踪;MCP 描述长度可调,适配长工具说明场景。
- 使用限制: Claude Code;网关功能需自建或使用 Claude apps gateway。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.283)

**maxProseWidth 与 Chrome 托管策略**
- 功能介绍: v2.1.282 新增 **maxProseWidth** 限制宽终端下散文宽度,表格与代码块保持全宽;新增 **allowClaudeInChromeWithManagedMcp** 允许 claude --chrome 与独占 managed-mcp.json 并存。
- 效果: 宽屏终端阅读体验改善;Chrome 集成与托管 MCP 策略不再互斥。
- 使用限制: Claude Code;Chrome 策略面向托管环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.282)

**Bedrock 上游 assume_role 与 guardrail 支持**
- 功能介绍: v2.1.281 为 Claude apps gateway 的 Bedrock 上游新增 **assume_role**(通过 STS 以 IAM 角色调用,可跨 AWS 账户、按开发者分会话)与 **guardrail: {id, version}** 应用 Amazon Bedrock Guardrails。
- 效果: 企业网关可跨账户安全调用 Bedrock,并直接挂载 Bedrock 内容护栏。
- 使用限制: Claude apps gateway + Amazon Bedrock 上游。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.281)
