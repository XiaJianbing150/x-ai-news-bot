**🅰️ Claude 产品更新详解**

**Claude Code v2.1.302**
- 功能介绍: 新增 **CLAUDE_CODE_AUTO_MODE_MODEL** 环境变量,可指定客户端侧 auto mode 分类器使用的模型(不影响服务端 auto mode);/config 中新增 Idle compaction 开关行,空闲压缩后的提示会告知如何关闭。
- 效果: 开发者可以更精细地控制 auto mode 的模型选择,同时能按需关闭空闲压缩,避免长会话被意外压缩。
- 使用限制: Claude Code(终端),需更新至 v2.1.302。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)

**Claude Code v2.1.301**
- 功能介绍: 新增 **CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS**,让无人值守重试模式在 usage limit 重置过远时直接结束请求而非等待;vim 模式新增 **% motion**(跳转到匹配括号,可配合 d/c/y);claude-api skill 增加 OpenTelemetry tracing 指引。
- 效果: 无人值守场景下避免长时间挂起;vim 用户获得更高效的括号跳转编辑能力;API 调试可更方便地接入 tracing。
- 使用限制: Claude Code(终端),需更新至 v2.1.301。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.301)

**Claude Code v2.1.300**
- 功能介绍: mod 的 prompt decorations 新增 **virtualText**(在输入框绘制的文本,不会进入草稿或提交的 prompt);OpenTelemetry api_request 事件新增 **cache_creation_5m_tokens** 和 **cache_creation_1h_tokens**,按缓存生命周期拆分写入量;mod 新增 **$.ui.view({ agentId })** 可在主视图查看 agent 的 transcript。
- 效果: mod 开发者可以做更丰富的输入框 UI 提示;API 成本分析更精细;多 agent 调试时可直接查看各 agent 的对话记录。
- 使用限制: Claude Code(终端),需更新至 v2.1.300。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.300)

**Claude Code v2.1.299**
- 功能介绍: 新增 **CLAUDE_CODE_DISABLE_FILE_MENTIONS** 环境变量(Claude 拿到 @ 文件提及的路径后用文件工具读取,而非直接获取内容);终端新增 **idle compaction**:200K+ token 的对话闲置约 54 分钟后会在 prompt cache 过期前自动压缩,避免下一条消息重新处理全部内容;新增 **CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS** 可调整 200K 的最低阈值。
- 效果: 长会话闲置后响应更快、token 消耗更省;文件提及行为可配置,适应不同工作流。
- 使用限制: Claude Code(终端),需更新至 v2.1.299。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)

**Claude Code v2.1.296**
- 功能介绍: Claude apps gateway 的 managed.policies[] 新增 **code key**(与 cli 相同设置,同时应用于 Claude Desktop 的 Code tab,并开启 Desktop 的 gateway mode);subagent frontmatter 和 --agents 定义新增 **autoCompactWindow**(子 agent 可比主对话更早自动压缩);新增 **CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL**(让所有 workflow agent 统一用一个模型,其他 subagent 保持各自模型)。
- 效果: 企业 gateway 策略可统一管控 Desktop 与 CLI;子 agent 的上下文管理更灵活;workflow 场景可统一模型以控制成本或行为一致性。
- 使用限制: Claude Code(终端)与 Claude Desktop,需更新至 v2.1.296。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.296)
