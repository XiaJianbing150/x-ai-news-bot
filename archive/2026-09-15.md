**🅰️ Claude 产品更新详解**

**Claude Code v2.1.271 — Remote 会话 fast mode + /config 鼠标支持**
- 功能介绍: 为 Claude Code Remote 会话(云端及自托管 runner)新增 fast mode,主机的 fast-mode 设置或会话内输入 /fast 即可生效(需组织允许);全屏模式下 /config 面板新增鼠标支持,滚轮滚动设置列表、点击设置值即可修改、指针所在行高亮。
- 效果: 远程/无头环境下也能快速切换快速模式,不必回到主机改配置;全屏配置面板从纯键盘操作升级为鼠标可点,降低上手门槛。
- 使用限制: Claude Code(需组织策略允许 fast mode);平台为 Claude Code Remote 会话(cloud / self-hosted runners);另新增 `claude self-hosted-runner --drain-marker-file ` 用于优雅排空。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.271)

**Claude Code v2.1.269 — plugin eval 与 /output-style**
- 功能介绍: 新增 `claude plugin eval`,可对插件 eval 套件跑分并输出可复现的 JSON + HTML 报告;新增 `/output-style [name]` 列出并切换输出风格,支持 Remote Control、云端及其他 headless 会话;Bash 工具处理文件编辑时,结果中附带被修改文件的 diff(设置项 bashEditDiffEnabled)。
- 效果: 插件作者可以量化验证插件质量;远程/无头用户也能切换输出风格;Bash 改文件后直接看 diff,减少"它到底改了什么"的核对成本。
- 使用限制: Claude Code;plugin eval 面向插件开发者;/output-style 覆盖 Remote Control 与 headless 会话。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.269)
