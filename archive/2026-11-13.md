**🅰️ Claude 产品更新详解**

**Claude Fable 5.2 与 Claude Mythos 5.2**
- 功能介绍: Anthropic 正式发布 **Claude Fable 5.2** 与 **Claude Mythos 5.2** 两款模型。Fable 5.2 成为新的默认 Fable 模型,支持 1M 上下文,定价 $8/$40 每 Mtok,缓存读取 $0.20/Mtok。
- 效果: 用户可在超长文档、代码库级任务中获得更强的上下文理解能力;缓存读取价格大幅降低,适合反复读取同一批上下文的 agent 工作流。Mythos 5.2 同步更新,面向创意与叙事类场景。
- 使用限制: 通过 Anthropic API 与 Claude Code 使用;Fable 5.2 已设为 Claude Code 默认 Fable 模型。具体档位与平台以 API 控制台为准。
[原文](https://www.anthropic.com/claude-fable-and-mythos-5-2)

**Claude Code v2.1.323 — Code Mode 实验性功能**
- 功能介绍: 新增 **Code Mode**,一个实验性 opt-in 模式,Claude 直接编写 JavaScript 来调用自身工具,而非走传统工具调用路径。同时为 plugin.json 增加 engines["claude-code"] 版本范围校验,超出声明版本范围的插件不会被安装、更新或加载;新增对插件 TypeScript hooks 模块的类型检查。
- 效果: Code Mode 让 Claude 以代码形式编排工具调用,适合需要复杂控制流或动态工具组合的高级用户;插件版本校验可防止不兼容插件破坏工作流。
- 使用限制: Claude Code,需手动开启;可按组织关闭。详见官方文档。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)

**Claude Code v2.1.322 — Vertex 快速模式**
- 功能介绍: 在 Google Vertex 的 global、us、eu 区域新增 **fast mode**;若 Vertex 拒绝快速模式,则自动回退到标准速度。
- 效果: 使用 Vertex 托管 Claude 的用户可获得更低延迟的响应体验,且回退机制保证可用性。
- 使用限制: Claude Code + Vertex 区域部署。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)

**Claude Code v2.1.321 — Fable 5.2 接入与 remote-control 增强**
- 功能介绍: 将 **Claude Fable 5.2** 设为默认 Fable 模型;为 **claude remote-control** 新增 **--settings ** 参数,可对每个启动的会话应用指定设置文件;修复 MCP OAuth 请求在服务器重定向时向其他主机泄露 refresh token 等密钥的问题。
- 效果: 远程控制多会话时统一注入配置,提升批量任务管理效率;OAuth 修复堵住了一个安全漏洞。
- 使用限制: Claude Code;remote-control 设置文件变更后需重启才对新会话生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)

**Claude Code v2.1.319 — auto mode 行为调整**
- 功能介绍: 当遥测或 feature flags 关闭时(包括在 LLM 网关后),auto mode 对服务器无法检查的调用改为询问或拒绝,不再回退到内置分类器;设置 **CLAUDE_CODE_AUTO_MODE_SERVER=0** 可继续使用内置分类器(Bedrock、Vertex、Foundry 不受影响)。LLM 网关后设置 **CLAUDE_CODE_AUTO_MODE_SERVER=1** 可强制开启服务器端检查。
- 效果: 提升 auto mode 在受限环境下的安全性与可预测性,避免静默降级。
- 使用限制: Claude Code,环境变量控制。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)
