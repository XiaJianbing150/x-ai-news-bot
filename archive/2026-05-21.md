🅰️ **Claude 产品更新详解**

**Claude Code v2.1.145 发布：代理会话 JSON 导出与 OTEL 追踪增强**
• 功能介绍：新增 **claude agents --json** 命令，可将当前活跃的 Claude 会话以 JSON 格式列出，方便脚本集成（如 tmux-resurrect、状态栏、会话选择器）。同时为 OTEL 遥测增加了 **agent_id** 和 **parent_agent_id** 属性，并修复了后台子代理追踪嵌套问题。
• 效果：DevOps 工程师可以通过脚本自动化监控和管理多个并行 Claude Code 会话；运维人员能用 JSON 输出构建自定义仪表盘。OTEL 修复让分布式追踪更准确，便于在复杂代理任务中排查性能瓶颈。
• 使用限制：**Claude Code (CLI)**；需升级至 v2.1.145；推测需安装 tmux 等工具以充分利用 JSON 输出。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.145)

**Claude Code v2.1.144 发布：后台会话接管与模型切换改进**
• 功能介绍：新增 **/resume** 支持后台（background）会话，与交互式会话并排列出并标记 **bg**；后台子代理完成通知现在显示已用时长（如“3h 2m 5s”）。**/model** 现仅影响当前会话，按 **d** 键可设置新会话的默认模型。**/plugin** 浏览面板增加插件最后更新时间展示。
• 效果：用户启动长期运行的后台任务后，可随时恢复查看进度；开发者能快速在不同模型间切换测试代码，不必担心全局设置被意外修改。
• 使用限制：**Claude Code (CLI)**；需升级至 v2.1.144；通过 **claude --bg** 或代理视图启动后台会话。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.144)

**Claude Code v2.1.143 发布：插件依赖强制管理与上下文成本预估**
• 功能介绍：**claude plugin disable** 现在会阻止禁用其他插件所依赖的目标，并给出可复制的依赖链提示；**claude plugin enable** 可强制启用传递性依赖。插件市场浏览面板新增**预估上下文成本**（每轮和每次调用 token 估算）。新增 **worktree.bgIsolation: "none"** 设置，允许后台会话直接编辑工作副本。
• 效果：插件生态的安全网——避免因误操作禁用关键插件导致环境崩溃；用户在选择插件前可预判 token 开销。高级用户可让后台代理直接操作文件，减少工作树切换开销。
• 使用限制：**Claude Code (CLI)**；需升级至 v2.1.143；worktree.bgIsolation 设置需在配置文件中显式开启。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.143)

**Claude Code v2.1.142 发布：后台会话完整参数传递与 Fast 模式升级**
• 功能介绍：新增 **claude agents** 多选项（--add-dir, --settings, --mcp-config, --plugin-dir, --permission-mode, --model, --effort, --dangerously-skip-permissions）以全面配置分派后台会话。**Fast 模式默认模型升级至 Opus 4.7**（此前为 Opus 4.6）。根目录有 **SKILL.md** 的插件现被识别为技能。
• 效果：用户启动后台代理时可完整复制当前会话的所有配置，确保行为一致。Fast 模式用户在交互式快速编码中获得更强推理能力，可通过环境变量回退到旧模型。
• 使用限制：**Claude Code (CLI)**；需升级至 v2.1.142；Fast 模式模型回退需设置 **CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1**；后台会话需对应权限模式。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.142)

**Claude Code v2.1.141 发布：桌面通知与工作负载身份联邦**
• 功能介绍：钩子 JSON 输出新增 **terminalSequence** 字段，可发送桌面通知、窗口标题更新和铃声。新增 **CLAUDE_CODE_PLUGIN_PREFER_HTTPS** 环境变量以 HTTPS 克隆 GitHub 插件源。新增 **ANTHROPIC_WORKSPACE_ID** 环境变量支持工作负载身份联邦，将铸造的令牌限定到特定工作区。
• 效果：长时间运行的任务完成后，用户可收到系统级弹窗通知；企业内部无 SSH 密钥的环境也能顺利安装插件；大型团队在使用联合身份时能更精细化地控制权限范围。
• 使用限制：**Claude Code (CLI)**；需升级至 v2.1.141；桌面通知功能推测需运行于支持 OSC 序列的终端；工作负载身份联邦需配合企业级 Anthropic API 配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.141)

**Claude Code v2.1.140 发布：代理类型匹配增强与 /goal 修复**

• 效果：用户编写代理指令时不用再记忆精确的标识符格式，容错性大幅提升。之前 /goal 在某些安全配置下无限等待的 bug 被修复，使用体验更流畅。
• 使用限制：**Claude Code (CLI)**；需升级至 v2.1.140；挂钩设置热修复为静默改进。
