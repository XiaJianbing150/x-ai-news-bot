**Claude Tag**

• 使用限制: 面向 Team 和 Enterprise 档位，在 Web 端可用 (推测)。
[原文](https://www.anthropic.com/news/introducing-claude-tag)

以下是 **Claude Code** 近期密集的版本更新要点:

**Claude Code v2.1.196 — 组织默认模型支持**
• 功能介绍: 新增对组织管理员设定的默认模型支持；会话开始时附带可读的默认名称；聊天中新增可点击的文件附件 (Cmd/Ctrl-单击在系统文件管理器中定位文件)。
• 效果: 企业管理员可以在组织控制台统一设定默认模型，成员在 /model 中看到"Org default"标识，提升治理一致性；文件附件的点击定位功能加快开发流。
• 使用限制: Claude Code CLI 环境，组织模型功能需 Enterprise 档位。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.196)

**Claude Code v2.1.195 — 禁用鼠标点击 & 钩子匹配修复**
• 功能介绍: 新增环境变量 CLAUDE_CODE_DISABLE_MOUSE_CLICKS，可在全屏模式下禁用鼠标点击/拖拽但保留滚轮滚动；修复了连字符标识符 (如 code-reviewer) 的钩子匹配问题，现在精确匹配。
• 效果: 在终端全屏工作流中避免误触中断；钩子精确匹配提升自动化脚本的可靠性。
• 使用限制: Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.195)

**Claude Code v2.1.193 — 自动模式扩展 & 遥测日志**
• 功能介绍: 新增 autoMode.classifyAllShell 设置可将所有 Shell 命令路由到自动模式分类器；自动模式拒绝原因现在会显示在记录和权限面板中；新增 OpenTelemetry 日志事件，可记录模型响应文本 (需设置 OTEL_LOG_ASSISTANT_RESPONSES=1)。
• 效果: 更精细的自动模式安全控制与审计追溯；为可观测性管道提供更完整的模型交互日志。
• 使用限制: Claude Code CLI，遥测日志功能需自建 OpenTelemetry 基础设施。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.193)

**Claude Code v2.1.191 — /rewind 支持与后台代理修复**
• 功能介绍: 新增 /rewind 支持，可在使用 /clear 之前恢复对话；修复后台代理在被停止后意外复活的问题 (现在停止是永久性的)；修复 /voice 在组织策略禁用时提示不明确的问题。
• 效果: /rewind 提供关键的对话容错能力；永久停止代理提升了任务管理的确定性。
• 使用限制: Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.191)

**Claude Code v2.1.187 — 沙盒凭据保护与组织模型限制**
• 功能介绍: 新增 sandbox.credentials 设置阻止沙盒化命令读取凭据文件和环境变量；组织配置的模型限制现在会显示在模型选择器、--model、/model 等所有入口，选中受限模型时会提示"restricted by your organization's settings"。
• 效果: 沙盒凭据保护显著提升安全隔离，防止沙盒内代码窃取密钥；统一的组织级模型治理入口确保合规。
• 使用限制: Claude Code CLI，组织功能需 Enterprise 档位。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.187)

**Claude Code v2.1.186 — MCP CLI 认证 & 工作流过滤**
• 功能介绍: 新增 claude mcp login/logout 子命令，可直接从 CLI 认证 MCP 服务器 (无需打开 /mcp 交互菜单)，支持 --no-browser 和 stdin 重定向以在 SSH 会话中完成认证；新增 /workflows 代理详情视图的状态过滤 (按 f 键)；新增 teammateMode: "iterm2" 设置。
• 效果: 无头服务器和远程 SSH 环境下的 MCP 配置体验大幅改善；工作流状态过滤提升复杂任务管理的效率。
• 使用限制: Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.186)
