**Claude Code v2.1.200–v2.1.207 更新汇总**
• 功能介绍：过去一周 Claude Code 连发 8个版本，带来多项重要变化：
  ① Auto mode 现已在 Amazon Bedrock、Google Vertex AI、SAP Foundry 上默认可用，不再需要手动设置环境变量（可通过 disableAutoMode 关闭）；② 新增 Dynamic workflow size 设置，可在 /config 中指定动态工作流所生成的代理规模（小/中/大），作为指导而非硬性限制；③ 默认权限模式改为 Manual，底部状态栏增加灰色 ⏸ 标识以醒目提示当前模式；④ AskUserQuestion 对话框默认不再自动继续，用户必须主动操作，避免错过关键询问；⑤ /cd 命令提供与 /add-dir 一致的目录路径建议；⑥ /doctor 检查新增强建议，可提示用户修剪已提交的 CLAUDE.md 文件，以移除 Claude 可从代码库直接推导的内容；⑦ /commit-push-pr 现在自动允许 git push 到配置的远程仓库（如 remote.pushDefault 或唯一远程）；⑧ 登录支持 Anthropic 运营的公共网关端点，并新增登录过期警告；⑨ MCP 根目录列表 (roots/list) 包含会话附加工作目录，当发生变化时发送通知；⑩ 新增 auto mode 规则阻止对会话转录文件进行篡改；⑪ 遥测中增加 workflow.run_id 和 workflow.name 属性，便于在工作流代理间追踪活动。
• 效果：开发者获得更细粒度的控制与安全感，手动模式默认减少意外执行；动态工作流大小让资源调配更灵活；各项 CLI 交互改善显著提升日常操作效率；Auto mode 向更多云平台开放降低了使用门槛。
• 使用限制：所有变更对 Claude Code（CLI / VS Code / JetBrains 扩展）用户即时生效；需绑定计费账单；部分行为可通过 /config 调优，无需额外申请。

🅾️ **OpenAI 产品更新详解**

**GPT-5.6：可随你野心扩展的前沿智能**
• 功能介绍：OpenAI 正式发布 GPT-5.6，新模型在每个 token 上提供更高智能、更强的单位成本性能，并可按需释放更多能力以应对最高难度的工作。自发布起即成为 Microsoft 365 Copilot 的首选模型，深度集成到 Word、Excel、PowerPoint、Chat 和 Cowork 中。
• 效果：用户在推理、编码、分析等复杂任务中获得更快、更高质量的输出；企业通过 M365 Copilot 可以直接在生产力工具中体验前沿 AI 的飞跃。
• 使用限制：ChatGPT Plus / Pro / Team / Enterprise 用户可通过模型选择器使用，API 同步开放；Microsoft 365 Copilot 用户自动受益。具体速率限制需查阅 OpenAI 账户配额。

**ChatGPT Work：陪你完成最远大的工作**
• 功能介绍：ChatGPT Work 是一个能够跨应用、跨文件执行操作的自主代理 (Agent)。它最多可以陪伴一个项目数小时，只需一个目标就能将其持续推进为最终成品，无需始终手动引导。
• 效果：面向多步骤的数字任务，例如自动整理资料、跨软件生成报告、持续监控信息并产出行方案，大幅度减轻人工串联操作的负担。
• 使用限制：(推测) 面向 ChatGPT Pro / Team / Enterprise 用户；需要授权连接相关应用和服务；可能处于早期访问阶段，具体开放范围以 OpenAI 界面显示为准。
[原文](https://openai.com/index/chatgpt-for-your-most-ambitious-work)

**GPT-Live：新一代语音模型驱动 ChatGPT 语音**
• 功能介绍：GPT-Live 是一代全新的语音模型，专为自然的人机语音互动而设计，现已注入 ChatGPT Voice，带来更低延迟、更自然的对话节奏和情感表达能力。
• 效果：语音对话几乎不再有机器的生硬感，用户可像与真人一样自然打断、切换话题，适用于实时口语陪练、边做事边交谈等场景。
• 使用限制：覆盖所有支持 ChatGPT Voice 的平台（iOS、Android、Web），免费用户可能有每日时长限制，Plus 及以上档位享受更长使用时间。
[原文](https://openai.com/index/introducing-gpt-live)
