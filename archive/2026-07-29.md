🅰️ **Claude 产品更新详解**

**Claude Opus 5**
• 功能介绍：**Anthropic** 正式发布最强模型 **Claude Opus 5**，具备 1M token 上下文，支持 fast mode，输入 \$10/Mtoks、输出 \$50/Mtoks，现已作为默认 Opus 模型在 API 与 **Claude Code** 中可用。
• 效果：处理超长文档、复杂推理与深度编码任务时响应更快、容量更大，并可在 **Claude Code** 内直接通过模型选择调用，替代旧版 Opus 成为默认高端模型。
• 使用限制：通过 Anthropic API 付费使用，亦可在 **Claude Code**（需相应计费层级）中作为 claude-opus-5 直接启用；具体档位（Max/Enterprise）及速率限制以控制台为准。
[原文](https://www.anthropic.com/news/claude-opus-5)

**Ask Claude about the Anthropic Economic Index**
• 功能介绍：推出 **Anthropic Economic Index** 的 MCP 连接器，用户可以在 **Claude** 中直接查询劳动力市场趋势、AI 使用分布等经济指标数据。
• 效果：研究者与分析师无需离开对话即可让 **Claude** 结合最新经济指数提供数据驱动的洞察，提升了经济影响分析的交互性。
• 使用限制：需要在 **Claude** 客户端（如 **Claude Code** 或支持 MCP 的 app）中配置该连接器，模型使用仍受对应档位限制。
[原文](https://www.anthropic.com/news/anthropic-economic-index-connector)

**Claude Code v2.1.219：支持 Claude Opus 5 与沙箱网络白名单**
• 功能介绍：**Claude Code** 2.1.219 正式添加 **Claude Opus 5** 作为默认 Opus 模型，并引入 *sandbox.network.strictAllowlist* 设置，可预先定义允许连接的主机，禁止未授权网络访问且不再弹窗询问；同时新增 *DirectoryAdded* 钩子（在执行 /add-dir 或 SDK 注册新仓库根目录后触发）和 headless 模式下 *mcp_server_errors* 初始化事件，便于诊断 MCP 配置问题。
• 效果：更强大的推理模型直接在终端可用，安全团队能精细化控制沙箱网络出口，开发者可通过钩子与错误事件构建更自动化的 CI/Agent 流程。
• 使用限制：**Claude Code** 终端；Opus 5 价格按 API 计费，沙箱/钩子功能面向所有 **Claude Code** 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)

**Claude Code v2.1.218：/code-review 后台子代理 & 屏幕阅读器增强**
• 功能介绍：*/code-review* 命令改为后台子代理执行，审查过程不再占用主会话历史，且能保留堆叠的斜杠命令作为审查目标；同时在 *--ax-screen-reader* 模式下增加删除文本播报（单词与行删除）。
• 效果：代码审查时主会话保持干净，可继续同时进行其他任务；视障用户通过屏幕阅读器能清晰感知删除操作，编辑体验更完整。
• 使用限制：**Claude Code**，子代理功能默认启用，屏幕阅读器模式需通过 *--ax-screen-reader* 参数开启。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.218)

**Claude Code v2.1.217：Emoji 快捷补全 & 转录风险警告**
• 功能介绍：输入框中支持 Emoji 短码自动补全（如 :heart: → ❤️），可通过 *emojiCompletionEnabled* 设置关闭；新增转录写入失败（磁盘满、环境变量导致保存关闭）的警告，避免静默丢失会话记录；同时修复了 MCP 工具输出截断后仍占用完整内存的泄漏问题。
• 效果：日常交互更生动，长时间工作不会因磁盘问题丢失历史，内存占用更稳定。
• 使用限制：**Claude Code** v2.1.217 及之后版本，Emoji 补全默认启用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.217)

**Claude Code v2.1.216：沙箱文件系统隔离开关 & 长会话加速**
• 功能介绍：新增 *sandbox.filesystem.disabled* 设置，可跳过文件系统隔离而保留网络出口控制；修复了长会话中消息规范化成本随轮数二次增长导致的卡顿与对话恢复缓慢问题；同时修复了 OAuth token 过期时 *auto mode* 出现 “HTTP 401” 分类器错误，以及 *AskUserQuestion* 在用户要求中断时仍继续执行的问题。
• 效果：信任环境下开发更灵活，长时间编码或调试不再出现数秒停滞，自动模式与询问交互更可靠。
• 使用限制：**Claude Code**，配置项需手动开启。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.216)

**Claude Code v2.1.220：可靠性修复**
• 功能介绍：纯粹的 bug 修复与可靠性改进，无新功能。（推测）

🅾️ **OpenAI 产品更新详解**

**Health in ChatGPT**
• 功能介绍：面向符合条件的美国用户，**ChatGPT** 新增 **Health** 功能，可安全连接医疗记录与 Apple Health 数据，提供个性化健康洞察与分析。
• 效果：用户能通过对话理解自身健康趋势、获得基于数据的建议，将个人健康管理与 AI 助手结合。
• 使用限制：目前仅限美国地区有资格的 **ChatGPT** 用户，需主动连接数据源，具体档位（Plus/Pro/Team）待官方进一步说明（推测）。
[原文](https://openai.com/index/health-in-chatgpt)

**Introducing OpenAI Presence**
• 功能介绍：发布 **OpenAI Presence**，一个面向企业的 AI 代理平台，支持部署可信的语音与聊天代理，用于客户服务和内部工作流。
• 效果：企业可快速构建与品牌调性一致的对话代理，处理客服、IT 支持等场景，降低人工介入成本。
• 使用限制：企业级产品，需通过 OpenAI 企业渠道接入，具体定价与发布范围未完全公开（推测）。
[原文](https://openai.com/index/introducing-openai-presence)

**ChatGPT for Small Business program**
• 功能介绍：启动 **ChatGPT 小企业计划**，帮助创业者通过 **ChatGPT Work** 构建 AI 技能、自动化工作并实现增长。
• 效果：小企业主可获得针对性指导和工具，利用 AI 优化营销、客户支持、运营等环节。
• 使用限制：面向小企业，需注册 **ChatGPT Work**（可能基于现有 Teams/Enterprise 的轻量版本，推测）。
[原文](https://openai.com/index/introducing-chatgpt-small-business-program)
