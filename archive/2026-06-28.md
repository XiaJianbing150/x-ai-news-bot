🅰️ **Claude 产品更新详解**

**Claude Tag 团队协作功能**
• 功能介绍：Claude Tag 是 Anthropic 新推出的团队协作功能，允许团队在工作区中用标签（Tag）组织对话、共享上下文，便于多人围绕同一项目或话题与 Claude 交互。
• 效果：团队成员可以通过标签快速筛选和接力对话，减少重复说明背景信息的成本，适合长期项目跟踪与知识沉淀。相比单纯的单线对话，提供了更清晰的共享工作流。
• 使用限制：预计优先面向 Team/Enterprise 计划（推测），具体上线方式和平台尚未完全公开。
[原文](https://www.anthropic.com/news/introducing-claude-tag)

**Claude Code 自动模式安全加固（v2.1.183）**
• 功能介绍：新增多项自动模式安全策略：破坏性 git 命令（reset --hard、checkout -- .、clean -fd、stash drop）在非主动要求丢弃本地工作时会被拦阻；不在本次会话中创建的 commit 会禁止 amend；terraform/pulumi/cdk 的 destroy 命令仅在明确要求销毁特定栈时才允许。同时，当请求的模型已弃用或自动升级时给出提醒。
• 效果：大大降低自动模式误删代码或基础设施的风险，开发者可以更放心地让 Claude Code 在“放手模式”下工作，不必逐条审查命令。
• 使用限制：Claude Code 所有用户，自动模式下生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.183)

**Claude Code 沙箱凭证保护与模型限制（v2.1.187）**
• 功能介绍：新增 sandbox.credentials 设置，可阻止沙箱命令读取凭证文件和敏感环境变量；模型选择界面、--model、/model 等位置会显示组织设置强制限制的模型，并提示“受组织策略限制”。同时为全屏模式下的选择菜单增加鼠标点击支持。
• 效果：企业管理员能强制执行安全基线，防止模型访问超出授权的凭证；开发者能立刻看清哪些模型可用，减少误选。
• 使用限制：Claude Code，部分功能依赖组织管理策略。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.187)

**Claude Code MCP 命令行认证与工作流改进（v2.1.186）**
• 功能介绍：新增 claude mcp login/logout 命令行，支持在无浏览器/SSH 环境下完成 MCP 服务器认证；/workflows 代理详情视图增加状态过滤（按 f 键）；插件安装页新增 Skills 区块；增加 teammateMode: "iterm2" 实验支持。
• 效果：远程开发或使用 SSH 时也能方便地管理与认证 MCP 服务；工作流状态查看更直观；插件能力发现更容易。
• 使用限制：Claude Code，teammateMode: iterm2 需搭配相应终端。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.186)

**Claude Code 会话恢复与界面微调（v2.1.191 / v2.1.185 / v2.1.195）**
• 功能介绍：v2.1.191 新增 /rewind 命令，可恢复到执行 /clear 之前的会话状态；修复滚动位置抖动、后台代理复活等问题。v2.1.185 将流式响应停滞提示改为“等待 API 响应·将在…后重试”，触发时间从 10 秒延长至 20 秒。v2.1.195 新增环境变量 CLAUDE_CODE_DISABLE_MOUSE_CLICKS 禁用全屏模式下鼠标点击/拖拽/悬停（保留滚轮）；修复钩子匹配及语音输入问题。
• 效果：误清对话后可以快速找回上下文，长会话中的 API 停顿不再频繁打断用户，全屏环境下的输入控制更灵活。
• 使用限制：Claude Code，部分修复需更新到对应版本。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.191) / [原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.185) / [原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.195)

**Claude Code 自动模式分类与遥测增强（v2.1.193 / v2.1.190）**
• 功能介绍：v2.1.193 增加 autoMode.classifyAllShell 设置，将所有 Bash/PowerShell 命令送入自动模式分类器（而非仅限任意代码执行模式）；自动模式拒绝原因现会写入转录、拒绝提示及 /permissions recent denials；新增 OpenTelemetry 日志事件用于记录模型回复文本（需设置环境变量开启）。v2.1.190 为问题修复与可靠性改进。
• 效果：开发者可以更细粒度地了解每次自动操作被拒绝的原因，并监控模型的实际输出与行为。
• 使用限制：Claude Code，遥测功能需配置 OpenTelemetry 环境变量。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.193) / [原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.190)
