[原文](https://www.anthropic.com/news/reflect-with-claude)

**Claude Code v2.1.202 – 动态工作流与遥测**
• 功能介绍：/config 新增“动态工作流大小”设置（小/中/大 agent 数），为指导性建议而非强制上限；为工作流生成的 agent 添加 workflow.run_id 和 workflow.name 的 OpenTelemetry 属性，便于从遥测数据重建工作流运行活动；修复内联 Ctrl+R 历史搜索接受/取消时的崩溃。
• 效果：让用户更灵活地调控工作流规模，增强可观测性；提升交互稳定性。
• 使用限制：Claude Code，在 /config 或设置文件中配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.202)

**Claude Code v2.1.203 – 登录提醒与 MCP 改进**
• 功能介绍：登录即将过期时发出警告，避免后台会话因未重新认证而中断；手动权限模式在底部状态栏新增灰色 ⏸ 标识，使权限模式始终可见；将会话的附加工作目录暴露给 MCP roots/list 并发送通知；修复 macOS 上打开/切换后台 agent 会话卡顿 15-20 秒的问题。
• 效果：提升长时间运行的可靠性，改善 MCP 集成体验，修复 macOS 交互延迟。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.203)

**Claude Code v2.1.204 – 后台钩子修复**
• 功能介绍：修复 headless 会话中 SessionStart 钩子事件不流式传输的问题，防止远程 worker 在钩子执行期间因空闲被回收。
• 效果：保证后台自动化任务与初始钩子可靠执行。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.204)

**Claude Code v2.1.205 – 防篡改与 JSON 可靠性**
• 功能介绍：增加自动模式规则阻止篡改会话记录文件；修复 --json-schema 在 schema 无效时静默输出非结构化内容以及 format 关键字被拒绝的问题；修复消息在 Claude 工作期间发送而因 --max-turns 限制丢失的问题；修复 Windows 工作树删除时因 NTFS 交接点或目录符号链接误删外部文件的问题。
• 效果：增强安全性与输出确定性，防止数据丢失，提升 Windows 环境的安全性。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.205)

**Claude Code v2.1.206 – 命令补全与项目医生**
• 功能介绍：为 /cd 命令添加目录路径建议，与 /add-dir 行为一致；/doctor 检查新增建议，修剪签入的 CLAUDE.md 中可从代码库推导出的重复内容；/commit-push-pr 自动允许 git push 到仓库配置的推送远程；网关 /login 支持 Anthropic 运营的公共网关端点；EnterWorktree 现在询问用户。
• 效果：提升路径输入效率，精简项目文档，简化 Git 操作，方便企业网关登录，改进工作树管理。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.206)

**Claude Code v2.1.207 – 自动模式免标志与长内容渲染修复**
• 功能介绍：自动模式在 Bedrock、Vertex AI 和 Foundry 上无需 CLAUDE_CODE_ENABLE_AUTO_MODE 标志即可使用（可通过 disableAutoMode 禁用）；修复终端冻结和响应包含长列表/表格/段落/代码块时的按键延迟；修复远程托管设置从非交互运行被永久记录为“同意”而不显示安全对话框的问题。
• 效果：简化云服务自动模式使用，流畅处理大量输出，避免安全设置被跳过。
• 使用限制：Claude Code，适用云平台托管。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.207)

**Claude Code v2.1.208 – 无障碍与 Vim 增强**
• 功能介绍：新增屏幕阅读器模式（--ax-screen-reader 或 CLAUDE_AX_SCREEN_READER=1 或设置），提供纯文本渲染；新增 vimInsertModeRemaps 设置，将插入模式下如 jj 的双键映射为 Escape；新增 CLAUDE_CODE_PROCESS_WRAPPER 环境变量，使 agent view 和后台服务通过公司启动器运行所有自生成进程。
• 效果：方便视障用户和 Vim 爱好者，满足企业统一进程管控要求。
• 使用限制：Claude Code，通过命令行或设置启用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.208)
