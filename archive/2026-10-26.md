**🅰️ Claude 产品更新详解**

**Claude Code v2.1.310**
- 功能介绍: 新增 Monitor 工具与插件监视器,覆盖 Bedrock、Vertex、Foundry 及禁用遥测/非必要流量的环境;同时在这些环境中阻止长时间前台 sleep

- 使用限制: Claude Code CLI,所有支持的环境;自动重试机制无需配置

**Claude Code v2.1.309**

- 效果: 沙箱隔离更可靠,防止命令通过启动文件或符号链接逃逸;MCP 配置文件不再被意外篡改,权限边界更清晰
- 使用限制: Claude Code CLI, macOS / Linux 沙箱环境
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.309)
