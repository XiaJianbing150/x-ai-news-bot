🅰️ **Claude 产品更新详解**

**Claude Code v2.1.224 自托管运行环境（Self‑hosted environments）**
• 功能介绍：新增 claude self-hosted-runner 命令，可将用户自己的机器或容器注册为 **Claude Code** Web、移动端和桌面端会话的执行目标，进入 Team / Enterprise 计划即可使用。
• 效果：团队可以将敏感的构建、测试或部署任务锁定在内部基础设施上执行，而不是在云端默认沙箱，满足合规要求的同时保持 Claude Code 的全平台无处不在的开发体验。
• 使用限制：Team / Enterprise 计划，支持 Web / Mobile / Desktop 客户端发起；需要在自有机器或容器上运行 claude self-hosted-runner 并完成配对。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)

**Claude Code v2.1.224 归档插件安装源（Archive plugin source）**
• 功能介绍：新增从 HTTPS 拉取 .zip 包安装插件的能力，无需 git 或 npm，且可选 SHA‑256 指纹校验。
• 效果：可以在气隙或受限网络环境中离线分发和安装插件，并通过指纹保证包的完整性，显著降低企业场景里的供应链风险。
• 使用限制：Claude Code 任意版本均可使用该安装方式；需提供合法的 HTTPS 链接与可选的 SHA‑256 值。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)

**Claude Code v2.1.223 Marketplace 组织级通配符规则**
• 功能介绍：在 strictKnownMarketplaces 和 blockedMarketplaces 受管设置中增加 owner/* 通配符，可一次性允许或阻止某 GitHub 组织下的所有市场仓库。
• 效果：企业管理员无需逐个添加仓库，能快速为整个组织（如内部工具团队）开通市场访问，提升治理效率。
• 使用限制：适用于 Team / Enterprise 计划的受管设置；通配符作用于 GitHub 组织。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)

**Claude Code v2.1.221 Focus view（专注视图）**
• 功能介绍：在 VS Code 扩展中加入聊天菜单开关“Claude Code: Toggle Focus view”（快捷键 Ctrl+Alt+F），将工具活动隐藏到可按轮次展开的摘要后方，并保留实时运行指示器。
• 效果：开发者可以在 Claude Code 大量并发执行工具时保持界面清爽，专注于对话核心，需要时再展开查阅细节，适合长时间的重度编码任务。
• 使用限制：需安装 Claude Code VS Code 扩展；通过 Ctrl+Alt+F 或命令面板切换。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)

**Claude Code v2.1.221 凭证掩码模式（Credential masking for sandbox）**
• 功能介绍：在 Linux 和 WSL 上新增 mode: "mask" 沙箱凭证文件处理——沙箱命令读取的是哨兵副本，沙箱代理在出口处替换为真实凭证；macOS 上通过 fallback 实现类似效果。
• 效果：沙箱化运行脚本或命令时，凭证不会以明文暴露给沙箱内进程，提高安全防护水平，尤其适用于 CI/CD 与自动化场景。
• 使用限制：Linux / WSL 环境；需要在沙箱配置文件中声明 mode: mask 并指定提取正则。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)

**Claude Code v2.1.222 工作树会话隔离强化**
• 功能介绍：修复了工作树隔离会话及其子代理可能对主检出库执行破坏性 git 命令的问题，现在隔离会应用到所有会话类型的文件编辑和 Bash 执行。
• 效果：使用 git worktree 并行处理多项任务时，不会因为一个会话的误操作污染主工作区，多任务更安全、可并行。
• 使用限制：所有 Claude Code 用户；该修复自动生效无需额外配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.222)
