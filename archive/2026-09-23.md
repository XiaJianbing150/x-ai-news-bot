**Claude Code v2.1.280 — Claude Opus 5.5 上线**
- 功能介绍: 新增 **Claude Opus 5.5**（claude-opus-5-5），成为默认 Opus 模型，支持 1M context，定价 $4/$20 每 Mtok，cache reads $0.20/Mtok；全屏模式下 /skills 列表支持滚轮滚动，/plugin 中技能状态选项可点击；新增 **CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH** 环境变量，可调整 MCP 工具描述与服务器指令的 2,048 字符上限。
- 效果: 用户获得更强默认模型与更长上下文；MCP 描述长度可调解决了复杂工具说明被截断的问题；全屏模式鼠标交互更顺手。
- 使用限制: Claude Code（CLI），需 API / Pro / Max 等账号；Opus 5.5 按 token 计费。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.280)

**Claude Code v2.1.278 — Auto mode 默认改用服务端分类器**
- 功能介绍: Claude API 与 Enterprise 用户，以及 Bedrock / Vertex / Foundry / gateways 上的 auto mode 默认切换到服务端分类器，不再对分类器开销计费；/status 新增 Auto mode server 行显示当前会话分类器运行位置。
- 效果: 降低 auto mode 使用成本，用户不再为分类器本身付费；状态面板可直观确认分类器是否在服务端运行。
- 使用限制: Claude Code；Bedrock / Vertex / Foundry / gateways 可用 **CLAUDE_CODE_AUTO_MODE_SERVER=0** 退出（推测）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)
