🅰️ **Claude 产品更新详解**

**Claude Sonnet 5 模型发布**
• 功能介绍：Anthropic 推出新一代旗舰模型 Sonnet 5，在编码、智能体、专业级任务中达到前沿性能，原生支持 1M token 上下文窗口。
• 效果：开发者可用单一模型处理超长代码库、整本法律文档或多轮复杂 Agent 任务，编码准确率和 agent 决策逻辑显著优于前代。作为对比，Sonnet 5 在 Claude Code 中开箱即用，8 月 31 日前输入/输出定价低至 $2/$10 per Mtok。
• 使用限制：已上线 API 与 Claude Code（v2.1.197+），Claude Pro/Max、Team、Enterprise 用户均可直接使用，促销价持续至 2026-08-31。
[原文](https://www.anthropic.com/news/claude-sonnet-5)

**Claude Science 科研工作台正式开放**
• 功能介绍：Anthropic 推出 Claude Science，一个面向科学家的可定制 AI 工作台，深度集成常用研究工具与软件包，输出可审计的 Artifact，并可灵活调用计算资源。
• 效果：研究人员能在同一环境中完成数据清洗、建模、文献分析与可视化，所有步骤自动留痕，方便复现与团队协作。对比通用聊天界面，它针对科学工作流大幅降低手动切换工具的成本。
• 使用限制：需通过 Anthropic 申请访问，定位为科研团队/实验室，当前可能采用受邀制。
[原文](https://www.anthropic.com/news/claude-science-ai-workbench)

**Claude Code 默认集成 Claude Sonnet 5**
• 功能介绍：Claude Code v2.1.197 起将 Sonnet 5 设为默认模型，自动提供 1M 上下文和促销计费。
• 效果：用户升级后所有会话直接享受最强代码与 agent 能力，无需手动切换模型，长上下文场景也能稳定运行。
• 使用限制：升级至 v2.1.197+ 即可使用，需有 API 额度或 Max/Team/Enterprise 授权。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.197)

**子代理自动后台运行 & Chrome 全面可用**
• 功能介绍：v2.1.198 起子代理默认切换到后台运行，主对话可继续工作，子代理完成时通知；Claude in Chrome 结束灰度，全面开放。
• 效果：多步骤任务不会被单个子代理卡死，可并行执行多个查询，整体效率提升明显。Chrome 用户现在无需插件就能在浏览器中调用 Claude Code。
• 使用限制：Claude Code 所有平台支持；Chrome 需最新版本，登录后可启用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.198)

**/dataviz 可视化指导技能上线**
• 功能介绍：v2.1.198 新增 /dataviz 斜杠技能，提供图表和仪表板设计指导并内建色板校验器。
• 效果：在数据分析或展示时直接调用，Claude 会给出专业设计建议并校验颜色可读性，适合非设计人员快速产出商业级图表。
• 使用限制：Claude Code 内键入 /dataviz 即可触发，所有层级可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.198)

**堆叠斜杠技能调用**
• 功能介绍：v2.1.199 支持一次性堆叠调用多个技能（例如 /skill-a /skill-b do XYZ），最多加载 5 个前置技能。
• 效果：无需分步执行，复杂工作流可在一句指令中激活多个技能，如先调用数据处理技能再调用图表技能，减少交互轮次。
• 使用限制：Claude Code，技能需预先配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.199)

**AskUserQuestion 对话框不再自动继续 & 默认权限模式改为手动**
• 功能介绍：v2.1.200 将“询问用户”对话框的默认行为从自动继续改为手动确认，并可通过 /config 设置空闲超时；同时将默认权限模式调整为手动（Manual），某些危险操作不会自动批准。
• 效果：防止意外操作，尤其是自动脚本或后台任务，提高安全控制；用户若需要自动应答可自行开启超时自动继续。
• 使用限制：所有 Claude Code 用户，新安装即生效，旧配置可手动迁移。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.200)

**动态工作流大小设置**
• 功能介绍：v2.1.202 在 /config 中加入“动态工作流大小”选项（小/中/大），指导 Claude 生成对应数量的代理，并新增 telemetry 属性 workflow.run_id 与 workflow.name。
• 效果：用户可依据任务复杂度（如小规模脚本或大型重构）给出代理规模建议，Claude 不会超出上限，避免资源浪费；遥测数据便于团队复盘工作流运行。
• 使用限制：Claude Code，通过 /config 调整，代理数量为建议值。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.202)

**登录过期预警 & 手动模式状态徽章**
• 功能介绍：v2.1.203 在登录即将过期时弹出警告以提前续登录，手动权限模式下在底部状态栏显示灰色 ⏸ 徽章，并新增对 MCP roots/list 变更的通知。
• 效果：后台长时间会话不会被意外中断；视觉徽章一目了然地知道当前处于手动确认模式，提升透明度。
• 使用限制：所有 Claude Code 环境自动享受。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.203)

**自动模式防篡改会话记录**
• 功能介绍：v2.1.205 为自动模式添加禁止修改会话转录文件的规则。
• 效果：在跑自动化 Agent 时无法篡改操作记录，保障审计与调试的完整性，对合规要求高的团队尤其重要。
• 使用限制：Claude Code v2.1.205+，自动模式自动生效。
