🅰️ **Claude 产品更新详解**

**Claude Opus 4.8 发布**
• 功能介绍：推出新一代旗舰模型 Claude Opus 4.8，大幅提升推理、编码与复杂任务处理能力，是当前最强 Claude。
• 效果：默认高 effort 模式，可用 /effort xhigh 解锁极限表现；在 Claude Code 中支持动态工作流，可协调数十到上百个 agent，自动拆分并完成巨型任务。
• 使用限制：API 及 Claude Code 中可用；Pro/Max 用户可直接使用（推测），Fast mode 2x 标准费率换取 2.5x 速度。
[原文](https://www.anthropic.com/news/claude-opus-4-8)

**Claude Code 动态工作流**
• 功能介绍：v2.1.154 起支持动态工作流，用户用自然语言描述目标，Claude 在后台自主规划、调度多个 agent 协同执行。
• 效果：将复杂任务拆分为可并行的子任务，运行状态通过 /workflows 查看，极大提高大项目的处理规模和完成度。
• 使用限制：Claude Code，依赖 Opus 4.8（推测需付费层级）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.154)

**插件系统自动加载与创建**
• 功能介绍：v2.1.157 起，.claude/skills 目录下的插件无痛自动加载，无需发布或连接 market；新增 claude plugin init <name> 脚手架命令；/plugin 实参自动补全。
• 效果：本地插件开箱即用，开发者可快速构建技能包，用户零配置享受扩展。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.157)

**一键代码审查修复**
• 功能介绍：/code-review --fix 在审查后自动将复用、简化与效率建议应用到工作树，/simplify 等同于 /code-review --fix；技能和斜杠命令可设置 disallowed-tools 禁止特定工具。
• 效果：审查即修复，零手动合并改动；权限控制更细，提升安全性与专注度。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.152)

**用量明细与诊断增强**
• 功能介绍：/usage 按技能、子代理、插件、MCP 服务器分类显示消耗；/diff 详情支持键盘滚动；Markdown 渲染 GFM 任务列表；新增 skipLfs 选项；/doctor 提供修复提示。
• 效果：精细管控成本来源，操作终端体验更流畅，问题排查更快。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**Auto mode 支持云平台**
• 功能介绍：v2.1.158 将 Auto mode 扩展到 Amazon Bedrock、Google Vertex AI 和 IBM watsonx Foundry，适用于 Opus 4.7/4.8。
• 效果：企业可在自有云上运行高自主 Claude Code 代理，通过 CLAUDE_CODE_ENABLE_AUTO_MODE=1 开启。
• 使用限制：需配套的 Bedrock/Vertex/Foundry 环境与 Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.158)
