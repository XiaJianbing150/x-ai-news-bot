**Claude Code v2.1.273**
- 功能介绍: 新增一组可选的 LLM 网关请求头(x-claude-code-request-class、x-claude-code-agent-type、x-claude-code-prev-tool-durations、x-claude-code-compaction、x-claude-code-context-compacted),通过 CLAUDE_CODE_GATEWAY_HINT_HEADERS=1 开启;MCP server 会话中断连且自动重连放弃时新增通知,指向 /mcp;支持从 Claude app 对 --remote-control 或 /remote-control 启动的会话进行 fork。
