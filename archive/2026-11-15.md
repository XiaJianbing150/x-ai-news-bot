**🅰️ Claude 产品更新详解**

**Claude Fable 5.2 与 Claude Mythos 5.2**
- 功能介绍: Anthropic 发布两款新模型 — **Claude Fable 5.2** 与 **Claude Mythos 5.2**,其中 Fable 5.2 成为 Claude Code 中的默认 Fable 模型。
- 效果: Fable 5.2 提供 1M context,定价 $8/$40 per Mtok,cache reads 为 $0.20/Mtok;面向长上下文与高吞吐场景。Mythos 5.2 定位尚未在版本说明中展开,推测为并行发布的另一条模型线。
- 使用限制: 通过 Anthropic API 与 Claude Code 使用;Fable 5.2 已在 Claude Code v2.1.321 中设为默认 Fable 模型(推测 API 需指定模型名 claude-fable-5-2)。
[原文](https://www.anthropic.com/claude-fable-and-mythos-5-2)

**Claude Code v2.1.325**
- 功能介绍: 修复 zstd 压缩响应解码的安全问题;在 VS Code 等集成终端中,当 Claude 读取或编辑过 Jupyter notebook 后,增加重新运行 notebook cell 的 spinner 提示;组织策略拦截请求时,错误下方新增提示,告知用户可运行 /rewind 修改消息或 /clear 继续。
- 效果: 提升安全性与 notebook 工作流的可操作性,减少策略拦截后的困惑。
- 使用限制: Claude Code(CLI / IDE 集成),版本 v2.1.325。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)

**Claude Code v2.1.323 — Code Mode(实验性)**
- 功能介绍: 新增 **Code Mode**,一个实验性 opt-in 模式,Claude 通过编写 JavaScript 来调用自身工具;plugin.json 新增 engines["claude-code"] 字段,超出声明版本范围的插件不再安装/更新/加载;新增对插件 TypeScript hooks 模块的类型检查。
- 效果: Code Mode 让 Claude 以代码方式编排工具调用,适合需要复杂控制流的自动化任务;插件版本约束与类型检查提升插件生态稳定性。
- 使用限制: 实验性,需手动开启;组织可关闭。文档见 code.claude.com/docs/en/code-mode。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)

**Claude Code v2.1.322**
- 功能介绍: 在 Vertex 的 global、us、eu 区域新增 fast mode,若 Vertex 拒绝则回退到 standard speed。
- 效果: 在 Google Cloud Vertex 上运行 Claude Code 时获得更快响应。
- 使用限制: Vertex 区域限定 global / us / eu。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)

**Claude Code v2.1.321**
- 功能介绍: 将 **Claude Fable 5.2** 设为默认 Fable 模型;claude remote-control 新增 --settings  参数,为每个启动的 session 应用 settings 文件;修复 MCP OAuth 在服务器重定向时把 refresh token 等 secrets 发送到其他 host 的问题;修复一个 read 相关边界情况。
- 效果: 新默认模型 + remote-control 的批量 settings 管理,适合多 session 运维;OAuth 修复堵住凭据泄露路径。
- 使用限制: Claude Code v2.1.321;--settings 需重启 remote-control 后对新 session 生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)

**Claude Code v2.1.319**
- 功能介绍: 调整 auto mode 行为 — 当 telemetry 或 feature flags 关闭(包括 LLM gateway 后)时,服务器无法检查的调用会被询问或拒绝,不再回退到内置 classifier;新增 CLAUDE_CODE_AUTO_MODE_SERVER=0 保留旧行为;LLM gateway 后可用 CLAUDE_CODE_AUTO_MODE_SERVER=1 强制开启服务端检查。
- 效果: 在受限环境中提供更可预测的 auto mode 权限行为,减少隐式回退带来的不确定性。
- 使用限制: Bedrock、Vertex、Foundry 行为不变;环境变量控制。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)
