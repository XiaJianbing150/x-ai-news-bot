🅰️ Claude 产品更新详解

**Claude Code v2.1.251：模型切换钩子 + 远程控制流**
- 功能介绍: 新增 PreModelSwitch / PostModelSwitch hook，可在模型切换前/后 block、confirm 或 annotate；SessionStart resume hook 现在会收到会话陈旧度与预估重缓存成本；Remote Control 客户端可实时流式查看前台 subagent 的工具调用与结果；/usage 增加 Spend limit bar，并新增 rate_limits.spend_limit 状态字段。
- 效果: 团队能审计和控制模型切换，远程观察前台 agent 实际执行，花费上限更直观。
- 使用限制: Claude Code；推测适用于 Pro / Max / Team / Enterprise 或 API 用户，Remote Control 需对应客户端。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.251)

**Claude Code v2.1.248：受限模式与缓存 TTL**
- 功能介绍: 新增 --restricted（或 CLAUDE_CODE_RESTRICTED=1）：移除运行命令/代码的内置工具和 WebFetch（除非 --tools 明确列出），文件工具限制在工作目录内，拒绝 bypassPermissions，并忽略 user、project、local settings；agent frontmatter 新增 experimental.cacheTtl（如 "5m" / "1h"）；claude self-hosted-runner 新增 --client-label。
- 效果: 更适合处理不可信仓库或脚本，降低任意命令执行风险；可针对 agent 单独设置 prompt cache TTL；自托管 runner 便于识别来源。
- 使用限制: Claude Code；安全敏感或自托管场景，推测企业/团队配置更常用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.248)

**Claude Code v2.1.247：SendFeedback 工具与自定义提示**
- 功能介绍: 新增 SendFeedback 工具，会话出错时 Claude 可起草反馈报告，用户审阅后从 /feedback 发送（可用 feedbackDrafts 关闭）；spinnerTipsOverride 支持 {id, text, cooldownSessions, priority}、tipsFile 和 label，组织可轮换自己的提示；Bash 权限提示新增一键切到 auto mode。
- 效果: 减少反馈摩擦，组织可定制 CLI 中的提示文案，权限批准更快。
- 使用限制: Claude Code；组织自定义提示需配置 settings。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.247)

**Claude Code v2.1.246：Auto mode 权限与启动警告**

- 效果: 避免误授权，提高自动模式的可见性和可控性。
- 使用限制: Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.246)
