**🅰️ Claude 产品更新详解**

**Claude Code v2.1.251**
- 功能介绍: 新增 PreModelSwitch / PostModelSwitch hook 事件，可 block、confirm 或 annotate 模型切换；SessionStart resume hooks 现在会收到会话陈旧度和预估 re-cache 成本；Remote Control 客户端可实时流式查看前台 subagent 的工具调用与结果；/usage 增加 Spend limit bar，并新增 rate_limits.spend_limit 状态字段。
- 效果: 适合团队做模型切换审批、恢复旧会话前的成本评估、远程调试子代理；花钱进度更直观。
- 使用限制: Claude Code CLI，随版本发布；具体取决于账号/workspace 的 spend limit 配置（推测）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.251)

**Claude Code v2.1.248**
- 功能介绍: 新增 --restricted 或 CLAUDE_CODE_RESTRICTED=1，移除运行命令/代码的内置工具和 WebFetch（除非在 --tools 中指定），文件工具限制在工作目录，拒绝 bypassPermissions，并忽略 user/project/local settings；agent frontmatter 新增 experimental.cacheTtl；新增 claude self-hosted-runner --client-label。
- 效果: 面向高合规/受限环境的安全模式；可按 agent 调整 prompt cache TTL；自托管 runner 可打标签。
- 使用限制: Claude Code CLI；更偏 Enterprise/受限部署；cacheTtl 为实验项。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.248)

**Claude Code v2.1.247**
- 功能介绍: 新增 SendFeedback 工具，出问题时 Claude 可起草反馈报告，在 /feedback 中查看并发送（可用 feedbackDrafts 关闭）；spinnerTipsOverride 支持组织在内置提示之外轮换自己的 tips；Bash 权限提示新增指向 auto mode 的一键切换提示。
- 效果: 故障反馈更容易，组织提示可定制，权限确认更快捷。
- 使用限制: Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.247)
