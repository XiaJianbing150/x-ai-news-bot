🅰️ Claude 产品更新详解

**Claude Code v2.1.239–v2.1.251 连续更新**
• 功能介绍: 近一周共发布 v2.1.239、240、241、243、245、246、247、248、250、251。新增 **PreModelSwitch / PostModelSwitch hook**（可 block / confirm / annotate 模型切换）；**SessionStart resume hook** 新增会话陈旧度与预计重缓存成本；**Remote Control** 客户端可实时流式查看前台子代理工具调用与结果；**/usage** 增加 spend limit 条，并给开发者新增 **rate_limits.spend_limit**；新增 **SendFeedback** 工具（会话出问题时草拟反馈，可从 /feedback 发送）；**spinnerTipsOverride** 支持组织自定义提示；**/permissions** 新增 Auto mode 规则页；Bash 通配符权限警告；回合完成时间显示；新增 **--restricted** 受限模式；agent frontmatter 新增 **experimental.cacheTtl**；**/claude-api upgrade** 可迁移 Python 项目从 anthropic 0.x 到 1.x；成本估算纳入 data-residency 工作区 1.1× 美国推理溢价；修复 Linux glibc 2.44 启动崩溃、全屏空白等。
• 效果: 开发者可更精细控制模型切换和权限、预估重缓存成本；受限模式适合沙箱/CI 等不可信环境；反馈草稿、auto 权限、spend 限额提升可观测性；Python SDK 迁移更顺滑，成本显示更贴近真实计费。
• 使用限制: Claude Code CLI；部分能力需要 Remote Control、Bedrock/Vertex/Foundry、data-residency workspace 或显式配置；详见各版本说明。

🅾️ OpenAI 产品更新详解

**ChatGPT for Teachers 扩展至 55 个美国学区**
• 功能介绍: OpenAI 将 **ChatGPT for Teachers** 推广到 55 个美国学校系统，为超过 10 万名教育工作者和员工提供安全的 AI 工具、培训和支持。
• 效果: 教师可把 ChatGPT 用于备课、行政和管理场景，并获得学区级安全与培训支持。
• 使用限制: 美国 K-12 学区/教师；需所在学区加入；平台推测为 Web/App。
[原文](https://openai.com/index/bringing-chatgpt-for-teachers-to-more-us-school-districts)

**ChatGPT Work 与 Codex 的 Admin 插件**
• 功能介绍: 新增 **Admin plugin**，可在 **ChatGPT Work** 和 **Codex** 中分析工作区用量、管理成员与权限、调整限额、处理管理员请求。
• 效果: 管理员无需离开工作界面即可完成团队、额度和安全策略管理。
• 使用限制: ChatGPT Work / Codex 管理员场景；档位推测为 Work 及以上/Enterprise。
[原文](https://openai.com/index/introducing-admin-plugin)

**GPT-5.6 在 Kiro 中可用**
• 功能介绍: **GPT-5.6** 现已在 **Kiro** 中可用，面向软件开发者的规划、构建、审查和测试环节，提供更好的价格性能。
• 效果: 开发者以更优性价比调用 GPT-5.6 执行编码任务，降低软件构建与审查成本。
• 使用限制: Kiro 产品内可用；具体档位/订阅推测为开发者或团队账号。
[原文](https://openai.com/index/gpt-5-6-in-kiro)

**Jalapeño 推理芯片公布首轮结果**
• 功能介绍: OpenAI 自研推理芯片 **Jalapeño** 首轮实测显示行业领先的推理速度与能效，具备更高吞吐和更低延迟。
• 效果: 可加快模型推理、降低单位智能成本，为规模化产品供应提供硬件基础。
• 使用限制: 仍属 OpenAI 基础设施层，不直接向用户提供；暂无公开上线时间。
[原文](https://openai.com/index/jalapeno-first-results)
