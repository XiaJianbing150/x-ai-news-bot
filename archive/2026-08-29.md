**🅰️ Claude 产品更新详解**

**Claude Code v2.1.251**
• 功能介绍：新增 **PreModelSwitch / PostModelSwitch** hook 事件，可在模型切换前/后 block、confirm 或 annotate；**SessionStart resume hooks** 现在接收 session staleness 与预计 re-cache 成本；Remote Control 客户端可实时流式传输前台 subagent 的工具调用与结果；**/usage** 增加 Spend limit bar，状态行增加 **rate_limits.spend_limit**。
• 效果：开发者能更细粒度控制模型切换；续接会话前可评估重缓存成本；远程监控前台 subagent 更实时；支出上限可视化。
• 使用限制：Claude Code（推测覆盖 CLI / IDE / Remote Control），需升级到 v2.1.251。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.251)

**Claude Code v2.1.250**
• 功能介绍：Bug 修复与可靠性改进，无具体功能披露。
• 效果：稳定性提升，建议升级。
• 使用限制：Claude Code。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.250)

**Claude Code v2.1.248**
• 功能介绍：新增 **--restricted**（或 **CLAUDE_CODE_RESTRICTED=1**），移除可运行命令/代码的内置工具与 WebFetch（除非在 **--tools** 中明确点名），文件工具限制在工作目录内，拒绝 **bypassPermissions**，并忽略用户/项目/本地设置文件；agent frontmatter 新增 **experimental.cacheTtl**（"5m" 或 "1h"）；新增 **claude self-hosted-runner --client-label**。
• 效果：适合 CI / 企业 / 不可信环境的最小权限运行；可按 agent 单独设置 prompt cache TTL。
• 使用限制：Claude Code；**--restricted** 为限制模式；**experimental.cacheTtl** 为实验配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.248)

**Claude Code v2.1.247**
• 功能介绍：新增 **SendFeedback** 工具，出错时 Claude 可起草反馈报告，用户审阅后从 **/feedback** 发送；**spinnerTipsOverride** 支持 {id, text, cooldownSessions, priority}、tipsFile、label，组织可轮换自定义提示；Bash 权限提示新增指向 auto mode 的提示，且可一键切换。
• 效果：反馈流程更顺畅；企业可定制加载提示；引导更多用户开启 auto mode。
• 使用限制：Claude Code；**feedbackDrafts** 设置可关闭反馈草稿。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.247)

**Claude Code v2.1.246**
• 功能介绍：对 wildcard 出现在 subcommand 前的 Bash allow 规则（如 **Bash(git * main)**）新增启动警告；**/permissions** 新增 Auto mode 标签页，可查看/编辑 auto mode 分类规则；回合完成时间显示在时长行；修复 fullscreen 模式重设终端后空白 transcript 等。
