**🅰️ Claude 产品更新详解**

**Claude Code v2.1.278 — Auto mode 计费切换至服务端分类器**
- 功能介绍: 针对 Claude API 和 Enterprise 用户,以及在 Bedrock / Vertex / Foundry 和各类网关上运行的场景,auto mode 默认改用服务端分类器,不再对分类器开销计费;若发生计费回退会给出警告。
- 效果: 用户在使用 auto mode 时不再被分类器消耗额外 token 成本,尤其对通过云平台或网关接入的团队,成本更可控;/status 中新增 Auto mode server 行,可直接查看当前会话的分类器运行位置。
- 使用限制: Claude API / Enterprise 用户;Bedrock / Vertex / Foundry / gateways 环境;可用 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 选择退出(推测)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)

**Claude Code v2.1.277 — AGENTS.md 支持与网关代理增强**
- 功能介绍: 项目中没有 CLAUDE.md 时,Claude Code 会读取 AGENTS.md 作为项目指令;新增 `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` 用于仅出口为正向代理的网关,出站请求将主机名交给代理而非本地解析;网关 upstream 支持可选 headers map 发送静态头。
- 效果: 使用 AGENTS.md 规范的项目无需再维护 CLAUDE.md,降低多工具协作时的配置成本;代理边界设置解决了特定企业网络拓扑下 DNS 解析失败的问题。
- 使用限制: Claude Code;AGENTS.md 支持暂未覆盖 Bedrock / Vertex / Foundry(推测);可在 /config 的 "Project instructions" 中切换。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)

**Claude Code v2.1.274 — 内存临界警告与 MCP 启动等待限制**
- 功能介绍: 内存使用达到临界值时显示可见警告,并给出释放内存或安全重启的步骤;新增 `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` 限制首个非交互回合等待 MCP 服务器连接的时间(0 表示不等待);OpenTelemetry trace span 增加 effort 属性,新增 managed_settings_resolved 事件。
- 效果: 长时间运行的会话在内存耗尽前能提前预警,避免崩溃丢失上下文;MCP 启动等待可配置后,启动慢的 MCP 服务器不再无限阻塞首个请求。
