🅰️ Claude 产品更新详解

**Claude for Teachers**
• 功能介绍：Anthropic 推出专为教育工作者打造的 Claude 体验，集成教案生成、课堂活动设计、学生评估等教学常用工具。
• 效果：教师可快速创建个性化学习材料，大幅减少备课时间，将精力集中在与学生的互动上。
• 使用限制：面向 K-12 及高等教育教师，需教育邮箱验证（推测）；当前为邀请制，平台预计为 Web。
[原文](https://www.anthropic.com/news/claude-for-teachers)

**Reflect with Claude**
• 功能介绍：新增“反思”模式，让用户回顾与 Claude 的历史对话，获得使用习惯总结、个人洞察与改进建议。
• 效果：帮助用户了解自己的工作模式（如提问风格、高频任务），优化后续交互，提升整体产出质量。
• 使用限制：可能面向所有 Claude 用户档位（Free/Pro/Team），Web 端逐步推出。
[原文](https://www.anthropic.com/news/reflect-with-claude)

**Claude Code 近期更新（v2.1.206–v2.1.214）**

**/fork 变为后台会话**
• 功能介绍：/fork 命令现在将当前对话复制为新的后台会话，在 claude agents 中以独立行显示，原内联子代理改为 /subtask。
• 效果：主会话继续工作的同时让分支任务并行运行，适合同时处理多线程开发。
• 使用限制：Claude Code v2.1.212+，所有 Claude 订阅及 API 用户均可使用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**WebSearch 调用次数上限**
• 功能介绍：新增会话级 WebSearch 工具调用限制，默认 200 次，可通过环境变量 CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION 调整。
• 效果：防止搜索循环导致的 token 浪费，让开发者更好地控制成本。
• 使用限制：Claude Code v2.1.212+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**Auto Mode 在云平台上默认可用**
• 功能介绍：Bedrock、Vertex AI、Foundry 环境下自动模式不再需要额外的 opt-in 环境变量，且可通过设置 disableAutoMode 关闭。
• 效果：企业云部署的用户可一键启用自动执行，降低配置门槛。
• 使用限制：Claude Code v2.1.207+，适用于云平台部署。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.207)

**屏幕阅读器模式**
• 功能介绍：通过 --ax-screen-reader 或环境变量 CLAUDE_AX_SCREEN_READER=1 将界面渲染为纯文本，便于屏幕阅读器使用。
• 效果：视障开发者可无障碍使用 Claude Code。
• 使用限制：Claude Code v2.1.208+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.208)

**Vim 模式插入映射**
• 功能介绍：支持 vimInsertModeRemaps 设置，可将 jj 等两次按键映射为 Escape。
• 效果：Vim 用户无需移手即可退出插入模式，编辑体验更流畅。
• 使用限制：Claude Code v2.1.208+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.208)

**/cd 路径补全**
• 功能介绍：/cd 命令现在提供目录路径自动建议，与 /add-dir 行为一致。
• 效果：快速导航项目目录，减少手动输入。
• 使用限制：Claude Code v2.1.206+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.206)

**/commit-push-pr 自动允许远程推送**
• 功能介绍：/commit-push-pr 流程自动允许 git push 到仓库的推送远程（remote.pushDefault 或唯一 remote），无需额外确认。
• 效果：一键完成提交、推送与创建 PR，加速 Git 工作流。
• 使用限制：Claude Code v2.1.206+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.206)

**/doctor 检查优化 CLAUDE.md**
• 功能介绍：/doctor 诊断现在会建议裁减已提交的 CLAUDE.md 中冗余内容（Claude 可从代码中自行推导的部分）。
• 效果：保持自定义指令文件精简，减少上下文占用，提升响应速度。
• 使用限制：Claude Code v2.1.206+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.206)

**Process Wrapper 企业管控**
• 功能介绍：新增 CLAUDE_CODE_PROCESS_WRAPPER 环境变量，要求所有 Claude Code 自生成进程通过指定的包装脚本启动。
• 效果：IT 管理员可对 Claude Code 的衍生进程实施安全审计、日志记录或策略控制，满足企业合规需求。
• 使用限制：Claude Code v2.1.208+，面向企业部署。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.208)

🅾️ OpenAI 产品更新详解

**ChatGPT Work**
• 功能介绍：ChatGPT Work 是一款能跨应用与文件自主行动的代理，可长时间跟随项目，即使无人看管也能将目标转化为成品。
• 效果：可自动完成如生成 PRD、跨工具协调、数据整理等多步复杂任务，连续工作数小时，显著提升个人与团队生产力。
• 使用限制：ChatGPT Pro 或更高档位（推测），已向部分用户开放，平台为 Web 和桌面应用。
[原文](https://openai.com/index/chatgpt-for-your-most-ambitious-work)

**GPT-5.6 模型发布**
• 功能介绍：OpenAI 推出下一代前沿模型 GPT-5.6，实现每 token 更高智能、更优性能成本比，并支持按需扩展算力以应对高难度任务。
• 效果：在复杂推理、编程、多语言等场景中表现更强，企业可在相同预算下获得更高质量输出。
• 使用限制：已上线 API 和 ChatGPT，具体档位可用性见官方定价；取代 GPT-5.5 成为默认模型（推测）。
[原文](https://openai.com/index/gpt-5-6)

**GPT-5.6 登陆 Microsoft 365 Copilot**
• 功能介绍：GPT-5.6 现已成为 Microsoft 365 Copilot 的首选模型，驱动 Word、Excel、PowerPoint、Chat 和 Cowork 等组件。
• 效果：Microsoft 365 用户将在文档生成、数据分析、演示设计等方面获得质量跃升。
• 使用限制：需 Microsoft 365 Copilot 许可，逐步推送中。
[原文](https://openai.com/index/gpt-5-6-preferred-model-microsoft-365-copilot)

**GPT-Red 自动红队系统**
• 功能介绍：GPT-Red 是 OpenAI 的自动化红队框架，通过自博弈方式发现模型的安全漏洞、越狱与提示注入弱点，并用于自我改进。
• 效果：加速安全迭代，提升模型稳健性与对齐水平，安全评估结果已应用于 GPT-5.6 等新模型。
• 使用限制：目前为内部研究工具，暂未对外开放（推测）。
[原文](https://openai.com/index/unlocking-self-improvement-gpt-red)
