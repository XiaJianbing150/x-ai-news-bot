**🅰️ Claude 产品更新详解**

**Claude Fable 5.2 与 Claude Mythos 5.2**
- 功能介绍: Anthropic 正式发布 **Claude Fable 5.2** 和 **Claude Mythos 5.2** 两款新模型,Fable 5.2 成为默认 Fable 模型,支持 1M 上下文。
- 效果: Fable 5.2 定价 $8/$40 per Mtok,cache reads 仅 $0.20/Mtok,大幅降低长上下文场景成本。Mythos 5.2 同步推出,面向不同工作负载。Claude Code 已将其设为默认模型,开发者可直接体验。
- 使用限制: 通过 Claude API 与 Claude Code 可用;Fable 5.2 为 Claude Code 默认模型,1M 上下文窗口。(推测) 具体档位与平台覆盖以官方后续公告为准。
[原文](https://www.anthropic.com/claude-fable-and-mythos-5-2)

**Claude Code v2.1.322 — Vertex fast mode**
- 功能介绍: 在 Vertex 的 global、us、eu 区域新增 fast mode,若 Vertex 拒绝则自动回退到 standard speed。
- 效果: 使用 Google Cloud Vertex 跑 Claude Code 的团队可以获得更快的响应速度,同时保持兼容性。
- 使用限制: Claude Code + Vertex 用户,global/us/eu 区域。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)

**Claude Code v2.1.321 — Fable 5.2 接入与 remote-control 增强**
- 功能介绍: 新增 **claude-fable-5-2** 模型并设为默认 Fable;为 `claude remote-control` 增加 `--settings ` 参数,可对每个 session 应用 settings 文件;修复 MCP OAuth 重定向时向其他 host 泄露 refresh token 等敏感信息的问题。
- 效果: 远程控制多 session 时配置管理更灵活;OAuth 修复堵住了一个安全漏洞。
- 使用限制: Claude Code CLI;remote-control 的 settings 文件变更后需重启 remote-control 才会对新 session 生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)

**Claude Code v2.1.319 — auto mode 网关行为调整**
- 功能介绍: 当 telemetry 或 feature flags 关闭(包括 LLM 网关后)时,auto mode 对 server 无法检查的调用改为询问或拒绝,不再回退到内置分类器;新增 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 环境变量可继续使用内置分类器(Bedrock、Vertex、Foundry 不变)。
- 效果: 企业网关场景下权限控制更严格,减少不可审计的自动放行。
- 使用限制: Claude Code;主要影响使用 LLM 网关的企业部署。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)

**Claude Code v2.1.318 — mods 记录与 AWS 角色支持**
- 功能介绍: 新增 session 中开启 mods 时对用户回答的记录;在 Claude apps gateway 的 mantle upstreams 上新增 `assume_role`,支持跨 AWS 账户角色与按开发者成本归属;mod 的 `$.model.fork` 新增 effort 选项。
- 效果: 审计更完整;多账户 AWS 环境下成本分摊更清晰;fork 出的快速子任务可以低 effort 运行。
- 使用限制: Claude Code;assume_role 面向 AWS 企业用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

**Claude Code v2.1.317 — 安全与调度提醒**
- 功能介绍: `/schedule` 在新增 cloud scheduled task 意外附带 connectors 时给出警告及移除方法;web/shell 工具调用发送账户邮箱前增加确认;Agent SDK hook 回调新增 `onFailure: "block"`;Claude Desktop 的 Code tab 在组织远程托管设置未加载时显示提示。
- 效果: 防止意外数据外泄,调度任务更透明,回调失败可阻断动作。
- 使用限制: Claude Code 与 Claude Desktop;onFailure: "block" 面向 Agent SDK 开发者。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)

**🅾️ OpenAI 产品更新详解**

**GPT-6 Cyber**
- 功能介绍: OpenAI 发布 **GPT-6 Cyber**,专用于网络安全领域的模型,可发现可利用漏洞并生成修复方案,训练目标限定在授权范围内。
- 效果: 面向安全团队与授权渗透测试场景,与 GPT-5.6 Cyber(Daybreak Red)形成梯度,提供更强的漏洞发现与修复能力。
- 使用限制: 需审批的受限模型;通过 **Daybreak Red** 在 AWS GovCloud (US-East) 的 Amazon Bedrock 上向获批客户提供。
[原文](https://openai.com/index/introducing-gpt-6-cyber)

**Images 2.6**
- 功能介绍: 推出 **Images 2.6**,图像生成更快,新增 GIF 创建、更精准的编辑能力,并在 ChatGPT、Codex 和 API 中提供新的 API 控制项。
- 效果: 用户可直接生成 GIF,编辑精度提升;开发者获得更细粒度的 API 控制。
- 使用限制: 覆盖 ChatGPT、Codex 与 API;具体档位与速率限制以各端为准。
[原文](https://openai.com/index/introducing-images-2-6)

**ChatGPT Enterprise 上线 AWS Marketplace**
