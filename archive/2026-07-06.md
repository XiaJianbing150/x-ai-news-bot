🅰️ **Claude 产品更新详解**

**Claude Sonnet 5**
• 功能介绍：新一代前沿模型 **Claude Sonnet 5** 正式发布，在编程、Agent 自主执行与规模化专业工作中达到前沿水平，原生支持 100 万 token 上下文窗口。
• 效果：用户可处理超长代码库、多文件项目与复杂代理任务，无需分段拼接；相比前代 Sonnet，在长程连贯性与指令遵循上大幅提升。API 侧推出推广价 $2/$10 每百万 token（输入/输出），截止至 2026 年 8 月 31 日。
• 使用限制：即日起在 **Claude Code**（更新至 v2.1.197）中作为默认模型。API 层面向全部开发者，推广价全平台可用，无等候名单。
[原文](https://www.anthropic.com/news/claude-sonnet-5)

**Claude Science**
• 功能介绍：面向科研人员的可定制 AI 工作台 **Claude Science** 正式上线，集成常用工具与科学计算包，产出可审计的 Artifacts，并灵活对接计算资源。
• 效果：科研人员可在统一界面完成数据分析、建模与报告生成全流程，保留完整推理过程便于复现与审查；区别于通用聊天界面，更像“科研操作系统”。
• 使用限制：现已开放使用，需通过 Anthropic 平台或专属入口访问，具体档位与定价信息参考官方公告。
[原文](https://www.anthropic.com/news/claude-science-ai-workbench)

**Claude Code v2.1.197 — Sonnet 5 成为默认模型**
• 功能介绍：**Claude Code** 将 **Claude Sonnet 5** 设为默认模型，带原生 1M token 上下文，并通过 **/model** 可切换。
• 效果：开发者开箱即用最强编码模型，无需额外配置；适用于超大型项目、全库重构等场景。
• 使用限制：**Claude Code** 用户需升级到 v2.1.197+，API 用量按 Sonnet 5 推广价计费。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.197)

**Claude Code v2.1.198 — 子代理默认后台运行、Chrome 普遍可用、后台通知与 /dataviz**
• 功能介绍：子代理（Subagents）默认在后台工作，Claude 可继续执行其他任务并在其完成时收到通知；**Claude in Chrome** 结束灰度，全面可用；新增后台代理通知钩子（agent_needs_input / agent_completed）；新增 **/dataviz** 技能，提供图表和仪表板设计指导及可运行的颜色调色板验证器。
• 效果：多任务并行不再阻塞主会话；浏览器内直接使用 Claude 更稳定；代理长时间任务可通过通知系统主动反馈；数据可视化场景有内置专业引导。
• 使用限制：**Claude Code** v2.1.198+，子代理后台行为默认开启；**Claude in Chrome** 已对所有用户开放；**/dataviz** 技能可在对话中调用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.198)

**Claude Code v2.1.196 — 组织默认模型、会话可读命名与文件附件点击**
• 功能介绍：支持管理员在组织控制台设置默认模型，用户在 **/model** 中看到“Org default”；会话启动时生成可读的默认名称，方便辨识和消息查找；聊天中文件附件支持 Cmd/Ctrl+点击在 Finder/Explorer 中定位。
• 效果：团队可统一模型选择策略；多会话管理更直观；快速在本地文件系统中定位对话里引用的文件。
• 使用限制：**Claude Code** v2.1.196+，组织默认模型需管理员在 org console 配置；附件点击功能在桌面版生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.196)

**Claude Code v2.1.199 — 堆叠斜杠技能、SSL 与流式修复**
• 功能介绍：支持堆叠调用多个斜杠技能（如 **/skill-a /skill-b**），可一次性加载最多 5 个技能；SSL 证书错误（TLS 检查代理、缺失 NODE_EXTRA_CA_CERTS 等）现在立即失败并给出修复提示，不再消耗重试次数；API 流式响应中途出错时保留已输出的部分。
• 效果：复杂工作流可组合多个技能；网络调试更直接；大段输出不会因为中途波动而完全丢失。
• 使用限制：**Claude Code** v2.1.199+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.199)

**Claude Code v2.1.200 — 权限模式默认“手动”与 AskUserQuestion 改动**
• 功能介绍：权限模式默认值切换为“Manual”，所有工具执行需用户显式确认（CLI、VS Code、JetBrains 均生效）；AskUserQuestion 对话框不再自动继续，可通过 **/config** 自行设置闲置超时；修复 .claude.json 中 MCP 服务器配置为非数组时的崩溃，以及后台会话中途静默停止的 bug。
• 效果：安全性提升，避免代码修改在未经确认的情况下执行；交互更可控，防止误操作；稳定性修复消除静默失败。
• 使用限制：**Claude Code** v2.1.200+，对注重安全或头次使用的用户尤其重要。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.200)

**Claude Code v2.1.201 — Sonnet 5 会话系统角色调整**
• 功能介绍：**Claude Sonnet 5** 会话不再在对话中间插入系统角色形式的 harness reminders，交互更干净。
• 效果：减少不必要的系统消息打断，提升对话流畅度，尤其在长 Agent 任务中体验更好。
• 使用限制：**Claude Code** v2.1.201+，自动对 Sonnet 5 会话生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.201)
