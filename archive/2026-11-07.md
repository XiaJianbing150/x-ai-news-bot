**🅰️ Claude 产品更新详解**

**Claude Code v2.1.319**
- 功能介绍: 调整 auto mode 在遥测或 feature flags 关闭时的行为,包括位于 LLM 网关后的场景;服务器无法检查的调用会被询问或拒绝,不再回退到内置分类器。新增 **CLAUDE_CODE_AUTO_MODE_SERVER=0** 环境变量可继续使用旧行为(Bedrock、Vertex、Foundry 不受影响)。
- 效果: 面向企业/网关部署,让权限判定更可控、更安全,避免在无法验证时静默放行。
- 使用限制: Claude Code CLI;需通过环境变量配置(推测)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)

**Claude Code v2.1.318**
- 功能介绍: 新增多项:记录 Claude Code 请求开启 session 中写入的 mods 时的用户回答;在 Claude apps gateway 的 mantle upstreams 上新增 **assume_role**(支持跨 AWS 账户角色与按开发者成本归因);mod 的 **$.model.fork** 新增 effort 选项,让快速 side job 可以低 effort 运行;claude auth status 新增显示 claude.ai 登录到期日期。
- 效果: 面向多账户 AWS 成本核算与 mod 工作流调优,开发者能更精细控制子任务算力与登录状态。
- 使用限制: Claude Code CLI;assume_role 需 gateway 配置(推测)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

**Claude Code v2.1.317**
- 功能介绍: /schedule 在新建云端定时任务意外带上未请求的 connectors 时新增警告及移除指引;web/shell 工具调用发送账户邮箱到网络前新增确认检查;Agent SDK hook 回调新增 **onFailure: "block"**,回调失败时阻止动作执行;Claude Desktop 的 Code 标签页在组织远程托管设置未加载时新增提示。
- 效果: 提升安全边界与可预期性,防止误发邮箱、误带连接器、回调失败静默放行。
- 使用限制: Claude Code CLI / Claude Desktop;Agent SDK 相关。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)

**Claude Code v2.1.316**
- 功能介绍: 新增 **CLAUDE_CODE_DISABLE_ULTRATHINK** 关闭 ultrathink 关键词;Claude apps gateway 新增 pooled group budgets(组内成员共享的月度预算,叠加在个人限额上,通过 spend limits admin API 的 pooled_budget 设置);新增 **CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP** 保留互相认证成环的系统交叉证书;新增 **CLAUDE_CODE_SUBAGENT_EFFORT**。
- 效果: 面向企业预算治理与私有 CA 环境,让组级成本管控和子代理算力可配置。
- 使用限制: Claude Code CLI / Claude apps gateway;需环境变量或 admin API 配置(推测)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)

**Claude Code v2.1.314**
- 功能介绍: 新增 **permissions.blockWritesOutsideWorkingDirectories**:Write、Edit、NotebookEdit 在所有权限模式下拒绝工作目录外的路径写入;Claude apps gateway upstreams 新增可选 groups 列表(仅列出的 IdP 组中的开发者被路由到该 upstream,含 failover);Bedrock upstreams 新增 **guardrail_trace**,记录触发的 Amazon Bedrock guardrail filter 而不记录匹配文本。

- 使用限制: Claude Code CLI / Claude apps gateway;需配置启用(推测)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)
