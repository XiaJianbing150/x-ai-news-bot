🅰️ **Claude 产品更新详解**

**Claude Fable 5**
• 功能介绍：发布全新公众可用模型 Claude Fable 5，属于 Mythos 5 系列，能力超过此前所有公开发布的 Claude 模型，设计为安全的一般用途模型，原生支持 1M token 上下文。
• 效果：在复杂推理、代码生成、长文档处理等任务上提供更强性能，适合需要前沿能力的日常工作与深度开发。相较上一代，Fable 5 在安全对齐的同时实现了能力质的跃升。
• 使用限制：通过 Claude Code v2.1.170 及以上版本、Anthropic API 均可使用；模型在 Max / Team Premium / Enterprise 计划及 API 按量付费账户中默认可用，Pro / Team 计划中由 Sonnet 代理，付费阶梯视具体计划而定。
[原文](https://www.anthropic.com/news/claude-fable-5-mythos-5) [Claude Code 发布说明](https://github.com/anthropics/claude-code/releases/tag/v2.1.170)

**子代理递归嵌套**
• 功能介绍：Claude Code 子代理（sub-agent）现在支持生成它们自己的子代理，最多支持 5 级深度嵌套。
• 效果：可以将复杂任务拆解为多层级的自动化流程，例如大型代码库跨模块重构、多文件批量修改等，子代理自行分派工作并汇总结果，大幅提升自动化上限。
• 使用限制：Claude Code v2.1.172+，所有用户。每层子代理消耗正常的 token 与并发限制，嵌套太深需注意上下文管理。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.172)

**备用模型 fallbackModel 设置**
• 功能介绍：新增 fallbackModel 设置，可配置最多三个备用模型，当主模型过载或不可用时按顺序自动切换；--fallback-model 参数现在也对交互式会话生效。
• 效果：在模型负载高峰或 API 波动时持续获得服务，不用手动中断切换模型，提高开发与使用连续性。
• 使用限制：Claude Code v2.1.166+，用户或项目级设置。需在配置文件中指定 fallbackModel 列表，备用模型须遵守可用模型白名单（若有）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.166)

**--safe-mode 安全模式**
• 功能介绍：新增 --safe-mode 标志及环境变量 CLAUDE_CODE_SAFE_MODE，启动 Claude Code 时自动禁用所有自定义内容：CLAUDE.md、插件、技能、hook、MCP 服务器。
• 效果：快速排查因自定义配置引发的问题，纯净启动后可逐个启用组件定位故障，适合调试和首次体验。
• 使用限制：Claude Code v2.1.169+，本地使用，无需额外权限。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)

**/cd 切换工作目录**
• 功能介绍：新增 /cd 命令，可在会话运行中切换到新工作目录，同时保持提示缓存不中断。
• 效果：长时间会话中需要切换到不同项目或代码位置时，无需重启会话或丢失上下文，提升多项目操作的流畅度。
• 使用限制：Claude Code v2.1.169+，交互式会话。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)

**鼠标滚轮加速开关**
• 功能介绍：新增 wheelScrollAccelerationEnabled 设置，可在全屏模式下禁用鼠标滚轮加速。
• 效果：满足偏好线性滚轮滚动精确度的用户，避免快速滚动时跳跃定位。
• 使用限制：Claude Code v2.1.174+，全屏模式，用户设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.174)

**会话标题语言自动匹配**
• 功能介绍：会话列表中的标题现在按照对话所用语言自动生成；新增语言设置可固定一种语言。
• 效果：多语言开发者浏览历史会话时更直观，标题语言与对话内容一致；固定语言后统一标题风格便于管理。
• 使用限制：Claude Code v2.1.176+，所有用户会话。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.176)

**增强模型白名单 enforceAvailableModels**
• 功能介绍：新增 enforceAvailableModels 托管设置，启用后 availableModels 白名单同时约束 Default 模型，且用户/项目设置不能再放宽已由托管设置限制的白名单。
• 效果：企业管理员能精确控制团队可用模型范围，防止用户绕过白名单使用未被批准的模型。
• 使用限制：Claude Code v2.1.175+，托管环境/团队管理。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.175)

• 效果：为自定义仪表板或企业集成提供可视化指示器，增强界面信息密度。

• 效果：在大量插件中快速定位所需插件，提升可发现性和体验。

**Bedrock 凭证缓存优化**
• 功能介绍：Amazon Bedrock 凭证从 awsCredentialExport 导出后，现在按凭据过期时间（Expiration）缓存，而非固定 1 小时；同时自动从 ~/.aws/config 读取区域。
• 效果：减少重复认证，延长有效登录时间，/status 显示凭据来源区域，故障排查更清晰。
• 使用限制：Claude Code v2.1.172 及 v2.1.176，Bedrock 集成环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.172) [原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.176)

🅾️ **OpenAI 产品更新详解**

**ChatGPT 记忆系统 “Dreaming”**
• 功能介绍：ChatGPT 推出新的记忆系统，能够更持久且智能地记住用户偏好、上下文及历史交互，跨会话保持相关信息的新鲜度与相关性。
• 效果：体验更个性化的助手，无需反复提供背景信息，适合长期项目跟进、个人偏好学习等场景；相比旧记忆机制，Dreaming 记忆保留更智能，上下文关联更紧密。
• 使用限制：ChatGPT 服务端功能，推测将在 ChatGPT Plus / Pro / Team / Enterprise 等计划中逐步推送；需登录 Account，用户可在设置中管理记忆或关闭。
[原文](https://openai.com/index/chatgpt-memory-dreaming)

**OpenAI 收购 Ona 扩展 Codex 持久云环境**
• 功能介绍：OpenAI 宣布计划收购 Ona，为 Codex 引入安全、持久的长时云环境，支持长时间运行的 AI agent 在企业工作流中的应用。
• 效果：Codex agent 不再受限于短暂会话，可在安全的持久环境中持续执行任务，如数小时级数据处理、持续监控与修复、多阶段自动化流程，大幅扩展 Codex 的企业自动化场景。
• 使用限制：收购未最终完成，功能将在后续集成；最终将面向 Codex 企业用户，预计整合进 ChatGPT Enterprise 及 API 渠道。
[原文](https://openai.com/index/openai-to-acquire-ona)

**通过 Oracle Cloud 使用 OpenAI 模型与 Codex**
• 功能介绍：OpenAI 模型及 Codex 现可通过 Oracle Cloud 的企业承诺计费访问，用户可使用已有的 Oracle 云资源来调用 OpenAI API 并部署 AI，配以企业级安全与治理。
• 效果：方便已采用 Oracle 云的大型企业客户，在不改变云采购流程的情况下接入 OpenAI 能力，降低合规摩擦；可将 OpenAI 与 Oracle 数据库及云服务结合，形成端到端解决方案。
• 使用限制：需 Oracle Cloud 账户并使用现有承诺额度；具体可用模型及 Codex 版本遵循 Oracle 市场提供的产品列表，API 定价可能略有差异。
[原文](https://openai.com/index/openai-on-oracle-cloud)
