**Claude Code v2.1.198：子代理后台运行与 /dataviz 技能上线**
• 功能介绍：Subagents 现在默认在后台运行，Claude 可连续工作而不等待其完成，完成后自动通知；新增 /dataviz 技能，提供图表和仪表盘设计指导，含可执行的颜色验证器；Claude in Chrome 全面可用；后台代理通过 Notification hook 触发 agent_needs_input/agent_completed 事件。
• 效果：后台并行处理大幅缓解“等子任务”的阻塞感，/dataviz 让数据分析可视化建议更可执行。
• 使用限制：Claude Code CLI / Chrome（推测需 Pro/Max/Team），无等候名单。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.198)

**Claude Code v2.1.199：斜杠技能叠加与流式响应增强**
• 功能介绍：支持连续调用多个斜杠技能（如 /skill-a /skill-b），最多加载 5 个前置技能；修复 API 中途过载错误时流式响应被丢弃的问题，现在保留已输出的部分内容。
• 效果：复杂任务可将多种技能串联，容错性提升，不会因偶发 API 错误丢失已完成的大段输出。
• 使用限制：Claude Code CLI，预计所有档位可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.199)

**Claude Code v2.1.200：权限模式默认改为手动**

• 效果：更强调用户对操作的控制权，安全性提升，适合需要严格审批的团队环境。

**Claude Code v2.1.202：动态工作流规模控制与遥测**

• 效果：用户可以按任务复杂度和成本偏好影响工作流规模，团队可监控工作流执行全貌。
