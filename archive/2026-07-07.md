🅰️ **Claude 产品更新详解**

**Claude Sonnet 5**
• 功能介绍：Anthropic 发布新一代模型 **Claude Sonnet 5**，在编程、智能体和专业工作负载上提供前沿性能。
• 效果：用户可获得更强的推理与代码能力，支持更大规模代理工作流和复杂任务，原生 1M token 上下文窗口（通过 Claude Code 使用）。
• 使用限制：已作为 **Claude Code** 默认模型上线；API 当前享受推广定价 $2/$10 每百万 token（截至2026年8月31日）；推测后续会扩展至 Web 及 API 全量。
[原文](https://www.anthropic.com/news/claude-sonnet-5)

**Claude Science**
• 功能介绍：面向科学家的可定制 AI 工作台 **Claude Science** 发布，集成常用研究工具与软件包，输出可审计的实验产物，并提供灵活的计算资源访问。
• 效果：科研人员可在统一环境中完成数据分析、模拟与文档化工作，全过程透明可复现，提升研究效率与可信度。
• 使用限制：现已可用，推测主要面向团队及企业用户，具体定价与访问方式详见官方。
[原文](https://www.anthropic.com/news/claude-science-ai-workbench)

**Claude Code v2.1.197**
• 功能介绍：**Claude Sonnet 5** 成为默认模型，支持原生 1M token 上下文窗口。
• 效果：开发者可直接在终端享受最新模型，处理超长代码库；推广期成本大幅降低。
• 使用限制：需更新至该版本，API 按量计费，推广价至2026-08-31。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.197)

**Claude Code v2.1.198**
• 功能介绍：子代理默认后台运行；**Claude in Chrome** 全面可用；新增 **/dataviz** 技能（图表与仪表板设计指导）；后台代理通知触发钩子（agent_needs_input / agent_completed）。
• 效果：子代理并行工作不阻塞主会话，Chrome 用户无需切换工具即可用 Claude Code，数据可视化指导更直接。
• 使用限制：所有 Claude Code 用户，Chrome 环境需通过相应入口。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.198)

**Claude Code v2.1.199**
• 功能介绍：支持堆叠斜线技能调用（最多5个）；SSL 证书错误快速失败并提示修复方法；修复流式响应因过载错误导致部分输出被丢弃的问题。
• 效果：技能串联更顺畅，代理中断故障更快暴露，部分输出不再丢失，流式体验更健壮。
• 使用限制：全部 Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.199)

**Claude Code v2.1.200**
• 功能介绍：**AskUserQuestion** 对话框默认不再自动继续，可选通过 /config 设置空闲超时；默认权限模式改为 **Manual**，影响 CLI、VS Code、JetBrains 终端。
• 效果：用户拥有更明确的操作控制权，避免自动跳过确认，安全性提升。
• 使用限制：全部 Claude Code 用户；可手动切换回其他权限模式。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.200)

**Claude Code v2.1.201**
• 功能介绍：**Claude Sonnet 5** 会话不再使用中间对话系统角色进行内部提醒（harness reminders）。
• 效果：简化对话流，减少冗余系统消息，可能略微提升交互效率。
• 使用限制：仅影响 Sonnet 5 会话的 Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.201)

**Claude Code v2.1.202**
• 功能介绍：新增 /config 中的“Dynamic workflow size”设置（小/中/大代理数，作为建议而非硬上限）；工作流运行 ID 和名称作为 OpenTelemetry 属性输出；修复内联 Ctrl+R 历史搜索崩溃。
• 效果：动态工作流编排更可控，遥测可完整追溯工作流调用链，搜索稳定性提高。
• 使用限制：所有 Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.202)

**Claude Code v2.1.196**
• 功能介绍：支持组织默认模型（管理员在控制台设定，个人可覆盖）；会话启动时自动生成易读名称；聊天中文件附件支持 **Cmd/Ctrl-点击** 在文件管理器中定位；多项安全修复。
• 效果：团队模型管控更便捷，多会话管理更清晰，文件溯源操作更直观。
• 使用限制：组织默认模型需企业/团队版配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.196)
