**🅰️ Claude 产品更新详解**

**Claude Fable 5.2 与 Claude Mythos 5.2**
- 功能介绍: Anthropic 正式发布 **Claude Fable 5.2** 和 **Claude Mythos 5.2** 两款新模型,其中 Fable 5.2 成为 Claude Code 中的默认 Fable 模型。
- 效果: Fable 5.2 提供 1M token 上下文窗口,定价为 $8/$40 每 Mtok(输入/输出),缓存读取 $0.20/Mtok。面向需要长上下文处理和高强度推理的编码、文档分析等场景。
- 使用限制: 通过 Anthropic API 与 Claude Code 使用;Fable 5.2 已设为 Claude Code 默认 Fable 模型(推测 Pro/Max/API 档位可用,具体档位以官方为准)。
[原文](https://www.anthropic.com/claude-fable-and-mythos-5-2)

**Claude Code v2.1.325**
- 功能介绍: 修复 zstd 压缩响应解码的安全问题;在 VS Code 等集成终端中,当 Claude 读取或编辑过 Jupyter notebook 后,新增一次性 spinner 提示(提示可重新运行 notebook cell);组织策略拦截请求时,错误下方新增提示行,告知用户可运行 /rewind 修改消息或 /clear 继续。
- 效果: 提升安全性与交互引导,减少用户在策略拦截或 notebook 场景下的困惑。
- 使用限制: Claude Code(CLI / VS Code 集成终端)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)

**Claude Code v2.1.323 — Code Mode(实验性)**
- 功能介绍: 新增实验性 **Code Mode**,开启后 Claude 通过编写 JavaScript 来调用其工具;plugin.json 新增 engines["claude-code"] 字段,超出声明版本范围的插件不会被安装、更新或加载;新增对插件 TypeScript hooks 模块的类型检查。
- 效果: Code Mode 为高级用户提供更灵活的工具调用方式;插件版本约束与类型检查提升插件生态的稳定性。
- 使用限制: 实验性 opt-in,需在 code.claude.com/docs/en/code-mode 开启;组织可关闭。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)

**Claude Code v2.1.322**
- 功能介绍: 在 Vertex(global、us、eu 区域)新增 fast mode,若 Vertex 拒绝则回退到 standard speed。
- 效果: 在 Google Cloud Vertex 上运行 Claude Code 的用户可获得更快的响应速度。
- 使用限制: Claude Code on Vertex(global / us / eu 区域)。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)

**Claude Code v2.1.321**
- 功能介绍: 将 **Claude Fable 5.2**(claude-fable-5-2)设为默认 Fable 模型;claude remote-control 新增 --settings  参数,可为每个启动的 session 应用设置文件(文件变更后需重启 remote-control 才生效);修复 MCP OAuth 请求在服务器重定向时将 refresh token 等机密发送到其他主机的问题。
