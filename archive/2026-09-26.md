**Claude Opus 5.5 上线 Claude Code**
- 功能介绍: **Claude Code** v2.1.280 新增 **claude-opus-5-5**,成为默认 Opus 模型,上下文 1M token,定价 $4/$20 每 Mtok,缓存读取 $0.20/Mtok。

- 使用限制: Claude Code(API / Enterprise / Bedrock / Vertex / Foundry / 网关均可用);需更新至 v2.1.280 及以上。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.280)

**AGENTS.md 支持**
- 功能介绍: **Claude Code** v2.1.277 起,项目中没有 CLAUDE.md 时会自动读取 **AGENTS.md** 作为项目指令;可在 /config 的 "Project instructions" 中切换。
- 效果: 与业界通用 agents 规范兼容,团队若已维护 AGENTS.md 无需再额外维护 CLAUDE.md,降低迁移成本。
- 使用限制: Claude Code;暂不支持 Bedrock、Vertex、Foundry 环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)

**Auto mode 服务端分类器默认启用**
- 功能介绍: v2.1.278 将 Claude API 和 Enterprise 用户的 auto mode 默认改为服务端分类器,不再对分类器开销计费;Bedrock / Vertex / Foundry / 网关同样默认启用,可用 CLAUDE_CODE_AUTO_MODE_SERVER=0 退出。
- 效果: 减少本地分类器带来的 token 消耗与延迟,降低 auto mode 使用成本;/status 新增 Auto mode server 行显示当前会话分类器运行位置。
- 使用限制: Claude Code;API / Enterprise 及 Bedrock / Vertex / Foundry / 网关用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)

**网关提示头与模型管控设置**
- 功能介绍: v2.1.283 新增 **x-claude-code-prompt-id** 网关提示头(需 CLAUDE_CODE_GATEWAY_HINT_HEADERS=1),让 LLM 网关能按用户 prompt 聚合请求;新增 **availableModelsMatch** 和 **deniedModels** 托管设置,可精确锁定或屏蔽特定模型版本。
- 效果: 企业网关可更细粒度追踪单次用户请求的底层调用;模型版本管控更严格,新版本发布后默认保持封锁直到管理员显式放行。
- 使用限制: Claude Code;需配置网关或托管策略文件。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.283)

**maxProseWidth 与终端体验优化**
- 功能介绍: v2.1.282 新增 **maxProseWidth** 设置,在宽终端中限制 Claude 正文宽度,表格和代码块保持全宽;新增启动提示、/status 和 claude doctor 条目列出被忽略或关闭遥测的变量。
- 效果: 宽屏终端下长段落不再铺满整行,提升可读性;遥测配置问题在启动时即可发现。

[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.282)

**send-now 快捷键与网关登录确认**
- 功能介绍: v2.1.275 新增 **ctrl+enter**(或 ctrl+x ctrl+s)立即中断当前回合并发送所有排队消息;Claude apps 网关登录时显示已登录账户,保存凭证前需确认。
- 效果: 排队多条消息后可一键全部发出,不必等待模型逐条接收;网关场景下账户身份更透明,避免误存错误凭证。
- 使用限制: Claude Code;网关功能需 Claude apps gateway。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.275)

**内存临界警告与 MCP 启动等待控制**
- 功能介绍: v2.1.274 在内存使用达到临界时显示可见警告并给出释放内存或安全重启步骤;新增 **CLAUDE_CODE_MCP_STARTUP_WAIT_MS** 限制首个非交互回合等待 MCP 服务器连接的时间(0 = 不等待)。
