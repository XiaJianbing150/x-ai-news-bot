**🅰️ Claude 产品更新详解**

**Claude Fable 5.2 / Claude Mythos 5.2**
- 功能介绍: Anthropic 发布两款新模型 **Claude Fable 5.2** 与 **Claude Mythos 5.2**,作为当前主力模型线的迭代版本。
- 效果: Fable 5.2 成为 Claude Code 默认 Fable 模型,拥有 1M context,定价 $8/$40 每 Mtok,cache 读取 $0.20/Mtok,面向长上下文与高吞吐场景;Mythos 5.2 定位为另一条模型线,具体差异官方未在摘要中展开。
- 使用限制: 通过 Anthropic API 与 Claude Code 使用;Fable 5.2 已在 Claude Code v2.1.321 起设为默认,API 侧需指定模型名 claude-fable-5-2(推测)。
[原文](https://www.anthropic.com/claude-fable-and-mythos-5-2)

**Claude Code v2.1.325**
- 功能介绍: 修复 zstd 压缩响应解码的安全问题;在 VS Code 及类似集成终端中,当 Claude 读取或编辑过 Jupyter notebook 后,新增 spinner 提示可重跑 notebook cell;组织策略拦截请求时,错误下方新增提示:运行 /rewind 修改消息或 /clear 继续;沙箱 git checkout / stash / autostash 时给 Claude 加注说明。
- 效果: 提升安全性与 notebook 工作流体验,减少用户被策略拦截后的困惑。
- 使用限制: Claude Code CLI,全平台。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)

**Claude Code v2.1.323 — Code Mode(实验性)**
- 功能介绍: 新增 **Code Mode**,一个实验性 opt-in 模式,Claude 通过编写 JavaScript 来调用自身工具;plugin.json 新增 engines["claude-code"] 字段,超出声明版本范围的插件不会被安装/更新/加载;新增对插件 TypeScript hooks 模块的类型检查。
- 效果: Code Mode 让 Claude 以代码方式编排工具调用,适合复杂自动化;插件版本约束提升稳定性。
- 使用限制: 实验性,需手动开启;组织可关闭。详见 code.claude.com/docs/en/code-mode。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)

**Claude Code v2.1.322 — Vertex fast mode**
- 功能介绍: 在 Vertex 的 global / us / eu 区域新增 fast mode,若 Vertex 拒绝则回退到标准速度。
- 效果: 提升 Vertex 用户的响应速度,失败自动降级保证可用性。
- 使用限制: Claude Code + Google Vertex 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)

**Claude Code v2.1.321 — Fable 5.2 默认 + remote-control 增强**
- 功能介绍: 将 **Claude Fable 5.2** 设为默认 Fable 模型;claude remote-control 新增 --settings  参数,为每个 session 应用设置文件;修复 MCP OAuth 在服务器重定向时把 refresh token 等 secrets 发送到其他 host 的问题;修复一个读取相关 bug。
- 效果: 默认模型升级到 5.2;remote-control 支持统一配置;OAuth 修复堵住凭据泄露风险。
- 使用限制: Claude Code CLI;Fable 5.2 定价 $8/$40 每 Mtok,cache 读取 $0.20/Mtok。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)

**Claude Code v2.1.319 — auto mode 行为调整**
- 功能介绍: telemetry 或 feature flags 关闭时(包括 LLM gateway 后),auto mode 对服务器无法检查的调用改为询问或拒绝,不再回退到内置分类器;可用 CLAUDE_CODE_AUTO_MODE_SERVER=0 保持旧行为;LLM gateway 后可用 CLAUDE_CODE_AUTO_MODE_SERVER=1 强制开启服务器端检查。
- 效果: 在受限环境与 gateway 场景下,权限决策更可控、更安全。
- 使用限制: Claude Code CLI;Bedrock / Vertex / Foundry 行为不变。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)

**🅾️ OpenAI 产品更新详解**

**ChatGPT Wallet**
- 功能介绍: 推出 **ChatGPT Wallet**,让 ChatGPT Work、Codex 和 dots 中的 agent 在用户批准下安全完成购买,agent 无法接触真实卡号,每笔购买需通过安全检查。

- 使用限制: 面向 dots,Pro 订阅者率先可用(推测为美国地区先行);ChatGPT Work / Codex 场景同步推出。
