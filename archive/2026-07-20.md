🅰️ **Claude 产品更新详解**

**Claude for Teachers 发布**
• 功能介绍：Anthropic 正式推出 **Claude for Teachers**，将 Claude 针对教育场景进行定制，直接提供备课、出题、作业反馈等专用工具。
• 效果：教师无需手动设计 prompt，即可快速生成教案、设计差异化测验、给出个性化评语，大幅降低 AI 进课堂的门槛。
• 使用限制：面向所有 Claude 用户，支持 Web / App（推测）；无需等候名单。
[原文](https://www.anthropic.com/news/claude-for-teachers)

**Claude Code v2.1.215：/verify 与 /code-review 改为手动调用**
• 功能介绍：Claude 不再自动运行 **/verify** 和 **/code-review** 技能，用户需要时必须显式输入 /verify 或 /code-review 才会触发。
• 效果：避免每次对话自动消耗 token 进行不必要的验证，开发者可按需检查代码，节省用量并提高交互速度。
• 使用限制：Claude Code 用户（Pro / Max / API），终端环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.215)

**Claude Code v2.1.214：安全与权限修复**
• 功能介绍：修复单段目录 allow 规则（如 Edit(src/**)）错误地对树中任意位置的嵌套目录自动批准；修复 Windows PowerShell 5.1 下命令权限检查可被绕过的问题；修复 Bash 文件描述符重定向及超长命令的权限检查缺陷。
• 效果：在多平台、复杂命令场景下，自动审批不再漏过危险操作，整体安全性大幅提升。
• 使用限制：Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.214)

**Claude Code v2.1.212：/fork 变为后台会话、新增 /subtask、WebSearch 限制等**
• 功能介绍：**/fork** 现在把当前对话复制为新的后台会话（在 claude agents 列表中独立一行），用户可继续工作；原先的会话内子代理改为新命令 **/subtask**；新增 **claude auto-mode reset** 恢复默认自动模式配置（带确认提示，可 --yes 跳过）；引入会话级 WebSearch 工具调用上限（默认 200 次，可通过环境变量 CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION 调整），防止失控搜索循环。
• 效果：开发者可以并行处理多个任务、自由拆分复杂工作，同时避免自动模式意外篡改与搜索死循环。
• 使用限制：Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**Claude Code v2.1.211：--forward-subagent-text 与权限预览修复**
• 功能介绍：新增 **--forward-subagent-text** 标志和环境变量 CLAUDE_CODE_FORWARD_SUBAGENT_TEXT，支持将子代理的文本和思考内容纳入 stream-json 输出；修复权限预览中未清理双向覆写、零宽及模仿引号等特殊字符导致视觉欺骗的问题；修复 auto mode 覆盖 PreToolUse hook 的 ask 决定，现在 hook 的 ask 会强制降级为 ask 以保护未沙盒化的 Bash。
• 效果：流式输出更完整，权限审批界面不再被特殊字符干扰，手动审批控制更可靠。
• 使用限制：Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.211)

**Claude Code v2.1.210：实时耗时、权限警告与 worktree 隔离修复**
• 功能介绍：在收缩的工具摘要行上添加实时计时器，长时间运行的工具会可见地跳动而非看起来卡死；对 Write(path)、NotebookEdit(path)、Glob(path) 权限规则加入启动警告，提示应改用 Edit(path) 或 Read(path)；修复 ‘worktree’ 子代理可以执行 git 修改命令影响主仓库而非自己的隔离工作树的问题。
• 效果：界面反馈更清晰，不安全的权限规则得到提醒，worktree 隔离更牢固，避免交叉污染。
• 使用限制：Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.210)

**Claude Code v2.1.209：修复后台会话中对话框阻塞**
• 功能介绍：修复在 claude agents 后台会话中 **/model** 等对话框被阻止的问题，回滚了过于广泛的防护。
• 效果：后台任务不再因无法切换模型而中断，开发者可以在后台自由调整设置。
• 使用限制：Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.209)

**Claude Code v2.1.208：屏幕阅读器模式、Vim 映射与进程包装器**
• 功能介绍：新增 **屏幕阅读器模式**（通过 --ax-screen-reader、CLAUDE_AX_SCREEN_READER=1 或设置项 axScreenReader: true 启用），提供纯文本渲染；加入 **vimInsertModeRemaps** 设置，允许将 jj 等两键插入模式序列映射为 Escape；引入 **CLAUDE_CODE_PROCESS_WRAPPER**，agent view 和后台服务通过该包装器可执行从企业启动器进行进程自举。
• 效果：视障开发者可通过屏幕阅读器流畅操作；Vim 用户可在插入模式下用习惯的快捷键退出；企业环境可统一管控 Claude Code 的进程启动。
• 使用限制：Claude Code 用户，涉及企业部署。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.208)
