**Claude for Teachers**

• 效果：教师可将 Claude 作为日常教学助手，快速生成教案草稿、差异化练习题、评分准则，减少机械性工作，把精力更多放在学生身上。这是 Anthropic 首次为特定职业群体推出定制化方案。
• 使用限制：—（推测目前通过 Anthropic 官方渠道申请，具体档位和平台待后续公布）
[原文](https://www.anthropic.com/news/claude-for-teachers)

**Claude Code v2.1.212 /fork 变为后台会话 & 新增 /subtask**
• 功能介绍：**/fork** 现在会将当前对话复制为一个新的后台会话（在 **claude agents** 中独占一行），原来的会话可以继续工作；原先的会话内子代理由新的 **/subtask** 命令接管。同时新增 **claude auto-mode reset** 命令恢复默认自动模式配置，并引入会话级 WebSearch 调用上限（默认 200 次，通过 **CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION** 可调）。
• 效果：/fork 让你可以“另存一个思考分支”在后台继续推进，而主会话不受干扰；/subtask 让子任务管理更语义化。WebSearch 限制防止搜索循环失控，自动模式重置提供安全网。
• 使用限制：所有 Claude Code 用户；CLI 命令和设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**Claude Code v2.1.211 --forward-subagent-text 选项**
• 功能介绍：新增 **--forward-subagent-text** 标志及环境变量 **CLAUDE_CODE_FORWARD_SUBAGENT_TEXT**，使子代理的文本和思考过程包含在 stream-json 输出中。
• 效果：开发者在使用流式 JSON 输出时，可以完整捕获子代理的推理链路，方便日志审计、调试与集成。
• 使用限制：Claude Code CLI，需主动启用标志。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.211)

**Claude Code v2.1.210 工具调用计时 & 权限规则警告**
• 功能介绍：在折叠的工具摘要行中新增 **实时耗时计时器**，长时间运行的调用会显式跳动，而不是看起来卡死。对 **Write/NotebookEdit/Glob 的权限规则**增加启动警告，提示使用 Edit 或 Read 替代。修复子代理隔离问题，防止 worktree 子代理在主仓库检出上执行 git 变更命令。
• 效果：更清晰的进度感知，避免误用权限规则带来的安全隐患。
• 使用限制：所有 Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.210)

**Claude Code v2.1.208 屏幕阅读器模式 & 进程包装器**
• 功能介绍：新增 **屏幕阅读器模式**（**--ax-screen-reader** 或设置 **axScreenReader: true**），为屏幕阅读器用户提供纯文本渲染。增加 **vimInsertModeRemaps** 设置，可将 **jj** 等双键序列映射为 Escape。新增 **CLAUDE_CODE_PROCESS_WRAPPER**，使 agent 视图和后台服务产生的所有自生成进程强制通过指定的包装器执行，方便企业管理。
• 效果：大幅提升无障碍体验，让 vim 用户操作更顺手，企业 IT 可以通过包装器注入安全策略。
• 使用限制：Claude Code 用户，通过命令行参数、环境变量或 settings 配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.208)

**Claude Code v2.1.207 自动模式全面可用 & 终端冻结修复**
• 功能介绍：**Auto mode** 现在无需 **CLAUDE_CODE_ENABLE_AUTO_MODE** 即可在 Bedrock、Vertex AI、Foundry 上使用（可通过 **disableAutoMode** 关闭）。修复了输出长列表/表格/大段代码时终端冻结和按键延迟问题，以及修复非交互运行中的远程托管设置被永久记录为同意而未显示安全同意对话框的问题。
• 效果：自动模式开箱即用，非交互式场景下的安全合规性得到保证，终端体验更流畅。
• 使用限制：所有 Claude Code 用户，Bedrock/Vertex/Foundry 环境同样受益。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.207)
