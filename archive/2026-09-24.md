**🅰️ Claude 产品更新详解**

**Claude Opus 5.5 上线 Claude Code**
- 功能介绍: Claude Code v2.1.280 新增 **claude-opus-5-5** 模型,现已成为默认 Opus 模型,支持 1M context。
- 效果: 定价 $4/$20 每 Mtok,cache 读取 $0.20/Mtok。相比旧 Opus,上下文翻倍,适合超长代码库分析和大型重构任务。
- 使用限制: Claude Code 内可用;API 用户与 Enterprise 用户默认启用。平台为 Claude Code CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.280)

**AGENTS.md 支持**
- 功能介绍: Claude Code v2.1.277 起,项目中没有 CLAUDE.md 时会自动读取 **AGENTS.md** 作为项目指令。
- 效果: 与业界通用 agent 配置文件兼容,团队可在多工具间共享同一份项目指令,减少重复维护。
- 使用限制: 可在 /config 的 "Project instructions" 中切换;暂不支持 Bedrock、Vertex、Foundry。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)

**Auto mode 服务端分类器默认启用**
- 功能介绍: v2.1.278 将 Claude API、Enterprise、Bedrock、Vertex、Foundry 及网关用户的 auto mode 默认改为服务端分类器,不再对分类器开销计费。
- 效果: 用户无需为 auto mode 的分类器计算付费,降低成本;若回退到计费模式会给出警告。
- 使用限制: 在 Bedrock/Vertex/Foundry/gateway 上可用 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 退出;/status 中新增 Auto mode server 行显示分类器运行位置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)

**Claude apps gateway 多项增强**
- 功能介绍: v2.1.281 为 Claude apps gateway 增加桌面策略支持(blockReadsOutsideWorkingDirectories、disableBypassPermissionsMode),Bedrock upstream 支持 assume_role 跨账号 STS 调用,并新增 guardrail 配置。
- 效果: 企业可通过 IAM 角色跨 AWS 账号调用 Bedrock,按开发者分配独立 session;同时可挂载 Amazon Bedrock guardrail 做内容安全过滤。
- 使用限制: Claude apps gateway 部署环境;需配置 upstream 与 IAM 角色。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.281)

**会话发送快捷键与排队消息**

- 效果: 用户可提前输入多条指令,模型未接收前消息以灰色显示,适合连续下达多步任务。
