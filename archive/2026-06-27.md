🅰️ **Claude 产品更新详解**

**Claude Tag**
• 功能介绍：为团队推出的一种新协作方式，允许用户给 Claude 对话打标签、分类或共享，方便多人项目中的上下文管理。
• 效果：团队成员可以快速搜索、过滤和复用过往对话，减少重复输入上下文的时间；在多项目并行时显著提升协同效率。
• 使用限制：推测面向 Team／Enterprise 计划；Web 端优先，App 端后续跟进；需管理员开启。
[原文](https://www.anthropic.com/news/introducing-claude-tag)

**Claude Code 多项更新 (v2.1.183–v2.1.195)**
• 功能介绍：本周连续发布多个小版本，核心改动包括：
  - **沙箱凭证保护**：新增 sandbox.credentials 设置，可阻止沙箱命令读取密钥文件与环境变量；
  - **/rewind 支持**：可在 /clear 之后恢复对话历史，避免误清丢失上下文；
  - **auto-mode 安全强化**：自动模式中拦截破坏性 git 命令（如 reset --hard、clean -fd、stash drop），并阻止非当前 agent 提交的 commit 被 --amend；同时阻止未明确指明的 terraform/pulumi/cdk destroy；
  - **MCP 服务器 CLI 认证**：增加 claude mcp login/logout 命令，可在不打开交互菜单的情况下通过 CLI 完成 MCP 服务器认证，支持 SSH 环境下的 stdin 重定向；
  - **全屏鼠标支持**：在权限提示、模型选择、设置菜单等选择界面中支持鼠标点击操作；
  - **流中断提示优化**：将 “No response from API” 改为 “Waiting for API response · will retry in …”，触发时间从 10 秒延长至 20 秒；
  - **组织策略提示**：当语音输入被组织策略禁用时，会给出明确说明而非仅显示“不可用”；
  - 多项崩溃修复与可靠性提升。
• 效果：开发者获得更细粒度的安全控制，尤其在沙箱环境中自动阻止泄露风险；/rewind 解决了日常高频痛点（误清对话）；MCP 认证命令极大简化 CI/CD 和远程 SSH 环境下的集成部署；全屏交互更接近现代终端习惯。
• 使用限制：所有 Claude Code 用户均可通过升级获取；CLI 环境，需自行执行 npm update；无额外用量限制。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.195)
