🅰️ **Claude 产品更新详解**

**Claude for Teachers 正式推出**
• 功能介绍：Anthropic 发布面向教育工作者的 **Claude for Teachers**，为教师提供专门优化的 Claude 使用体验，辅助备课、创建教学材料、设计课程活动等。
• 效果：教师可直接用 Claude 生成教案、习题、评分量规等，降低备课时间；界面和交互更贴合课堂教学场景，区别于通用 Claude 版本。
• 使用限制：具体档位和平台尚未详述 (推测面向教育机构或通过专门入口访问，可能集成在现有的 Claude 产品中)。
[原文](https://www.anthropic.com/news/claude-for-teachers)

**Claude Code：/fork 与 /subtask 分离，后台独立会话**
• 功能介绍：**/fork** 现在将对话复制到一个新的后台会话（在 claude agents 视图中显示为独立行），原对话可继续工作；原先启动的会话内子代理改为独立命令 **/subtask**。
• 效果：用户可随时分叉出独立会话处理分支任务，不中断主线开发；后台会话管理更清晰，便于多线并行。
• 使用限制：**Claude Code** 命令行工具；适用于已登录的开发者；后台会话数量受环境限制。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**Claude Code：新增实时耗时计数器与权限警告**
• 功能介绍：长期运行的工具调用现在会显示 **实时耗时计数器**，防止看起来像卡死；同时针对 Write/NotebookEdit/Glob 权限规则增加了启动警告，建议使用 Edit/Read 替代。
• 效果：开发者可直观看到工具调用进度；更早发现不安全的权限配置，降低误操作风险。
• 使用限制：**Claude Code** 命令行工具，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.210)

**Claude Code：屏幕阅读器模式与进程包装器**
• 功能介绍：新增 **--ax-screen-reader** 启动选项或 **CLAUDE_AX_SCREEN_READER=1** 环境变量，为屏幕阅读器用户提供纯文本渲染；同时支持 **CLAUDE_CODE_PROCESS_WRAPPER**，让企业启动器可以包装所有 Claude Code 自举子进程，包括 agent view 和后台服务。
• 效果：视障开发者更友好；企业 IT 可强制所有 Claude Code 进程通过公司监控/安全工具运行。
• 使用限制：**Claude Code** 命令行工具；屏幕阅读器模式需在启动时指定。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.208)

**Claude Code：auto-mode 重置与 WebSearch 限制**
• 功能介绍：新增 **claude auto-mode reset** 命令恢复默认自动模式配置（带确认提示）；同时增加会话级 **WebSearch 工具调用上限**（默认 200 次，可通过 **CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION** 调整）。
• 效果：避免自动模式配置混乱；防止搜索循环消耗过多资源，提升稳定性。
• 使用限制：**Claude Code** 命令行工具；限制可配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**Claude Code：子代理文本转发与安全修复**
• 功能介绍：新增 **--forward-subagent-text** 标志和环境变量，可将子代理的文本与思考过程包含在 stream-json 输出中；同时修复了多个权限检查绕过问题（Windows PowerShell 5.1、Bash 文件描述符重定向等）。
• 效果：工具链集成更透明；安全防护更严密。
• 使用限制：**Claude Code** 命令行工具，企业环境尤其受益。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.211)
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.214)

**Claude Code：/verify 与 /code-review 改为手动调用**
• 功能介绍：Claude 不再自动运行 **/verify** 与 **/code-review** 技能，用户需要时手动触发。
• 效果：减少不必要的自动检查，提升会话流畅度，用户对代码审查时机有完全控制。
• 使用限制：**Claude Code** 命令行工具，所有用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.215)

**Claude Code：沙箱文件系统隔离可选关闭及长会话性能修复**
• 功能介绍：新增 **sandbox.filesystem.disabled** 设置，可在保留网络出口控制的前提下跳过文件系统隔离；同时修复了长会话中消息归一化成本随回合数平方增长导致的严重减速问题。
• 效果：高级用户可灵活调整隔离级别；长时间编程会话不再出现数秒冻结。
• 使用限制：**Claude Code** 命令行工具，需要理解安全含义。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.216)

🅾️ **OpenAI 产品更新详解**

**GPT-Red：自我博弈驱动的自动红队系统**
• 功能介绍：OpenAI 公布 **GPT-Red**，一个通过自我对弈自动生成攻击提示的红队系统，用于提升模型对提示注入等攻击的鲁棒性。
• 效果：自动化安全测试，持续发现并修复漏洞，使模型在实际部署中更可靠；相比人工红队，可扩展性大幅提升。
• 使用限制：目前作为内部安全工具 (推测)，尚未开放给外部用户直接使用。
[原文](https://openai.com/index/unlocking-self-improvement-gpt-red)

**ChatGPT 面向青少年的安全保护升级**
• 功能介绍：OpenAI 在 **ChatGPT** 中引入针对青少年的适龄保护措施，包括年龄验证、学习工具、家长控制面板，并与儿童发展专家合作设计交互体验。
• 效果：让 13‑17 岁用户更安全地使用 ChatGPT 辅助学习，家长可管理使用权限与隐私；课堂场景更合规。
• 使用限制：Free / Plus / Team / Enterprise 均将受益 (推测通过账户年龄设置触发)，覆盖 Web / iOS / Android。
[原文](https://openai.com/index/why-teens-deserve-access-safe-ai)
