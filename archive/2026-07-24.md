🅰️ **Claude 产品更新详解**

**Claude Code v2.1.218: /code-review 后台化与无障碍增强**
• 功能介绍: **/code-review** 命令改为后台子代理运行，不再占满主会话上下文；新增屏幕阅读器模式下的文本删除语音播报；修复了 Windows 路径中含 \u 前缀段时被错误渲染为 CJK 字符的问题。
• 效果: 代码评审不再打断主会话流程，开发者可以在评审进行时继续其他工作；使用屏幕阅读器的开发者能清晰感知删除操作。Windows 特殊路径（如 C:\Users\unicorn）不再出现乱码，文件操作更可靠。
• 使用限制: **Claude Code** CLI；**--ax-screen-reader** 模式需手动开启。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.218)

**Claude Code v2.1.217: Emoji 自动补全与会话保存告警**
• 功能介绍: 提示输入框新增 emoji 短码自动补全（输入 :heart: 即插入 ❤️）；转录写入失败或会话保存被环境变量关闭时新增告警；修复 MCP 工具输出截断导致的内存泄漏问题。
• 效果: 在 commit message 或注释里快速插入 emoji，提升表达效率；之前会话静默丢失的情况现在会主动提示，避免丢失重要上下文；长时间运行 MCP 工具不再导致内存持续增长。
• 使用限制: **Claude Code** CLI；emoji 补全可通过 **emojiCompletionEnabled** 设置关闭。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.217)

**Claude Code v2.1.216: 沙盒文件系统隔离与长会话性能修复**
• 功能介绍: 新增 **sandbox.filesystem.disabled** 设置，可在保持网络出口控制的同时跳过文件系统隔离；修复长会话中消息归一化成本随轮次平方增长导致的卡顿和恢复缓慢。
• 效果: 对不需要文件隔离但需要网络安全控制的场景，灵活性更高；长会话（数百轮以上）的响应速度和恢复速度显著改善。还修复了 OAuth token 过期导致命令被 “HTTP 401” 错误拒绝的问题。
• 使用限制: **Claude Code** CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.216)

**Claude Code v2.1.215: /verify 与 /code-review 不再自动运行**
• 功能介绍: Claude 不再在完成任务后自行触发 /verify 和 /code-review，改为需要用户手动调用。
• 效果: 减少不必要的自动验证消耗 token，用户可以按需发起审查，让对话更聚焦于核心任务。
• 使用限制: **Claude Code** CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.215)

**Claude Code v2.1.214: 权限检查安全强化**
• 功能介绍: 修复单段目录通配符允许规则（如 Edit(src/**)）的误判问题、Windows PowerShell 5.1 下的权限检查绕过漏洞、Bash 文件描述符重定向的权限检查缺漏，以及超长命令（超过特定长度）的权限误判。
• 效果: 多处安全漏洞被修补，沙盒和权限控制更严密，防止意外或恶意文件写入。
• 使用限制: **Claude Code** CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.214)

**Claude Code v2.1.212: /fork 后台会话 + WebSearch 调用上限**
• 功能介绍: **/fork** 现在将对话复制到全新后台会话（在 claude agents 中独立一行），原会话可继续工作，原先的内联子代理改为 **/subtask**；新增会话级 WebSearch 调用上限（默认 200 次，可通过 **CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION** 调节）；新增 **claude auto-mode reset** 命令恢复默认自动模式配置。
• 效果: /fork 实现真正的多任务并行，一个会话 fork 出去干活，自己继续编码；WebSearch 上限防止失控的搜索循环消耗大量资源。
• 使用限制: **Claude Code** CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

**Claude Code v2.1.211: 子代理文本转发与权限预览安全修复**
• 功能介绍: 新增 **--forward-subagent-text** 标志，将子代理文本和思考过程纳入 stream-json 输出；修复权限预览中的双向覆盖字符和零宽字符注入风险；修复 auto mode 在 hook 返回 ask 时仍执行未沙盒 Bash 的问题。
• 效果: 通过 stream-json 消费 Claude Code 输出的工具现在能获取子代理完整内容；安全修复堵住了通过特殊 Unicode 字符伪造审批界面的攻击路径。
• 使用限制: **Claude Code** CLI。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.211)
