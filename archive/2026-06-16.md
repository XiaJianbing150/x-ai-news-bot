🅰️ **Claude 产品更新详解**

**Claude Fable 5 与 Mythos 5 模型发布**
• 功能介绍：Anthropic 发布 Claude Fable 5，这是基于 Mythos 级架构的通用安全模型，能力超越公司以往所有公开发布的模型；同时公开更强大的 Mythos 5，但该模型严格受限。
• 效果：Fable 5 面向所有用户提供更强的推理、编程等能力，大幅提升复杂任务表现；Mythos 5 仅限特定安全审查后的受控使用。
• 使用限制：Fable 5 已通过 API 与 Claude Code v2.1.170+ 提供；Mythos 5 当前因政府指令暂停访问（详见公司动态）。
[原文](https://www.anthropic.com/news/claude-fable-5-mythos-5)

**递归子代理（Claude Code v2.1.172）**
• 功能介绍：子代理现在可以生成自己的子代理，最多支持 5 层深度嵌套。
• 效果：复杂任务可以自动拆解为多层代理协同完成，提升自动化编排与长链任务处理能力。
• 使用限制：Claude Code v2.1.172+，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.172)

**安全模式排错（Claude Code v2.1.169）**
• 功能介绍：新增 --safe-mode 标志及 CLAUDE_CODE_SAFE_MODE 环境变量，启动时会禁用所有自定义项（CLAUDE.md、插件、技能、挂钩、MCP 服务器），用于故障排查。
• 效果：当出现异常行为时，可快速进入“干净”状态定位问题来源。
• 使用限制：Claude Code v2.1.169+，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)

**会话内切换工作目录（/cd 命令，v2.1.169）**
• 功能介绍：新增 /cd 命令，可在会话中途切换工作目录，且不会破坏已有的提示缓存。
• 效果：无需重启会话即可在不同项目间快速切换上下文，提升多项目并行工作效率。
• 使用限制：Claude Code v2.1.169+，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)

**权限规则参数匹配（Claude Code v2.1.178）**
• 功能介绍：支持 Tool(param:value) 语法在权限规则中精确匹配工具输入参数，可配合 * 通配符使用，例如 Agent(model:opus) 可阻止创建 Opus 模型的子代理。
• 效果：实现更细粒度的安全与使用控制，便于企业按需限制特定模型或参数组合。
• 使用限制：Claude Code v2.1.178+，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.178)

**嵌套技能与目录优先级（v2.1.178 / v2.1.176）**
• 功能介绍：嵌套的 .claude/skills 目录中的技能现在可以自动加载，名称冲突时显示为 <目录>:<名称>；同一项目中多个 .claude/ 目录的 agent、workflow、output-style 配置会优先采用距离当前工作目录最近的设置。此外支持页脚链接正则自定义、会话标题跟随对话语言等功能。
• 效果：更适应多目录 / 多项目的复杂工程结构，自定义信息更本地化、更有条理。
• 使用限制：部分特性需要 v2.1.176+，完整的技能嵌套支持需 v2.1.178。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.178)

• 使用限制：面向所有 OpenAI 用户（推测需登录账号），课程可能免费开放，限制细节尚未说明。
