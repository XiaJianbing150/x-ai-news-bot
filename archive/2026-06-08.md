🅰️ Claude 产品更新详解

**Claude Code v2.1.158 – v2.1.168：多项功能提升**
过去一周 Claude Code 密集迭代，重点引入备用模型自动切换、托管版本锁、插件管理、并行工具可靠性、安全写入提示及多云 Auto 模式等能力。

**备用模型与过载切换**  
• 功能介绍：v2.1.166 新增 fallbackModel 配置项，支持设置最多三个备用模型，当主模型因过载或不可用时按顺序尝试；--fallback-model 参数现在也适用于交互式会话。  
• 效果：开发者在调用高峰期或区域故障时不再因模型不可用而中断工作流，Claude Code 可自动降级到备用模型继续完成请求，提升持续集成与个人开发环境的可靠性。  
• 使用限制：通过 Claude Code CLI 配置文件或命令行参数设置，需有效的 Anthropic API 账号；所有 API 档位均可使用，但不同模型的配额独立计费。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.166)

**托管版本锁 requiredMinimumVersion / requiredMaximumVersion**  
• 功能介绍：v2.1.163 新增托管设置项，管理员可在 managed settings 中指定客户端允许的最低和最高版本；版本不符时 Claude Code 拒绝启动并引导用户安装符合范围的版本。  
• 效果：企业 IT 团队能统一控制团队内 Claude Code 版本，避免因版本差异导致的 API 兼容问题或未经审计的功能使用，提升治理能力与安全基线。  
• 使用限制：仅限 Team / Enterprise 账户通过 managed settings 下发；不支持个人用户自行设定。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.163)

**插件列表命令与 /btw 复制快捷键**  
• 功能介绍：v2.1.163 新增 /plugin list 指令，支持 --enabled/--disabled 过滤查看已安装插件；/btw（快速提问）回复底部新增「c to copy」快捷键，可一键复制格式完整的 Markdown 答案。  
• 效果：开发者能快速审计当前会话启用的插件，排查问题或按需加载；复制功能让答案直接粘贴到文档、PR 说明或同事聊天窗口，保留代码块和格式，减少重新排版。  
• 使用限制：所有 Claude Code 用户均可用，无档位限制。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.163)

**并行工具调用容错增强**  
• 功能介绍：v2.1.161 中，并行工具调用里某个 Bash 命令失败不再取消同一批次的其他调用，其余任务会继续执行。  
• 效果：当 Claude Code 并行执行多个检查、构建或部署步骤时，单个非关键命令出错不会中断整个流水线，提高自动化脚本的容错能力。  
• 使用限制：所有用户，自动生效。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.161)

**安全写入保护与编辑免重读**  
• 功能介绍：v2.1.160 增加对 shell 启动文件及 build-tool 配置文件写入前的交互式确认；单文件 grep 后直接编辑不再要求额外的 Read 步骤。  
• 效果：防止恶意或误操作指令更改 .zshrc、.npmrc 等可导致命令执行的配置文件；同时，在快速查找后直接修改文件省去一次工具调用，缩短反馈循环。  
• 使用限制：安全提示在 acceptEdits 模式下自动生效；编辑优化对所有用户开放。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.160)

**多云 Auto 模式支持**  
• 功能介绍：v2.1.158 将 Auto 模式扩展至 Amazon Bedrock、Google Vertex AI 和 Oracle Foundry 上的 Opus 4.7 与 Opus 4.8，可通过环境变量 CLAUDE_CODE_ENABLE_AUTO_MODE=1 启用。  
• 效果：已在这些云平台上托管 Claude 模型的团队现在也能利用 Auto 模式自动执行多步任务、编写并运行代码，无需等待原生支持。  
• 使用限制：需拥有对应云平台的模型访问权限，且主动设置环境变量；Auto 消耗按 API 调用计费。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.158)

🅾️ OpenAI 产品更新详解

**Dreaming：ChatGPT 记忆系统全面升级**  
• 功能介绍：OpenAI 为 ChatGPT 推出全新「Dreaming」记忆机制，能够更精准地捕捉用户偏好和背景信息，并在后续会话中自动保持上下文关联。  
• 效果：用户无需反复重设个人偏好，ChatGPT 会在合适时机主动调用记忆，提供更一致的个性化回答，例如记住你常用的编程语言、回复长度偏好或项目名称，显著减少重复性说明。  
• 使用限制：面向所有 ChatGPT 登录用户（Free 用户可能有一定容量限制，Pro/Team/Enterprise 推测记忆窗口更长）；可在设置中管理或清除记忆；平台覆盖 Web、移动端和桌面。  
[原文](https://openai.com/index/chatgpt-memory-dreaming)

**GPT-Rosalind 新能力：生命科学专用智能跃升**  
• 功能介绍：专为生命科学打造的 GPT-Rosalind 模型新增强化生物推理、药物化学专业知识、基因组学分析与实验工作流规划能力。  
• 效果：研究人员可以用它生成可检验的生物假设、辅助先导化合物优化、解读多组学数据，并自动生成湿实验步骤，将数周的分析工作缩短至数小时。  
• 使用限制：通过 OpenAI API 提供，推测需要申请研究访问或加入特定合作伙伴计划；定价可能基于 token 用量或合约协议。  
[原文](https://openai.com/index/introducing-new-capabilities-to-gpt-rosalind)

**Codex for every role, tool, and workflow：覆盖非开发角色**  
• 功能介绍：发布一系列新 Codex 插件、交互站点及注释，为分析师、市场营销、设计师、投资人等岗位提供开箱即用的 AI 工作流。  
• 效果：非工程背景的人员可直接在 Codex 界面用自然语言连接 Salesforce、Figma 或内部数据库，自动生成销售报表、设计变体或投资概要，摆脱对工程师的依赖。  
• 使用限制：需订阅 ChatGPT Enterprise、Team 或 Codex 专用计划；插件市场内按需安装，部分可能附加第三方费用。  
[原文](https://openai.com/index/codex-for-every-role-tool-workflow)

**OpenAI 前沿模型与 Codex 正式登陆 AWS**  
• 功能介绍：OpenAI 最新前沿模型（含推理、代码等系列）及 Codex 现已在 AWS 上正式可用，企业可通过 AWS Marketplace、SageMaker 等渠道直接调用。  
• 效果：现有 AWS 客户能利用已有 VPC、IAM 和安全控制策略快速集成 OpenAI 能力，简化合规与采购流程，从原型验证到生产部署的时间大幅缩短。  
• 使用限制：需 AWS 账户，按用量或预留实例付费；支持企业级协议统一账单；区域可用性参照 AWS 公告。  
[原文](https://openai.com/index/openai-frontier-models-and-codex-are-now-available-on-aws)
