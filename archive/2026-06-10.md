🅰️ Claude 产品更新详解

**Claude Fable 5 与 Claude Mythos 5 模型发布**
• 功能介绍：Anthropic 正式发布两款新一代模型。Claude Fable 5 是首个面向公众安全开放的“Mythos 级”模型，能力超越此前所有公开模型；Claude Mythos 5 为同系列更高级别版本。
• 效果：为普通用户提供前所未有的推理和生成能力，在复杂任务、创意写作和代码生成上达到新高度。Claude Code 同步更新至 v2.1.170 以支持该模型。
• 使用限制：通过 Web、API 和 Claude Code (v2.1.170+) 提供，具体档位和额度详见官方公告。(推测)
[原文](https://www.anthropic.com/news/claude-fable-5-mythos-5)

**Claude Code v2.1.170**
• 功能介绍：发布版本更新，主要引入对 Claude Fable 5 模型的支持。修复了从 VS Code 集成终端或继承环境变量的 shell 启动时，会话无法保存转录且无法通过 --resume 恢复的问题。
• 效果：用户可立即在 Claude Code 中使用 Fable 5 的超强能力；修复后会话记录保存更稳定。
• 使用限制：Claude Code (二进制/Node.js 包)，需更新到此版本。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.170)

**Claude Code v2.1.169**
• 功能介绍：新增 **--safe-mode** 标志，禁用所有自定义项（CLAUDE.md、插件、技能、hooks、MCP 服务器）以便排查问题。新增 **/cd** 命令，可在会话中途切换工作目录且不中断 prompt 缓存。新增 **disableBundledSkills** 设置项，可隐藏内置技能、工作流和斜杠命令。
• 效果：安全模式帮助用户隔离问题；/cd 让长会话中切换项目更流畅；隐藏内置功能可精简模型上下文。
• 使用限制：Claude Code v2.1.169+，安全模式和配置项通过 CLI 标志或环境变量使用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)

**Claude Code v2.1.166**
• 功能介绍：新增 **fallbackModel** 设置，可配置最多三个后备模型，当主模型过载或不可用时按顺序尝试（现在交互式会话也支持 --fallback-model 标志）。Deny 规则的工具名位置支持 glob 模式（"*" 拒绝所有工具）。加强跨会话消息传递安全性。
• 效果：提升服务可用性，避免因模型过载中断工作；更灵活的权限控制。
• 使用限制：Claude Code v2.1.166+，通过设置文件或环境变量配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.166)

**Claude Code v2.1.163**
• 功能介绍：新增 **requiredMinimumVersion** 和 **requiredMaximumVersion** 托管设置，版本不匹配时拒绝启动并引导用户安装批准版本。新增 **/plugin list** 命令列出已安装插件。新增 /btw 的 "c 复制" 快捷键，可直接复制原始 markdown 答案。Hooks: Stop 和 SubagentStop hooks 可返回操作。(推测)
• 效果：企业可强制版本合规；插件管理更直观；复制分享更便捷。
• 使用限制：Claude Code v2.1.163+，托管设置适用于团队/企业环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.163)

**Claude Code v2.1.162**
• 功能介绍：**claude agents --json** 输出新增 waitingFor 字段，显示等待中会话被阻塞于何处（如权限提示）。--tools 显式列出 Grep/Glob 现在在原生构建中提供专用搜索工具。/effort 确认时提示所选级别将作为新会话的默认值。自动完成菜单点击斜杠命令会填入提示而非直接运行。
• 效果：监控和调试 Agent 行为更透明；搜索工具调用更可靠；降低误操作风险。
• 使用限制：Claude Code v2.1.162+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.162)

**Claude Code v2.1.161**
• 功能介绍：OTEL_RESOURCE_ATTRIBUTES 值现在作为 metric 数据点标签，可按团队或仓库等自定义维度切片用量指标。claude agents rows 在任务扇出时显示完成数/总数。并行工具调用中，一个失败的 Bash 命令不再取消同批次其他调用。
• 效果：用量监控更精细；Agent 进度一目了然；并行任务容错性提升。
• 使用限制：Claude Code v2.1.161+，OTEL 增强需配置 OpenTelemetry。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.161)
