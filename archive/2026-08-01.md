🅰️ **Claude 产品更新详解**

**Claude Opus 5 正式发布**
• 功能介绍：Anthropic 推出新一代旗舰模型 **Claude Opus 5**，支持 1M token 上下文窗口，并在快速模式下提供 $10/$50 per Mtok（输入/输出）的定价。该模型现已成为 **Claude Code** 中默认的 Opus 模型（模型代号 claude-opus-5）。
• 效果：面向深度推理、大规模代码库分析、复杂智能体工作流等场景，以更低的延迟和更高的准确率处理超长上下文任务，在编程、长文理解和多步规划上表现显著提升。
• 使用限制：通过 Anthropic API 和 **Claude Code** 可用；Claude Code 中作为默认 Opus 模型；Web/App 端预计逐步推送（推测）；具体用量上限参见官方定价页。
[原文](https://www.anthropic.com/news/claude-opus-5)

**Claude Code v2.1.219：Opus 5 集成 + 沙箱网络管控 + 新 Hook**
• 功能介绍：本次版本重点接入 **Claude Opus 5** 模型，并新增多项开发者控制功能：**sandbox.network.strictAllowlist** 设置可强制沙箱命令仅访问允许列表内的主机，无需每次弹出提示；新增 **DirectoryAdded hook**，在会话中通过 /add-dir 或 SDK 注册新工作目录时触发；**headless stream-json init 事件** 现在包含 **mcp_server_errors** 字段，便于排查 MCP 配置错误。
• 效果：开发者可以更精细地控制沙箱网络访问、监听工作区变更、快速定位 MCP 服务端启动问题，整体提升安全性和开发体验。
• 使用限制：通过 **Claude Code** CLI 更新即可；功能对所有 Claude Code 用户开放；相关配置需在 settings 文件中设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)

**两项 API 设置让 GPT-5.6 在 ARC-AGI-3 基准上得分翻三倍**

• 效果：开发者可在调用 API 时应用这两项设置，在不修改模型本身的情况下大幅提升复杂推理任务的准确率和效率，揭示出 GPT-5.6 在特定配置下的巨大潜力。
• 使用限制：需使用 OpenAI API 并设置相关推理/压缩参数（推测需指定 reasoning_effort 和 compaction 等参数）；适用于 GPT-5.6 模型。
[原文](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores)
