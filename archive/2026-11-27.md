**Claude Code v2.1.331**

**Claude Code v2.1.330**

- 效果: 企业管理员可以统一管控 Claude Code 的登录和云资源配置;easel 让数据分析结果直接可视化,减少手动绘图步骤。
- 使用限制: easel 在 Pro、Max 及可用的 Team、Enterprise 档位,macOS 和 Linux 平台;自动图表可在 /config 中关闭;组织登录需 Enterprise Admin Console 管理。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.330)

**Claude Code v2.1.328**
