🅰️ **Claude 产品更新详解**

**Claude Sonnet 5**
• 功能介绍：Anthropic 发布新一代模型 Claude Sonnet 5，在编码、智能体（agent）与专业工作中达到前沿性能，原生支持 100 万 token 上下文窗口，并推出截至 2026 年 8 月 31 日的促销定价：$2/百万 token（输入）和 $10/百万 token（输出）。
• 效果：用户可处理超长代码库、复杂多步骤代理任务和大规模专业文档，同等成本下获得更高吞吐和更深理解。Claude Code 中已将其设为默认模型，开发者可立即体验到显著的长上下文与整体性能提升。
• 使用限制：已通过 API 和 Claude Code（v2.1.197+）可用；促销价适用于所有付费用户；企业组织可通过控制台统一管理。暂无区域限制公告。
[原文](https://www.anthropic.com/news/claude-sonnet-5)

**Claude Science**
• 功能介绍：全新推出的可定制 AI 工作台，面向科研人员，集成常用研究工具与软件包，生成可审计的工件（auditable artifacts），并提供灵活的计算资源访问。
• 效果：科学家可在统一界面中完成数据分析、建模和报告生成，全程可追溯、可复现，降低从实验到论文的摩擦。区别于通用聊天界面，Claude Science 更像一个“可编程实验室助手”。
• 使用限制：当前已发布，推测需申请或通过 Anthropic 团队计划访问；具体订阅门槛未公开，面向学术和工业研究团队。
[原文](https://www.anthropic.com/news/claude-science-ai-workbench)

**Claude Tag**
• 功能介绍：为团队协作推出的新功能，允许以标签（Tag）方式组织与 Claude 的对话会话、项目或上下文。
• 效果：团队成员可以通过标签快速筛选历史对话、共享项目脉络，提升多人协作中的信息检索效率和会话管理能力，适合持续性的团队项目。
• 使用限制：推测属于 Team 和 Enterprise 计划的协作特性；具体发布平台和开启方式尚未详细说明，预计在 Web 与桌面应用中逐步上线。
[原文](https://www.anthropic.com/news/introducing-claude-tag)

**Claude Code 最新功能汇总（v2.1.186–v2.1.197）**

**组织默认模型与模型限制**
• 功能介绍：管理员可在组织控制台设定默认模型，成员在 /model 中可选“Org default”；同时模型选择器、--model 参数和环境变量都会受组织策略限制，禁止使用受限模型会显示明确提示。
• 效果：企业能统一控制模型版本与成本，防止员工误用高开销或未审批模型，简化合规管理。
• 使用限制：需组织管理员在控制台配置；适用于所有 Claude Code 企业部署。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.196)

**聊天中可点击文件附件、全屏鼠标支持与选择菜单操作**
• 功能介绍：在 Claude Code 对话中的文件附件现可 Cmd/Ctrl‑单击 在 Finder/Explorer 中直接定位；同时全屏模式下全面支持鼠标点击/拖拽操作，包括选择菜单、权限提示、/model 等界面。
• 效果：开发者不再需要通过命令行路径手动查找文件，鼠标操作更贴近日常模态，降低交互学习成本。
• 使用限制：依赖终端支持；鼠标点击受 CLAUDE_CODE_DISABLE_MOUSE_CLICKS 环境变量控制（可禁用）；版本需 ≥ v2.1.196。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.196)

**/rewind 命令支持恢复 /clear 之前的会话**
• 功能介绍：新增 /rewind 子命令，允许用户在误执行 /clear 后回退到清屏前的对话状态。
• 效果：再也不用担心手误清空关键上下文，长时间多步骤开发会话的容错性大幅提升。
• 使用限制：仅在 /clear 执行后的当前会话有效；需要 Claude Code v2.1.191+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.191)

**后台代理永久停止与 /workflows 状态筛选**
• 功能介绍：从任务面板停止的后台 agent 现在彻底终结，不再“复活”；同时 /workflows 的 agent 详情视图支持按状态过滤（按 f 键），方便管理大量并发代理。
• 效果：避免幽灵 agent 占用资源，团队可以高效监控和批量操作 agent 工作流，提升多任务并行效率。
• 使用限制：需升级至 v2.1.191 和 v2.1.186 以上；后台 agent 的终止操作立即生效，无额外配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.191)

**沙盒凭证保护与自动模式 Shell 分类**
• 功能介绍：新增 sandbox.credentials 设置，阻止沙箱命令读取系统凭据文件与敏感环境变量；同时 autoMode.classifyAllShell 选项可将所有 Bash/PowerShell 命令送入 auto-mode 分类器（而非仅匹配高风险模式），拒绝原因会记入 transcript、弹窗和 /permissions recent denials。
• 效果：安全团队可以更精细地控制沙箱内代码执行权限，所有拒绝事件可审计，显著降低凭据泄露风险。
• 使用限制：sandbox.credentials 与 classifyAllShell 均为可选设置，需在配置中显式开启；适用于企业级安全策略。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.193)

**MCP 服务器 CLI 认证与 SSH 兼容**
• 功能介绍：新增 claude mcp login <name> 和 claude mcp logout <name> 命令，支持直接从 CLI 完成 MCP 服务器认证，无需打开交互式 /mcp 菜单；通过 --no-browser stdin 重定向，可远程经 SSH 完成登录。
• 效果：开发者在无图形环境的远程机器上也能配置 MCP 连接，大幅简化自动化脚本和 CI/CD 集成。
• 使用限制：需要 Claude Code v2.1.186+；仅适用于支持 MCP 认证的服务器。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.186)
