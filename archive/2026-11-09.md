**🅰️ Claude 产品更新详解**

**Claude Code v2.1.319**
- 功能介绍: 调整了 auto mode 在遥测或功能开关关闭时的行为,包括在 LLM 网关后的场景;服务器无法检查的调用会被询问或拒绝,不再回退到内置分类器;新增 **CLAUDE_CODE_AUTO_MODE_SERVER=0** 环境变量以保留旧行为(Bedrock、Vertex、Foundry 不受影响)。
- 效果: 提升企业网关环境下的安全可控性,避免模型在无法验证时擅自执行操作。
- 使用限制: **Claude Code** CLI;环境变量配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)

**Claude Code v2.1.318**
- 功能介绍: 新增多项能力——记录会话中 Claude Code 请求开启 mods 时的用户回答;在 Claude apps 网关的 mantle upstreams 上新增 assume_role,支持跨 AWS 账户角色与按开发者成本归因;为 mod 的 **$.model.fork** 增加 effort 选项,让快速侧任务可以低 effort 运行;在 **claude auth status** 中显示存储的 claude.ai 登录截止日期。
- 效果: 面向团队与多账户 AWS 场景,提升成本管理与任务调度灵活性;开发者可更精细地控制 fork 任务的算力消耗。
- 使用限制: **Claude Code** CLI;部分功能需企业网关或 AWS 配置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

**Claude Code v2.1.317**
- 功能介绍: 新增多项安全与调度改进——**/schedule** 在云端定时任务意外附带 connectors 时给出警告及移除方法;web 或 shell 工具调用发送账户邮箱前增加确认;Agent SDK hook 回调新增 **onFailure: "block"**,失败时阻断动作而非放行;**Claude Desktop** 的 Code 标签页在组织远程托管设置未加载时显示提示。
- 效果: 强化隐私保护与任务调度透明度,防止敏感信息意外外发;Agent SDK 开发者获得更严格的失败处理语义。
- 使用限制: **Claude Code** CLI、**Claude Desktop**、Agent SDK。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)
