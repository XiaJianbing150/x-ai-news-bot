**🅰️ Claude 产品更新详解**

**Claude Code v2.1.269:插件评测与输出风格切换**
- 功能介绍: 新增 **claude plugin eval** 命令,可对插件运行评测套件并获得可复现的评分结果(JSON + HTML 报告);新增 **/output-style [name]** 命令,可在 Remote Control、云端及 headless 会话中列出并切换输出风格。
- 效果: 插件开发者可以像跑测试一样验证插件质量;远程或无人值守场景下也能调整 Claude 的回复格式,适配不同工作流。
- 使用限制: Claude Code CLI / Desktop / SDK,需 v2.1.269+;插件评测需插件自带 eval 套件。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.269)

**Claude Code v2.1.268:网关定价同步与公网访问警告**
- 功能介绍: Claude apps gateway 新增 **pricing** 配置项,登录后的 Claude Code 客户端可通过托管设置获得与 spend meter 一致的费率;当 **access_control.allow_cidrs** 为空时新增启动警告,首次从公网地址收到请求时也会警告一次;新增 **gatewayInternalNetworks** 托管设置。
- 效果: 企业管理员可以让 /cost 和遥测数据与实际计费完全对齐;公网暴露风险在启动阶段即可被发现,降低误配导致的安全隐患。
- 使用限制: Claude apps gateway 部署场景,面向 Team / Enterprise 管理员。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.268)

**Claude Code v2.1.267:maxEffortLevel 上限设置**
- 功能介绍: 新增 **maxEffortLevel** 设置(顶层或 modelSettings 下按模型配置),可对包括 Bedrock、Vertex、Foundry 在内的所有 provider 限制 effort level 上限,用户仍可选择更低档位。
- 效果: 管理员可以防止团队成员在昂贵模型上消耗过多推理预算,同时保留灵活性。
- 使用限制: Claude Code 全平台,面向组织级管控场景。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.267)

**Claude Code v2.1.265:插件目录与工具结果上限**
- 功能介绍: **--plugin-dir** 现在支持指向包含多个插件的文件夹,运行中增删子文件夹会被实时感知;工具结果保存到磁盘的上限设为 1 GB,截断时对话预览会提示。
- 效果: 插件管理从单文件升级为目录级热加载,适合大型插件生态;超大工具输出不再撑爆磁盘。
- 使用限制: Claude Code CLI,插件开发者与重度用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.265)

**Claude Code v2.1.260:全屏 diff 面板与缓存未命中归因**
- 功能介绍: 全屏模式下新增 **/diff** 切换的 diff 面板,实时展示 Claude 编辑产生的未提交变更;**/cost** 和状态栏的 prompt_cache 字段新增缓存未命中的可能原因(如工具定义或系统提示变化、TTL 过期);headless 会话新增 **/reload-plugins**。
- 效果: 开发者可以边看 Claude 改代码边审阅 diff,不用切到 git;排查 prompt cache 命中率下降时有了直接线索。
- 使用限制: Claude Code CLI / Desktop / SDK,全平台。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.260)

**Claude Code v2.1.261:输出上限与组织策略诊断**
- 功能介绍: 新增 **bashOutputMaxChars** 和 **taskOutputMaxChars** 设置,可将命令与后台任务输出内联上限提升至 128K 字符;**/status** 和 **claude doctor** 新增"Organization policy"行,说明组织策略加载失败的原因(如代理未放行端点)。
- 效果: 长输出场景(如大日志、批量测试)减少文件落盘频率;企业用户排查策略同步问题不再靠猜。
- 使用限制: Claude Code 全平台。
