**/config 快捷设定键值语法**
• 功能介绍: Claude Code v2.1.181 新增 /config key=value 语法, 可直接从提示框设置任意配置项 (如 /config thinking=false), 同时新增 macOS Apple Events 沙盒设置、客户端存在文件环境变量及升级内建 Bun 运行时.
• 效果: 用户无需离开对话即可调整思考模式、通知行为等; 沙盒命令可按需发送 Apple Events, 适用于自动化 macOS 操作; 存在文件抑制移动推送避免骚扰.
• 使用限制: Claude Code; 支持交互模式、-p 模式和远程控制; 推测无特定档位限制.
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.181)

**Tool(param:value) 权限规则语法**
• 功能介绍: v2.1.178 新增 Tool(param:value) 语法匹配工具输入参数 (支持 * 通配符), 如 Agent(model:opus) 可阻断 Opus 子代理; .claude/skills 嵌套目录加载与 .claude/ 目录最近优先规则.
• 效果: 企业管理员可精细控制子代理模型使用, 嵌套项目中同名技能显示为 <dir>:<name> 共存; 最近的 agent/workflow/output-style 配置自动胜出.
• 使用限制: Claude Code; 推测面向 Team/Enterprise 管理员.
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.178)

**子代理多层递归**
• 功能介绍: v2.1.172 允许子代理再次生成自己的子代理, 最大嵌套深度 5 层; Bedrock 自动读取 ~/.aws config 区域; /plugin 新增市场搜索栏; 修复 1M 上下文无使用积分的卡死问题.
• 效果: 复杂多步骤任务可拆解为树状子代理并行; AWS 用户减少手动配置负担; 插件发现更便捷.

• 使用限制: Claude Code; Enterprise 托管部署.
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.175)
