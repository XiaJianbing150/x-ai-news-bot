🅰️ **Claude 产品更新详解**

**Claude Fable 5 与 Mythos 5 模型发布**
• 功能介绍：Anthropic 正式发布 **Claude Fable 5**，属于 Mythos 级模型，能力超越以往所有公开模型，并已完成安全调整。
• 效果：开发者可在 **Claude Code** 中获得更强的代码生成、复杂推理与长上下文处理能力，适合从大型重构到系统设计级任务。相比上一代模型，指令遵循和多步骤规划表现明显提升。
• 使用限制：通过 **Claude Code v2.1.170** 及以上版本使用，API 同步可用。推测首批覆盖 Max / Pro / Team 用户，按 token 计费。(推测)
[原文](https://www.anthropic.com/news/claude-fable-5-mythos-5)

**Claude Code：子代理递归生成**
• 功能介绍：v2.1.172 起，子代理（sub-agent）可以创建自己的子代理，最多支持 5 层递归。
• 效果：处理大型项目时主代理可自动拆分多层子任务，显著提升并行与分解效率，适合多模块协调、全栈重构等场景。
• 使用限制：**Claude Code** 终端用户默认启用，无需额外配置，仅限会话内的代理调用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.172)

**Claude Code：安全模式 --safe-mode**
• 功能介绍：v2.1.169 新增 --safe-mode 启动标志及环境变量 CLAUDE_CODE_SAFE_MODE，启动时禁用所有自定义（CLAUDE.md、插件、技能、hooks、MCP 服务器）。
• 效果：当自定义配置导致异常时，可快速进入纯净环境排查问题，无需手动逐一关闭扩展。
• 使用限制：所有 **Claude Code** 用户通过命令行或环境变量启用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)

**Claude Code：会话内切换目录 /cd**
• 功能介绍：v2.1.169 新增 /cd 命令，可在会话中切换到新工作目录，并保留 prompt 缓存。
• 效果：在一个会话中跨项目工作时无需重启，保持上下文连续性，尤其适合同时在多个模块间调试。
• 使用限制：仅限交互式 **Claude Code** 会话。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)

**Claude Code：回退模型配置 fallbackModel**

• 效果：降低模型拥塞或服务中断对开发流程的影响，提升整体可用性。
• 使用限制：通过设置文件配置，所有 **Claude Code** 用户均可使用。

**Claude Code：Hooks 重试与并行工具调用改进**
• 功能介绍：v2.1.163 的 Stop 和 SubagentStop hooks 可返回 retry 指令；v2.1.161 优化并行工具调用，一个 Bash 命令失败不再取消同一批次的其他调用。
• 效果：更精细的自动化流程控制，并行执行容错能力更强，大任务多个独立步骤互不干扰。
• 使用限制：所有使用 hooks 的 **Claude Code** 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.163)
