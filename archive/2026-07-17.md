**Claude Code 近一周更新 (v2.1.205–v2.1.212)**
• 功能介绍：连续发布 8 个版本，主要包括：
  - **Auto mode 默认可用**：在 Bedrock、Vertex AI、Foundry 上无需额外 opt-in 即可启用自动模式 (v2.1.207)
  - **屏幕阅读器模式**：运行 `claude --ax-screen-reader` 或设置环境变量以纯文本形式输出，改善无障碍体验 (v2.1.208)
  - **目录路径补全**：/cd 命令支持目录建议，匹配 /add-dir 行为 (v2.1.206)
  - **子代理与 fork 操作优化**：/fork 会将对话复制到新后台会话（agent view 中独立一行），原会话继续工作；主会话中的子代理改为 /subtask (v2.1.212)
  - **工具调用限制**：新增 WebSearch 会话级调用上限（默认 200 次，可通过环境变量配置）(v2.1.212)
  - **耗时显示**：长时间工具调用在摘要行展示实时计时器，避免看起来卡死 (v2.1.210)
  - **自动模式规则**：禁止篡改会话转录文件 (v2.1.205)
  - **vim 模式映射**：支持两键序列（如 jj）映射为 Escape (v2.1.208)
  - **企业启动包装器**：agent view 与后台服务通过 CLAUDE_CODE_PROCESS_WRAPPER 支持企业启动器 (v2.1.208)
  - **安全性/修复**：修复了子代理权限问题、Windows 工作树删除、JSON schema 校验、流输出冻结等多项 bug。
• 效果：开发者获得更顺畅的自动模式交互、更好的可访问性与 vim 编辑体验，企业部署更安全可控，子代理工作流更清晰。
• 使用限制：**Claude Code** CLI 工具，通过 API 或 Bedrock/Vertex AI/Foundry 使用，部分功能需相应的环境变量或设置文件。
