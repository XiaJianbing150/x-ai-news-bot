**📰 Anthropic & OpenAI 速报 · 2026-06-21 Sunday**

🅰️ **Claude 产品更新详解**

**Claude Code v2.1.185：API 等待提示优化**
• 功能介绍：将流式响应停滞提示从“No response from API · Retrying in …”改为“Waiting for API response · will retry in …”，静默超时检测从 10 秒延长至 20 秒。
• 效果：减少因短暂网络波动触发的误导性重试提示，让开发者在等待大模型响应时获得更清晰的状态反馈；20 秒阈值更适合处理长上下文或复杂工具调用场景。
• 使用限制：适用于 **Claude Code** 所有版本，更新后自动生效。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.185)

**Claude Code v2.1.183：自动模式安全增强**
• 功能介绍：在自动模式下拦截破坏性 git 命令（如 git reset --hard、git checkout -- .、git clean -fd、git stash drop），并阻止非当前会话创建的 commit 被 git commit --amend 修改；同时拦截未经用户明确指定 stack 的 terraform destroy / pulumi destroy / cdk destroy。用户指定时不再拦截。
• 效果：防止 AI 代理在自动执行中意外丢弃本地工作或删除云资源，提高生产环境中的安全性与可控性，特别适合 CI/CD 或无监督长时间任务。
• 使用限制：适用于 **Claude Code** 所有版本；拦截行为可通过明确指示覆盖。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.183)

**Claude Code v2.1.181：/config 快捷设置与新环境变量**
• 功能介绍：新增 /config key=value 语法，可直接在终端中设定任意配置项（如 /config thinking=false），支持交互模式、-p 模式和远程控制。同时引入 sandbox.allowAppleEvents 设置允许沙盒命令发送 Apple Events，新增 CLAUDE_CLIENT_PRESENCE_FILE 环境变量，指向标记文件后可在本机操作时抑制移动推送通知。内置 Bun 运行时升级至 1.4，并改进了长文本输出的流式传输。
• 效果：开发者无需编辑配置文件即可快速切换思考模式等选项；macOS 自动化工作流更灵活；多设备使用时避免不必要的手机通知，体验更顺畅。
• 使用限制：适用于 **Claude Code** 所有版本；allowAppleEvents 需手动开启。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.181)

**Claude Code v2.1.179：连接中断修复与滚动兼容性**
• 功能介绍：修复了流式响应中途断开时显示原始错误和 spinner 卡死的问题，现在部分响应会被保留；修复了 WSL2 下 Windows Terminal 与 VS Code 内鼠标滚轮失效的回归问题；修复了大目录树 glob 导致 Bash 工具描述过大的 Sandbox 问题；修复反馈调查中单数字误识问题。
• 效果：连接不稳定时不再丢失已生成内容，WSL 开发者在常用终端中的滚动和交互恢复正常，整体稳定性明显提升。
• 使用限制：适用于 **Claude Code** 所有版本。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.179)

**Claude Code v2.1.178：工具权限参数匹配与嵌套技能目录**
• 功能介绍：权限规则新增 Tool(param:value) 语法，支持用 * 通配符匹配工具的输入参数（如 Agent(model:opus) 可阻止 Opus 子代理）。嵌套的 .claude/skills 目录中的技能现在可在处理该目录文件时加载，名称冲突时以 <dir>:<name> 区分。同时优化了嵌套 .claude/ 目录下代理、工作流和输出样式的就近匹配规则。
• 效果：为团队或大型项目提供细粒度权限控制，防止误用昂贵模型；多层级技能管理使用更容易，避免命名冲突覆盖。
• 使用限制：适用于 **Claude Code** 所有版本；权限规则语法可在 .claude 配置文件中使用。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.178)

**Claude Code v2.1.176：会话标题多语言与 Bedrock 凭证缓存**
• 功能介绍：会话标题现在自动跟随对话语言生成（可通过 language 设置固定语言）。新增 footerLinksRegexes 设置，支持在页脚栏显示按正则匹配的链接徽章。改进了 Bedrock 凭证缓存：awsCredentialExport 导出的凭证现在按其过期时间缓存，而非固定 1 小时。修复了 availableModels 强制策略下别名模型仍可绕过限制的问题。
• 效果：多语种团队获得更直观的会话列表管理；AWS 用户减少频繁重新认证；企业管理员对可用模型的控制更加严格。
• 使用限制：适用于 **Claude Code** 所有版本；Bedrock 特性仅限使用 AWS 后端的用户。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.176)

**Claude Code v2.1.175：可用模型强制策略**
• 功能介绍：新增 enforceAvailableModels 托管设置。开启后，availableModels 白名单同时约束默认模型（若默认模型被禁止，则回退至白名单中第一个模型），且用户或项目级设置无法扩大托管 availableModels 列表。
• 效果：企业 IT 管理员可彻底锁定可用的 Claude 模型，避免终端用户通过本地配置使用未授权模型，强化合规与成本管控。
• 使用限制：仅适用于 **Claude Code** 托管（Managed）设置环境，通常为 Team/Enterprise 部署。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.175)

**Claude Code v2.1.174：模型选择器修复与鼠标滚轮加速控制**
• 功能介绍：新增 wheelScrollAccelerationEnabled 设置，可禁用全屏模式下的鼠标滚轮加速。修复了 /model 选择器中默认模型对应家族不显示的问题（Max/Team Premium/Enterprise 显示 Opus，Pro/Team 显示 Sonnet，API 按量付费显示 Opus）；修复了自定义 ANTHROPIC_DEFAULT_SONNET_MODEL 时仍显示硬编码 Sonnet 版本标签的问题。
• 效果：用户通过 /model 可更清晰地看到当前实际使用的模型，滚轮体验可定制，减少误操作。
• 使用限制：适用于 **Claude Code** 所有版本；滚轮加速设置需手动开启/关闭。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.174)
