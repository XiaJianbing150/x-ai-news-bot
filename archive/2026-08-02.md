**Claude Opus 5**
• 功能介绍：Anthropic 发布最新一代旗舰模型 **Claude Opus 5**，具备 1M token 长上下文窗口，快速模式下输入价格 $10/Mtokens、输出价格 $50/Mtokens。
• 效果：针对高难度推理、多步骤代理任务、前沿网络安全评估等场景大幅提升表现，是目前 Claude 家族中最强模型，可直接用于复杂编程、深度分析和企业级工作流。
• 使用限制：已通过 Anthropic API 提供；**Claude Code** 中将 claude-opus-5 设为默认 Opus 模型；Claude Pro / Max / Team 用户预计可在产品内切换（推测）。价格相比前代显著降低，推动高端能力落地。
[原文](https://www.anthropic.com/news/claude-opus-5)

**Claude Code v2.1.219**
• 功能介绍：新增 **Claude Opus 5** 模型支持，将其设为默认 Opus；添加 `sandbox.network.strictAllowlist` 设置，可对沙箱命令禁止非白名单主机而不弹窗；新增 **DirectoryAdded** 钩子，会在 `/add-dir` 或 SDK `register_repo_root` 注册新工作目录后触发；在无头模式 stream-json 的 init 事件中返回 `mcp_server_errors`，列出 `--mcp-config` 条目。
• 效果：开发者可直接在 CLI 中调用最新旗舰模型处理超长上下文任务；通过网络白名单/钩子增强沙箱安全与自动化；MCP 配置错误直接上报，方便调试。
• 使用限制：更新至 **Claude Code** v2.1.219 即可使用，适用于所有 Claude Code 用户（需有效 API 密钥，模型按量计费）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)
