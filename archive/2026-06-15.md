🅰️ **Claude 产品更新详解**

**Claude Fable 5 模型正式发布**
• 功能介绍：Anthropic 推出 **Claude Fable 5**，这是一款基于 **Mythos 级** 能力、经过安全调校后对公众开放的模型，Fable 的能力超过此前所有公开发布的模型。同时发布的还有更高能力的 **Claude Mythos 5**，目前受到更严格的使用限制。
• 效果：用户可在 **Claude Code**、API 等渠道直接使用 Fable 5 进行复杂代码生成、长篇分析与推理，体验迄今最强的 Claude 模型。Mythos 5 能力更强，但暂不对一般用户开放。
• 使用限制：Fable 5 可立即在 **Claude Code v2.1.170+** 和 API 中使用，推测支持 Pro / Max / Team / Enterprise 及 API 用户，无等候名单。（Mythos 5 受美国联邦指令管控，目前暂停访问。）
[原文](https://www.anthropic.com/news/claude-fable-5-mythos-5)

**Claude Code v2.1.170–v2.1.177 多项更新**
• 功能介绍：**Claude Code** 从 v2.1.170 起支持 Claude Fable 5，并在后续版本中新增：子代理可递归创建最多 5 层子代理、安全模式 (--safe-mode) 启动以排查自定义配置、/cd 命令中途切换工作目录、disableBundledSkills 隐藏内置技能与命令、enforceAvailableModels 管理设置强制模型白名单、wheelScrollAccelerationEnabled 选项控制全屏滚动加速、搜索插件市场、多语言会话标题生成等。
• 效果：开发者能更精准地管理可用模型，用 /cd 灵活切换项目，通过安全模式快速排除插件/CLAUDE.md 引起的问题，子代理递归使复杂代码重构可自动分派多层 subtask。Bedrock 用户的凭证缓存更符合到期时间，避免频繁重新认证。
• 使用限制：均为 **Claude Code** 终端应用功能，需更新至对应版本。部分设置（如 enforceAvailableModels）仅适用于 Managed 企业场景，需管理员配置。Fable 5 模型在 /model 选择器中可见，计划与默认模型关系见版本说明。
[原文(汇总)](https://github.com/anthropics/claude-code/releases/tag/v2.1.170)

🅾️ **OpenAI 产品更新详解**

**OpenAI 计划收购 Ona，为 Codex 增加持久云环境**
• 功能介绍：**OpenAI** 宣布计划收购 **Ona**，一家专注于安全、持久云环境的企业。通过收购，**Codex** 将能运行长期、持续存在的 AI 代理，支撑复杂的多步骤企业工作流。
• 效果：未来用户可以直接在 Codex 中启动长时间运行的代理任务（如持续监控数据库、多天数据分析），代理的状态和数据不会因会话结束而丢失，大幅扩展 Codex 在企业自动化中的使用场景。
• 使用限制：收购尚未完成，功能上线时间待定。（推测）未来将通过 Codex CLI 和 API 开放，可能优先面向 Enterprise 客户。
[原文](https://openai.com/index/openai-to-acquire-ona)

**Oracle 云上可直接使用 OpenAI 模型和 Codex**
• 功能介绍：**OpenAI** 模型（GPT 系列）和 **Codex** 现可通过 **Oracle Cloud (OCI)** 访问，用户可以使用已有的 Oracle 云承诺消费额度，在 OCI 上构建和部署 AI 应用，并享受企业安全与治理能力。
• 效果：已在 Oracle 云上运行关键负载的企业，无需切换云平台即可直接调用 OpenAI 的先进模型与 Codex，简化采购与集成流程。
• 使用限制：需为 Oracle 云客户，通过 OCI 控制台或 API 访问；计费使用现有 Oracle 承诺消费，具体模型版本及区域可用性请查阅 OCI 文档。
[原文](https://openai.com/index/openai-on-oracle-cloud)

**OpenAI Academy 发布三节新课程**
• 功能介绍：**OpenAI Academy** 推出三节面向新工作时代的课程，内容涵盖如何构建实用的 AI 技能、创建可重复的工作流，以及将 AI 代理应用于日常工作。
• 效果：用户可免费学习如何用 ChatGPT、Codex 等工具自动化重复任务、搭建 agent 工作流，把 AI 真正融入日常工作而非一次性提问。
• 使用限制：课程开放给所有用户，通过 OpenAI Academy 平台访问，无需付费。
[原文](https://openai.com/index/academy-courses-applying-ai-at-work)
