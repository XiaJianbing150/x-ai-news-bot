🅰️ **Claude 产品更新详解**

**Claude Code v2.1.186: MCP 服务器 CLI 认证与工作流过滤**
• 功能介绍: 新增 **claude mcp login** / **claude mcp logout** 命令，支持在 CLI 中直接认证 MCP 服务器，无需打开交互式 /mcp 菜单；支持 --no-browser stdin 重定向，方便在 SSH 会话中完成认证。同时新增 /workflows 代理详情视图的状态过滤（按 f 键），以及 Web UI 上的 Installed 插件标签页中展示 Skills 部分。
• 效果: 对通过 SSH 远程开发或使用 CI/CD 管道的用户，现在可以在无图形界面的终端里完成 MCP 服务器认证，解决了此前必须打开交互式菜单的痛点。工作流状态过滤让多代理调试更便捷。
• 使用限制: Claude Code CLI，版本 ≥2.1.186
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.186)

**Claude Code v2.1.185: 流式响应断连提示优化**
• 功能介绍: 将流式传输停滞的提示文案从 "No response from API · Retrying in …" 改为 **"Waiting for API response · will retry in …"**，并将触发阈值从 10 秒延长到 **20 秒**，减少因临时网络波动造成的误导性错误提示。
• 效果: 用户体验改善——等待 API 响应时不再看到令人紧张的"无响应"措辞，20 秒的宽限期也能覆盖大部分瞬时网络抖动。
• 使用限制: Claude Code CLI，版本 ≥2.1.185
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.185)

**Claude Code v2.1.183: 自动模式安全性强化**
• 功能介绍: 自动模式下，**破坏性 git 命令**（git reset --hard、git checkout -- .、git clean -fd、git stash drop）现在被拦截，除非用户明确要求丢弃本地工作；**git commit --amend** 在当前会话中未创建过的 commit 上被阻止；**terraform destroy / pulumi destroy / cdk destroy** 被阻止，除非用户指定了具体的 stack。此外新增请求的模型已弃用时的警告提示。
• 效果: 大幅降低自动模式意外丢失代码或破坏基础设施的风险。对于依赖自动代理做多步骤重构的开发者，这是关键的安全网。
• 使用限制: Claude Code CLI，版本 ≥2.1.183
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.183)

**Claude Code v2.1.181: /config 命令增强与沙盒设置**
• 功能介绍: 新增 **/config key=value** 语法，可直接在提示符中设置任意配置项（如 /config thinking=false），支持交互模式、-p 模式及远程控制。新增 **sandbox.allowAppleEvents** 可选设置，允许沙盒命令在 macOS 上发送 Apple Events。新增 **CLAUDE_CLIENT_PRESENCE_FILE** 环境变量，指向标记文件时可抑制移动端推送通知。
• 效果: /config 快捷语法让模型切换和参数调整不必跳出工作流；presence file 则解决了在桌面工作时手机仍收到 Claude 通知的干扰问题。
• 使用限制: Claude Code CLI，版本 ≥2.1.181
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.181)

**Claude Code v2.1.179: 连接中断处理与 WSL2 修复**
• 功能介绍: 修复了流式传输中途连接断开的问题——部分响应现在被保留而非显示原始错误，且 spinner 不再卡在 "running tool" 状态。修复了 WSL2 下 Windows Terminal 和 VS Code 中的鼠标滚轮滚动问题；修复了 Linux 上 denyRead/allowRead glob 作用于大目录树时导致 Bash 工具描述异常膨胀的沙盒问题。
• 效果: 提升远程开发和 WSL2 用户的稳定性体验，连接中断时不再丢失已生成的代码。
• 使用限制: Claude Code CLI，版本 ≥2.1.179
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.179)

**Claude Code v2.1.178: 工具参数匹配权限与嵌套技能加载**
• 功能介绍: 新增 **Tool(param:value)** 语法用于权限规则匹配，支持 * 通配符（例如 Agent(model:opus) 可阻止 Opus 子代理）。嵌套的 .claude/skills 目录中的技能现在可在处理嵌套目录文件时自动加载；同名时显示为 <dir>:<name> 以保持共存。嵌套 .claude/ 目录的代理、工作流和输出样式采用最接近工作目录的配置。
• 效果: 权限控制粒度大幅提升，团队可以精细管理不同子代理的模型使用权限；嵌套技能加载让 monorepo 中的多团队协作更灵活。
• 使用限制: Claude Code CLI，版本 ≥2.1.178
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.178)
