**Claude Code v2.1.239：成本估算计入数据驻留溢价 + /claude-api 升级**
• 功能介绍：**/cost**、状态栏、**--max-budget-usd** 现在对数据驻留工作区计入 1.1× US-only-inference 溢价；首次在 Bedrock、Vertex、Foundry 等此前排除的环境提供一次性全屏渲染；新增 **/claude-api upgrade** 把 Python 项目从 anthropic 0.x 迁移到 1.x。
• 效果：数据驻留用户预算更准；更多云环境可开全屏；旧 SDK 项目可半自动迁移，减少手动改依赖。
• 使用限制：**Claude Code** CLI v2.1.239，升级即生效；计费沿用现有订阅/API 额度（推测）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.239)

**Claude Code v2.1.238：keybindingFlavor 与插件市场 headersHelper**
• 功能介绍：新增 **keybindingFlavor** 设置，设为 “readline” 后，输入框内 Ctrl+W 会像 Bash 一样删到前一个空白；插件市场为 url marketplace/catalog entry 新增 **headersHelper**，可运行命令铸造短期 HTTP 头。
• 效果：终端编辑习惯更顺手；私有插件市场能用动态 token 完成鉴权拉取。
• 使用限制：**Claude Code** CLI，需在配置中开启；headersHelper 仅用于安装/更新插件时（推测）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.238)

**Claude Code v2.1.237：修复网关缓存 + 新增 Concise 输出风格**
• 功能介绍：修复使用 LLM gateway 或自定义 base URL 时的 prompt caching；新增内置 **Concise** 输出风格，Claude 直接给结果，跳过开场白和叙述。
• 效果：自定义网关用户也能享受缓存省钱；自动化、脚本化场景下输出更快更干净。
• 使用限制：**Claude Code** CLI；在 /config 的 Output style 下选择 Concise。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.237)

**Claude Code v2.1.236：ANTHROPIC_DEFAULT_MODEL、notify_when_idle 与沙箱规则**
• 功能介绍：新增 **ANTHROPIC_DEFAULT_MODEL** 环境变量，设置新会话默认模型；跨会话 SendMessage 新增 **notify_when_idle**，可让本机另一个 Claude Code 会话下次空闲时发一次性通知；macOS 上通配 read-deny 规则现在优先。
• 效果：多模型工作流少手动 /model；并行多会话可互相提醒；敏感文件防
