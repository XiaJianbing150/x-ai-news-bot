**Claude Fable 5.2 与 Claude Mythos 5.2**
- 功能介绍: Anthropic 发布两款新模型 **Claude Fable 5.2** 与 **Claude Mythos 5.2**,Fable 5.2 成为新的默认 Fable 模型。
- 效果: 1M context 窗口,定价 $8/$40 每 Mtok,cache reads 为 $0.20/Mtok;面向长上下文推理与高吞吐场景,较前代在成本与上下文长度上形成明确升级。
- 使用限制: 通过 Anthropic API 与 Claude Code 可用;Claude Code 中模型 ID 为 **claude-fable-5-2**。Mythos 5.2 的档位与平台细节官方未在条目中展开(推测同为 API 优先)。
[原文](https://www.anthropic.com/claude-fable-and-mythos-5-2)

- 效果: 面向团队协作与工具规则配置场景,减少静默失败,让管理员和开发者更快定位配置问题。
- 使用限制: Claude Code CLI,版本 v2.1.326。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)

**Claude Code v2.1.325**

- 效果: 提升安全性,并改善 notebook 与策略受限场景下的用户引导。
- 使用限制: Claude Code CLI,版本 v2.1.325。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)

**Claude Code v2.1.323 — Code Mode**
- 功能介绍: 新增实验性 **Code Mode**(opt-in),Claude 通过编写 JavaScript 来调用其工具;plugin.json 新增 `engines["claude-code"]` 版本范围校验,超出范围的插件不会被安装、更新或加载;插件 TypeScript hooks 模块增加类型检查。
- 效果: Code Mode 让 Claude 以代码方式编排工具调用,适合需要复杂控制流的自动化任务;插件版本约束避免不兼容插件破坏工作流。
- 使用限制: Claude Code CLI,版本 v2.1.323;Code Mode 为实验性 opt-in,可按组织关闭。文档见 code.claude.com/docs/en/code-mode。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)
