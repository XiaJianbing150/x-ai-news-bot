🅰️ **Claude 产品更新详解**

**Claude Opus 5**
• 功能介绍：发布全新模型 **Claude Opus 5**，成为当前能力最强的 Claude 模型。在 **Claude Code** 中作为默认 Opus 模型启用，支持 1M token 上下文窗口，并在 fast mode 下提供 **$10/Mtokens(输入) 与 $50/Mtokens(输出)** 的定价。  
• 效果：适用于复杂推理、深度代码分析、长文档理解等高端场景；在代码生成、多步骤规划、研究辅助等任务上显著超越前代 Opus 模型，并在 1M 大上下文内保持高一致性。  
• 使用限制：通过 Anthropic API 及 **Claude Code** 接入。快速模式定价较低，API 速率限制可参考账户 tier；Web/移动端是否全量推送暂未明确（推测面向 Pro/Max 用户优先）。  
[原文](https://www.anthropic.com/news/claude-opus-5)

**Ask Claude about the Anthropic Economic Index**  
• 功能介绍：发布 **Anthropic Economic Index Connector**，让用户可以直接在对话中向 Claude 提问关于 Anthropic 经济指数的数据与分析。本质是一个 MCP 连接器或内置数据源，将官方经济研究指标引入 Claude。  
• 效果：分析师、研究人员可自然语言查询劳动力市场分布、职业 AI 暴露度等经济指标，无需离开聊天界面即获得数据洞察，替代手动查表或编写查询代码的流程。  
• 使用限制：推测面向 **Claude Pro / Max / Team** 及 API 用户，通过 MCP 或直接对话访问；具体是否需要手动启用连接器或依赖地区尚未明确。  
[原文](https://www.anthropic.com/news/anthropic-economic-index-connector)

**Claude Code v2.1.219：集成 Opus 5 & 沙箱网络安全白名单等**  
• 功能介绍：**v2.1.219** 将 **Claude Opus 5** 设为默认 Opus 模型并支持 1M 上下文；新增 **sandbox.network.strictAllowlist** 设置，可禁止未经许可的主机的沙箱命令；新增 **DirectoryAdded hook**，在 /add-dir 或 SDK 注册新工作目录时触发；在 headless stream-json 的 init 事件中添加 **mcp_server_errors**，便于诊断 MCP 配置问题。  
• 效果：企业用户可精细控制沙箱网络出口，防止数据泄露；IDE/插件可感知目录变更以自动刷新上下文；调试 MCP 服务器连接更透明。  
• 使用限制：**Claude Code** v2.1.219+，通过 npm 更新。环境要求同 Claude Code 本身。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)

**Claude Code v2.1.218：后台 /code-review 与屏幕阅读器改进**  
• 功能介绍：**/code-review** 改为作为后台子代理运行，不再占据主对话，且以堆叠的斜杠命令作为评审目标；在 **--ax-screen-reader** 模式下为单词/行删除（Option+Delete, Ctrl+W 等）增加屏幕朗读提示；修复 Windows 路径含 \u 前缀片段（如 C:\Users\unicorn）被转换为 CJK 字符的 bug。  
• 效果：代码评审时不打断主工作流，保持良好的对话上下文；视障开发者获得更精准的删除反馈；Windows 路径不再损坏。  
• 使用限制：**Claude Code** v2.1.218+，支持 --ax-screen-reader 模式。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.218)

**Claude Code v2.1.217：emoji 短码补全与转录告警**  
• 功能介绍：输入提示支持 **emoji 短码自动补全**（如 :heart: → ❤️），可通过 **emojiCompletionEnabled** 设置关闭；新增转录写入失败告警（如磁盘满）或环境变量导致会话保存关闭时的提示，避免会话静默丢失；修复 MCP 工具输出截断后仍占用全部未截断结果的内存泄漏。  
• 效果：聊天体验更轻松；会话记录不会悄悄丢失，数据安全检查点更主动；长时间 MCP 任务内存占用降低。  
• 使用限制：**Claude Code** v2.1.217+，emoji 补全默认启用。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.217)

**Claude Code v2.1.216：沙箱文件系统豁免与性能修复**  
• 功能介绍：新增 **sandbox.filesystem.disabled** 设置，可跳过文件系统隔离但保留网络出口控制；修复长会话中消息规范化成本随轮次平方增长导致的数秒卡顿与恢复缓慢；修复 OAuth token 过期后 auto 模式误拒命令（HTTP 401 错误）；修复 **AskUserQuestion** 在用户要求停止后仍继续执行的问题。  
• 效果：可信环境下可提升文件访问性能；连续长对话不再在后期严重降速；OAuth 认证刷新后自动许可更稳定。  
• 使用限制：**Claude Code** v2.1.216+。  
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.216)

🅾️ **OpenAI 产品更新详解**

**Health in ChatGPT**
• 功能介绍：在 ChatGPT 中推出 **Health** 功能，允许符合条件的美国用户安全连接医疗记录和 Apple Health 数据，以获取更加个性化的健康洞察与理解。  
• 效果：用户可向 ChatGPT 提问基于自身健康数据的分析、趋势解释或生活方式建议，相当于多了一个隐私保护下的健康信息整理代理。  
• 使用限制：目前仅限 **美国** 符合条件的用户，具体需连接医疗提供者或 Apple Health；推测面向 **ChatGPT Plus / Pro / Team** 等付费计划，并遵循 HIPAA 等隐私保护协议。  
[原文](https://openai.com/index/health-in-chatgpt)

**Introducing OpenAI Presence**
• 功能介绍：发布 **OpenAI Presence**，一个经过验证的企业 AI 代理平台，帮助组织部署值得信赖的语音和聊天代理，用于客户服务和内部工作流。  
• 效果：企业可直接部署基于 OpenAI 模型的对话代理，具备语音交互、工作流集成和可定制性，降低自建 AI 客服或内部助手的门槛。  
• 使用限制：面向企业客户，需通过 OpenAI 销售渠道接入；预计采用独立产品/包套餐。  
[原文](https://openai.com/index/introducing-openai-presence)

**ChatGPT for Small Business Program**
• 功能介绍：启动 **ChatGPT for small business** 计划，推出 **ChatGPT Work**，帮助创业者构建 AI 技能、自动化工作并实现增长。  
• 效果：小企业可获得定制化的 ChatGPT 工作空间、培训和资源，将日常行政、客服、营销等任务自动化，降低用人成本。  
• 使用限制：针对小企业，具体注册条件和覆盖地区未完全公布；推测为付费订阅方案，可能包含专属 workspace 与工具。  
[原文](https://openai.com/index/introducing-chatgpt-small-business-program)
