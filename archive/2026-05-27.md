🅰️ **Claude 产品更新详解**

**/usage 用量分类明细**
• 功能介绍：**Claude Code v2.1.149** 中 /usage 命令现在显示按类别细分的用量驱动项，包括 skills、subagents、plugins 以及每个 MCP 服务器的费用。
• 效果：用户可以精确定位哪些功能在消耗额度，方便优化 token 预算，排查成本异常，比先前只展示总量更透明。
• 使用限制：Claude Code CLI，适用于 Pro/Max/Team/Enterprise 用户，无需等候名单。平台：macOS / Linux / Windows (WSL)。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**/diff 详情视图键盘滚动**
• 功能介绍：**v2.1.149** 为 /diff 详情视图添加键盘滚动支持，支持方向键、j/k、PgUp/PgDn、空格、Home/End。
• 效果：审查代码差异时完全脱离鼠标，vim 用户操作更流畅，大幅提升 code review 效率。
• 使用限制：同上。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**固定后台会话 (Pinned Background Sessions)**
• 功能介绍：**v2.1.147** 引入固定后台会话：通过 Ctrl+T 标记的会话在空闲时保持存活，并在 Claude Code 更新后会原地重启应用新版本，且仅在非固定会话之后才因内存压力被释放。
• 效果：长时间运行的 agent 任务（如监控、持续集成）不再因更新或空闲而被意外终止，可靠性显著提高。
• 使用限制：Claude Code CLI，支持 Pro/Max/Team/Enterprise。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**/code-review 替代 /simplify**
• 功能介绍：**v2.1.147** 将 /simplify 重命名为 /code-review，并引入努力等级（如 /code-review high）来报告代码正确性缺陷。可通过 --comment 将发现作为内联 GitHub PR 评论提交。旧的「清理并修复」行为已移除。
• 效果：从单纯代码简化转向专业的代码审查，适合在 PR 流程中快速发现 bug 并自动评论，进一步提升团队协作效率。
• 使用限制：同上。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**claude agents --json 与可观测性增强**
• 功能介绍：**v2.1.145** 新增 claude agents --json 命令，以 JSON 格式列出所有活跃会话，同时为 OTEL span 添加了 agent_id 和 parent_agent_id 属性，并修复了后台子 agent span 的追踪嵌套关系。
• 效果：方便编写脚本（如 tmux-resurrect、状态栏集成、会话选择器）管理会话；可观测性提升让 agent 执行链的监控和调试更精准，适合企业生产环境。
• 使用限制：Claude Code Enterprise 使用 OTEL 导出，其余同 CLI。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.145)

**/resume 支持后台会话**
• 功能介绍：**v2.1.144** 扩展 /resume 以支持后台启动的会话（通过 claude --bg 或 agent view），这些会话现在与交互式会话一同列出并标明 bg。
• 效果：后台运行的长时间任务可以随时恢复查看或接管，不必担心丢失会话上下文。
• 使用限制：同上。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.144)

**/model 仅更改当前会话**
• 功能介绍：**v2.1.144** 调整 /model 行为：现在仅影响当前会话，不会改变全局默认。在模型选择器按 d 可设置新会话的默认模型。
• 效果：更细粒度的模型切换控制，避免一次测试性更改污染所有后续会话，适合需要频繁在不同模型间切换以对比效果的场景。
• 使用限制：Claude Code CLI，所有付费档位。[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.144)
