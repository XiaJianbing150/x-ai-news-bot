🅰️ Claude 产品更新详解

**Claude Tag**
• 功能介绍: 为团队协作推出的全新功能 **Claude Tag**,允许团队以标签形式组织和共享与 Claude 的工作内容。
• 效果: 团队可以将对话、文件、项目打标签,提升协作效率和信息检索体验,方便成员快速找到相关上下文。
• 使用限制: Team、Enterprise 档位可用；推测覆盖 Web 端,后续可能扩展至 Claude Code 等平台。
[原文](https://www.anthropic.com/news/introducing-claude-tag)

**Claude Code v2.1.187**
• 功能介绍: 新增沙盒凭证保护设置 `sandbox.credentials`,组织级模型限制显示,以及全屏模式下鼠标点击选择菜单支持。
• 效果: 安全增强 — 可阻止沙盒命令读取凭证文件和密钥环境变量；组织管理员可限制可用模型,用户看到明确提示；全屏模式下操作更便捷。
• 使用限制: Claude Code (CLI) 更新,覆盖所有档位；无额外使用上限。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.187)

**Claude Code v2.1.186**
• 功能介绍: 新增 MCP 服务器 CLI 登录/登出命令 `claude mcp login/logout`；`/workflows` 细节视图支持状态过滤；新增 `teammateMode: "iterm2"` 设置。
• 效果: 无需打开交互菜单即可认证 MCP 服务器,支持 SSH 会话；工作流监控更精细；iTerm2 用户自动模式警告优化。
• 使用限制: Claude Code (CLI) 更新,所有档位可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.186)

**Claude Code v2.1.185**

• 效果: 减少误报,用户在 API 延迟时获得更友好的等待体验。
• 使用限制: Claude Code (CLI) 更新,所有档位。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.185)

**Claude Code v2.1.183**

• 效果: 防止 AI 在自动化会话中意外丢弃本地代码或销毁云资源,降低误操作风险。
• 使用限制: Claude Code (CLI) 更新,所有档位。
