**🅰️ Claude 产品更新详解**

**Claude Sonnet 5.5 上线**
- 功能介绍: **Claude Code v2.1.284** 新增 **claude-sonnet-5-5** 模型,现已成为 Anthropic API 上的默认 Sonnet 模型,支持 1M 上下文。
- 效果: 用户可在 **Claude Code** 中直接使用新一代 Sonnet,处理超长代码库和文档;定价 $2/$10 每 Mtok,缓存读取 $0.20/Mtok,适合大规模代码理解与重构场景。
- 使用限制: 通过 Anthropic API 与 Claude Code 可用;需更新至 v2.1.284 及以上版本。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.284)

**Claude Mods 插件深度行为修改**
- 功能介绍: **Claude Code v2.1.287** 引入 **Claude Mods**,允许插件修改更深层行为;同时内置 **You should know** mod,一个侧边 agent 会观察会话并标记你可能或 Claude 可能遗漏的问题。
- 效果: 开发者可编写更强大的插件来定制 Claude Code 行为;内置 mod 提供实时风险提示,提升复杂任务中的可靠性。
- 使用限制: 通过 `/plugin enable cc-plugin-you-should-know@builtin` 启用,需 first-party 会话且开启 telemetry。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.287)

**Claude Code 桌面应用启动命令**
- 功能介绍: **v2.1.285** 新增 `claude --desktop`,可在当前目录打开 Claude 桌面应用,或配合 `--continue` / `--resume ` 恢复会话。
- 效果: 用户可从终端一键切换到桌面端继续工作,打通 CLI 与桌面应用的工作流。
- 使用限制: Claude Code CLI 环境,需 v2.1.285+。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.285)

**Claude Code 多项小功能更新**
- 功能介绍: 近一周密集发布 v2.1.286–v2.1.290,包括:权限提示堆叠时显示"2 of 5"计数;全屏模式列表鼠标悬停/点击支持;新增 `CLAUDE_CODE_DISABLE_WEB_FETCH` 环境变量关闭 WebFetch;mod 的 turn.step hook 新增 `serverToolUses` 字段;plugin hook 的 tool.check 事件新增 `agentId`;新增 `$.ui.selection()` 供 mods 读取全屏模式选中文本;Ctrl+C 清空提示后按 Up 可恢复草稿;agents view 新增 `n:` 过滤器匹配会话名与任务。
- 效果: 提升权限管理透明度、全屏模式交互体验、mod 开发灵活性与会话恢复能力,面向重度 CLI 用户与插件开发者。
- 使用限制: 均为 Claude Code 版本更新,需升级至对应版本。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.290)
