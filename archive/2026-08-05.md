🅰️ **Claude 产品更新详解**

**Claude Code v2.1.222：工作树隔离与子代理安全修复**
• 功能介绍：修复了 worktree 隔离会话及其子代理能够对主检出执行破坏性 git 命令的问题；修复了 PreToolUse 自动允许钩子在后台代理任务中绕过工具限制的漏洞；修正了 Team/Enterprise 下 /usage-credits 被驳回后仍误报“已发送请求”的 bug。
• 效果：提升代码仓库安全性，防止子代理误操作影响主工作区；确保权限钩子在摘要、压缩、重命名等后台任务中始终生效；改善企业用户的用量额度申请体验。
• 使用限制：Claude Code 所有用户（CLI/VSCode），版本自动更新，无需额外设置。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.222)

**Claude Code v2.1.221：焦点视图与沙箱凭据 mask 模式**
• 功能介绍：VSCode 扩展新增 **Focus view**，通过 Ctrl+Alt+F 或命令切换。开启后隐藏实时工具调用日志，代之以可展开的每轮摘要和“正在运行工具”指示器，减少干扰。在 Linux 和 WSL 上为沙箱凭据文件新增 **mask** 模式——沙箱命令只读取哨兵副本，代理在出口处替换为真实凭据；macOS 上已有 fmediaopen 方案。
• 效果：开发者可专注对话，不被海量工具输出淹没；凭据 mask 显著提升沙箱中敏感信息的安全性。
• 使用限制：Focus view 需 VSCode 扩展；mask 模式在 Linux/WSL 可用。适用于所有 Claude Code 用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)
