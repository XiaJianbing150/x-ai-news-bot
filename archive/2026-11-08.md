**🅾️ OpenAI 产品更新详解**

**GPT‑6 Cyber**
- 功能介绍: OpenAI 推出网络安全专用模型 **GPT‑6 Cyber**,用于发现可利用漏洞并生成修复方案,训练目标限定在授权范围内。
- 效果: 面向防御性安全团队,可在授权环境中自动找漏洞、出补丁;与通用模型相比更强调对齐与范围约束,降低越权风险。
- 使用限制: 面向 approved customers,通过 **Amazon Bedrock** 在 AWS GovCloud (US-East) 提供(见 Daybreak Red 条目);需审批,非公开 API 全量开放。
[原文](https://openai.com/index/introducing-gpt-6-cyber)

**Images 2.6**
- 功能介绍: 推出 **Images 2.6**,图像生成更快,新增 GIF 创建、更精准的编辑能力,并在 API 中增加新的控制参数。
- 效果: 用户可在 **ChatGPT**、**Codex** 和 API 中直接生成动图、做精细局部编辑;相比旧版生成速度提升,适合快速迭代视觉素材。
- 使用限制: 覆盖 ChatGPT、Codex 与 API;具体档位与用量上限未在公告中详述(推测按现有图像生成配额执行)。
[原文](https://openai.com/index/introducing-images-2-6)

**Daybreak Red(基于 GPT-5.6 Cyber)**
- 功能介绍: **Daybreak Red** 将 **GPT-5.6 Cyber** 引入 AWS GovCloud (US-East),通过 Amazon Bedrock 向获批客户开放。
- 效果: 政府与合规要求高的安全团队可在 GovCloud 环境中做授权网络安全工作,满足数据驻留与合规需求。
- 使用限制: 仅限 approved customers;AWS GovCloud (US-East) 区域;需通过 Amazon Bedrock 使用。
[原文](https://openai.com/index/daybreak-red-aws-govcloud)

**🅰️ Claude 产品更新详解**

**Claude Code v2.1.319**
- 功能介绍: 调整 auto mode 在遥测或 feature flags 关闭时的行为,包括 LLM 网关后场景:服务器无法检查的调用会被询问或拒绝,不再回退到内置分类器;设置 **CLAUDE_CODE_AUTO_MODE_SERVER=0** 可继续使用内置分类器(Bedrock、Vertex、Foundry 不受影响)。
- 效果: 企业网关部署下权限判定更可控,避免静默回退导致的安全策略不一致。
- 使用限制: Claude Code CLI;环境变量配置;Bedrock/Vertex/Foundry 用户行为不变。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)

**Claude Code v2.1.318**
- 功能介绍: 新增多项:会话中 Claude Code 请求开启其写入的 mods 时记录用户回答;Claude apps 网关的 mantle upstreams 支持 **assume_role**(跨 AWS 账户角色与按开发者成本归因);mod 的 **$.model.fork** 增加 effort 选项,快速侧任务可低 effort 运行;claude auth status 显示 claude.ai 登录到期日。
- 效果: 企业多账户 AWS 成本分摊更清晰;mod 侧任务可按需降 effort 省 token;登录状态更透明。
- 使用限制: Claude Code CLI;assume_role 与 pooled budget 等面向企业网关部署。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

**Claude Code v2.1.317**
- 功能介绍: /schedule 在新建云端定时任务意外附带 connectors 时给出警告及移除方法;web/shell 工具调用发送账户邮箱到网络前增加询问;Agent SDK hook 回调新增 **onFailure: "block"**,回调失败时阻止动作执行;Claude Desktop 的 Code 标签页在组织远程托管设置未加载时显示提示。
- 效果: 防止定时任务静默带上多余连接器、避免邮箱意外外发、hook 失败不再静默放行。
- 使用限制: Claude Code CLI 与 Claude Desktop;Agent SDK 相关。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)

**Claude Code v2.1.316**
- 功能介绍: 新增 **CLAUDE_CODE_DISABLE_ULTRATHINK** 关闭 ultrathink 关键词;Claude apps 网关支持 pooled group budgets(组成员共享月度预算,叠加个人限额,通过 spend limits admin API 的 pooled_budget 设置);新增 **CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP** 保留互相认证的循环系统交叉证书;新增 **CLAUDE_CODE_SUBAGENT_EFFORT**。
- 效果: 企业可按组管控预算;私有 CA 需要循环证书的服务器不再被误删;子代理 effort 可全局调。
- 使用限制: Claude Code CLI;pooled budgets 面向 Claude apps 网关企业部署。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)

**Claude Code v2.1.314**
- 功能介绍: 新增 **permissions.blockWritesOutsideWorkingDirectories**,Write/Edit/NotebookEdit 在所有权限模式下拒绝工作目录外路径;Claude apps 网关 upstreams 支持可选 groups 列表,仅列出的 IdP 组开发者被路由到该 upstream(含 failover);Bedrock upstreams 增加 **guardrail_trace**,记录触发的 Amazon Bedrock guardrail filter 而不含匹配文本。
- 效果: 防止模型写工作目录外文件;企业可按 IdP 组做网关路由;Bedrock guardrail 审计更安全。
- 使用限制: Claude Code CLI;企业网关与 Bedrock 部署。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)
