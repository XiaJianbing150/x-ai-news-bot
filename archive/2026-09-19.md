**🅰️ Claude 产品更新详解**

**Claude Code v2.1.277 — AGENTS.md 支持**
- 功能介绍: 在没有 CLAUDE.md 的项目中,Claude Code 现在会读取 AGENTS.md 作为项目指令文件;可在 /config 的 "Project instructions" 中切换(尚未支持 Bedrock / Vertex / Foundry)。

- 使用限制: Claude Code CLI;Bedrock / Vertex / Foundry 暂不支持。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)

**Claude Code v2.1.275 — 发送快捷键与网关登录确认**
- 功能介绍: 新增 send-now 快捷键(ctrl+enter 或 ctrl+x ctrl+s),可中断当前回合并一次性发送所有排队消息;排队中的消息以灰色显示。Claude apps gateway 登录时显示已登录账号,确认后才保存凭证,/status 可见。
- 效果: 长对话中可随时打断模型输出、批量提交修正,减少等待;网关登录更透明,避免误用他人凭证。

[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.275)

**Claude Code v2.1.274 — 内存告警与 MCP 启动等待上限**
- 功能介绍: 内存使用达到临界值时显示可见警告并给出释放/重启建议;新增 CLAUDE_CODE_MCP_STARTUP_WAIT_MS 环境变量,限制首个非交互回合等待 MCP server 连接的时间(0 = 不等待);OTel trace 增加 effort 属性。
- 效果: 长会话内存耗尽前提前预警,避免静默崩溃;MCP 启动慢时不再无限阻塞自动化流程。

[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.274)

**Claude Code v2.1.273 — 网关提示头与 MCP 断连通知**
