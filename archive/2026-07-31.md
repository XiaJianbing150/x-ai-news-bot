**Claude Opus 5 正式发布**
• 功能介绍：Anthropic 发布最新旗舰模型 **Claude Opus 5**（API 标识 claude-opus-5），提供 1M token 超长上下文窗口，并支持快速模式（fast mode），定价为输入 $10/Mtokens、输出 $50/Mtokens。该模型从 Claude Code v2.1.219 起成为默认 Opus 模型。
• 效果：在推理、复杂分析、编码等最前沿任务中实现更高智能水平，适合企业级高难度工作；超长上下文可一次处理整本书或大型代码库。
• 使用限制：API 可用；Claude Pro / Max / Enterprise 用户可直接在 Web 或应用端选用（推测）；Claude Code 已内置支持。快速模式可能受并发限制（推测）。
[原文](https://www.anthropic.com/news/claude-opus-5)

**Claude Code v2.1.219 — 新增 sandbox 严格白名单、目录钩子与 MCP 错误报告**
• 功能介绍：Claude Code 新增 sandbox.network.strictAllowlist 设置，可禁止沙盒命令访问未允许的主机而无需提示；新增 DirectoryAdded 钩子，在 /add-dir 或 SDK 注册新工作目录时触发；headless 模式 stream-json 的 init 事件中增加 mcp_server_errors 字段。
• 效果：提升沙盒安全可控性，避免意外网络访问；自动化工作流中可监听目录变化；排查 MCP 服务配置错误更方便。
• 使用限制：Claude Code（v2.1.219+），需在配置中启用相应功能；sandbox 设置仅对沙盒命令生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)

**Claude Code v2.1.218 — 代码审查后台化、屏幕阅读器增强与路径修复**
• 功能介绍：/code-review 命令改为后台子代理（subagent）运行，不占用主对话；在 --ax-screen-reader 模式下新增删除文本的屏幕阅读器播报；修复 Windows 下包含 \u 前缀（形如 C:\Users\unicorn）的路径被错误转为中日韩字符的问题。
• 效果：代码审查异步化后主对话保持清爽，适合频繁 review 的开发者；视障用户能更清晰感知编辑动作；Windows 特殊路径文件可正常操作。
• 使用限制：Claude Code v2.1.218+；后台审查对象为当前堆叠的斜杠命令；屏幕阅读器公告需配合 --ax-screen-reader 标志。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.218)
