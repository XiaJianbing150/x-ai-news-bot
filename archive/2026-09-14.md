**🅰️ Claude 产品更新详解**

**Claude Code v2.1.269:插件评测与输出样式切换**
- 功能介绍: 新增 **claude plugin eval** 命令,可对插件运行评测套件并生成可复现的评分结果(JSON + HTML 报告);新增 **/output-style [name]** 命令,可在 Remote Control、云端及 headless 会话中列出和切换输出样式;当 Bash 工具处理文件编辑时,在工具结果中附带文件变更 diff(设置项 **bashEditDiffEnabled**)。
- 效果: 插件开发者可以像跑测试一样验证插件质量,拿到量化分数;远程或无人值守场景下也能调整 Claude Code 的输出风格;查看 Bash 命令改动了哪些文件不再需要手动 git diff。
- 使用限制: Claude Code CLI,所有档位可用;插件评测与输出样式为本地功能,无用量上限。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.269)

**Claude Code v2.1.268:Claude apps gateway 定价与安全增强**
- 功能介绍: gateway.yaml 中新增 **with pricing** 配置,登录后的 Claude Code 客户端通过托管设置获得与 spend meter 一致的费率;当 **access_control.allow_cidrs** 为空时增加启动警告,首次收到公网地址请求时给出一次性警告;新增 **gatewayInternalNetworks** 托管设置,允许管理员控制 /login 的访问范围。
- 效果: 企业管理员可以让 /cost 和遥测数据与实际账单精确对齐;公网暴露风险在启动阶段即可被发现,减少误配导致的安全事故。
- 使用限制: Claude apps gateway 部署场景,面向 Team / Enterprise 管理员。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.268)

**Claude Code v2.1.267:maxEffortLevel 上限设置**
- 功能介绍: 新增 **maxEffortLevel** 设置(顶层或 modelSettings 下按模型配置),可对包括 Bedrock、Vertex、Foundry 在内的所有 provider 封顶 effort level,用户仍可选择更低档位;新增 **--system-prompt-snapshot off** 参数,每次请求重新渲染系统提示而非复用会话记录中的快照,便于迭代 prompt 文本。
- 效果: 管理员可以防止用户在昂贵模型上烧掉过多推理预算;prompt 工程师调试系统提示时无需重启会话即可看到最新效果。
- 使用限制: Claude Code CLI,Team / Enterprise 管理员可全局强制;Bedrock / Vertex / Foundry 均支持。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.267)

**Claude Code v2.1.266:LLM-gateway 回归修复**
- 功能介绍: 修复 2.1.265 引入的回归——此前被忽略的 **CLAUDE_CODE_USE_GATEWAY** 环境变量在 2.1.265 中开始独立强制 Cloud-gateway 登录,导致同时配置了 API key、apiKeyHelper 或自定义 auth header 的 LLM-gateway / 代理用户所有请求报 "Not signed in to the Cloud gateway"。
- 效果: 使用自建网关或代理的团队恢复正常请求,不再被误判为未登录。
- 使用限制: Claude Code CLI,影响 LLM-gateway 和 proxy 配置用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.266)

**Claude Code v2.1.265:插件目录与遥测增强**
- 功能介绍: **--plugin-dir** 现支持指向包含多个插件的文件夹,每个含 manifest 的子文件夹自动加载,运行中增删子文件夹会被实时感知;遥测中新增 **user.email** 和 **user.groups**,与终端会话对齐;工具结果落盘增加 1 GB 上限,对话预览会提示文件被截断。
- 效果: 插件开发者可以批量管理多个插件而无需逐个指定路径;企业管理员在网关侧能看到更完整的用户身份信息;超大工具输出不再撑爆磁盘。
- 使用限制: Claude Code CLI 与 Claude Desktop / Cowork 通过网关的遥测场景。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.265)

**Claude Code v2.1.270 / v2.1.263**
