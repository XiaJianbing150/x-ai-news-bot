🅰️ **Claude 产品更新详解**

**/usage 分类细目**
• 功能介绍：**Claude Code** 的 /usage 命令现在按技能（skills）、子代理（subagents）、插件（plugins）、以及每个 MCP 服务器的用量分别展示消耗明细，代替过去笼统的数字。
• 效果：开发者可以一眼定位哪些 MCP 工具或子代理在大量消耗 token 限额，方便做性能优化和用量控制。在复杂项目里尤其有用。
• 使用限制：Claude Code v2.1.149，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**/diff 键盘滚动**
• 功能介绍：**Claude Code** 的 /diff 详情视图现在支持键盘滚动，包括方向键、j/k、PgUp/PgDn、Space、Home/End。
• 效果：在审查长 diff 时不再依赖鼠标，操作更流畅，贴近 Vim 用户的习惯。
• 使用限制：Claude Code v2.1.149，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.149)

**固定后台会话（Pinned background sessions）**
• 功能介绍：通过 Ctrl+T 在 **claude agents** 中创建的会话现在被固定（pinned），空闲时不会被回收，更新 Claude Code 后会原地重启。只有在内存真正紧张时，固定会话才会排在非固定会话之后被关闭。
• 效果：长时间运行的后台代理任务（例如监控、持续集成）不会因暂时无交互而丢失，大幅提升了后台工作的可靠性。
• 使用限制：Claude Code v2.1.147，所有用户。需要在 claude agents 中用 Ctrl+T 标记固定。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**/code-review（原 /simplify）**
• 功能介绍：**Claude Code** 将 /simplify 重命名为 /code-review，现在专注于报告代码中的正确性错误，支持通过 /code-review high 调整审查强度，并可通过 --comment 将发现的问题作为内联评论提交到 GitHub PR。原来的清理/修复行为已移除。
• 效果：从“简化代码”转向更聚焦的“正确性审查”，适合在合并前做自动化安全检查，且能直接集成进 GitHub 工作流。
• 使用限制：Claude Code v2.1.147，所有用户可用。需要 GitHub 集成方可使用 PR 评论功能。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.147)

**/model 会话级更改与默认模型设置**
• 功能介绍：**Claude Code** 的 /model 现在只影响当前会话；在模型选择器中按 d 键可为新对话设置默认模型。以前 /model 可能直接更改全局默认。
• 效果：避免了临时切换模型后忘记改回而污染后续会话的情况，同时可灵活设置个人偏好默认值。
• 使用限制：Claude Code v2.1.144，所有用户可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.144)

**claude agents --json 与 OTEL 改进**
• 功能介绍：新增 claude agents --json 命令，以 JSON 格式列出当前存活的 Claude 会话，方便脚本处理（如 tmux-resurrect、状态栏、会话选择器）。同时 OpenTelemetry 的 span 中增加了 agent_id 和 parent_agent_id，并修复了后台子代理 span 的父子嵌套关系。
• 效果：让高级用户和平台工程师可以更精细地编写自动化脚本，追踪多代理系统的调用链，便于监控和调试。
• 使用限制：Claude Code v2.1.145，所有用户。OTEL 需要自行配置采集端。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.145)
