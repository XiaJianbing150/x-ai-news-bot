**🅰️ Claude 产品更新详解**

**Claude Tag：团队协作新方式**
• 功能介绍：**Claude Tag** 是一种全新团队协作功能，用户可给对话片段打标签，快速组织、分类并跨项目复用知识，无需离开 Claude 界面。
• 效果：团队成员可按标签检索历史决策、代码思路、会议摘要等，减少重复沟通；相较于传统文件夹/搜索，标签体系更灵活，能动态重塑信息流。

[原文](https://www.anthropic.com/news/introducing-claude-tag)

• 效果：用户执行 /clear 误清对话后能立即回退，避免丢失代码上下文；滚动位置保持稳定，查看早前输出体验改善；停止 agent 操作现在彻底生效。
• 使用限制：Claude Code CLI 用户，通过 claude update 获取；无额外限制。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.191)

**Claude Code v2.1.187：沙箱凭证隔离与模型限制提示**

**🧰 Claude / GPT 实战玩法**

**Codex 长程工作法（Codex-maxxing）**
Jason Liu 分享了利用 **Codex** 在极长任务中保持上下文的技巧：通过将大项目拆解为具有明确上下文标识的子任务，在每个子任务开头注入“记忆锚点”，并阶段性要求模型总结当前状态，可使 Codex 持续跨多轮提示推进复杂项目而不丢失上下文。该方法已在超过 200 轮交互的自动化流程中验证有效。
[原文](https://openai.com/index/codex-maxxing-long-running-work)
