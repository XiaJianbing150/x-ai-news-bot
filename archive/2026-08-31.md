- **Claude Code v2.1.251 · 模型切换 Hook 与消费可见性**
- 功能介绍: 新增 PreModelSwitch/PostModelSwitch hook 事件，可阻止、确认或注释模型切换；SessionStart resume hook 现在会收到会话陈旧度和预计重缓存成本；Remote Control 客户端可实时流式查看前台子代理的工具调用与结果；/usage 新增 Spend limit 进度条，并提供 rate_limits.spend_limit 状态字段。
- 效果: 开发者能更精细控制模型切换带来的成本与行为，远程观察前台子代理执行细节，实时感知消费是否逼近上限。
- 使用限制: Claude Code CLI；适用于 Pro/Max/Team/Enterprise 及 API 用量环境（推测），具体限额按账号权限。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.251)

- **Claude Code v2.1.248 · 受限模式与缓存 TTL**
- 功能介绍: 新增 --restricted / CLAUDE_CODE_RESTRICTED=1：移除运行命令或代码的内置工具和 WebFetch（除非在 --tools 中指定），文件工具仅限工作目录，拒绝 bypassPermissions，并忽略用户、项目、本地设置文件；新增 agent frontmatter 的 experimental.cacheTtl（"5m"/"1h"），用于每个代理的 prompt cache TTL；新增 claude self-hosted-runner --client-label。
- 效果: 在受限环境中安全运行 Claude Code；可微调单个 agent 的缓存时长以优化成本/性能；自托管 runner 便于标识客户端。
- 使用限制: Claude Code CLI；受限模式适合组织管控场景；cacheTtl 为实验性。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.248)

- **Claude Code v2.1.247 · SendFeedback 工具与提示轮换**
- 功能介绍: 新增 SendFeedback 工具：会话出错时 Claude 可草拟反馈报告，供你审阅后在 /feedback 发送（可用 feedbackDrafts 关闭）；spinnerTipsOverride 支持 {id, text, cooldownSessions, priority}、tipsFile 和 label，组织可与企业内置提示一起轮换自定义 tips；Bash 权限提示新增指向 auto mode 的一键提示。
- 效果: 故障反馈流程更顺；组织可定制加载提示；用户在 Bash 授权提示中可快速切换到 auto mode 减少打断。
- 使用限制: Claude Code CLI；组织定制提示适合 Team/Enterprise；SendFeedback 默认开启。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.247)

- **Claude Code v2.1.246 · Bash 通配符警告与 Auto mode 规则页**
- 功能介绍: 对子命令前含通配符的 Bash allow 规则（如 Bash(git * main)）新增启动警告；/permissions 新增 Auto mode 标签页，可查看/编辑自动模式分类器规则；回合完成时间显示在 duration 行末尾；修复全屏模式在调整终端尺寸并跳到底部后空白 transcript 的问题。
- 效果: 避免宽泛 allow 规则误匹配选项；更方便管理 auto mode 权限；回合耗时可见；全屏体验修复。
- 使用限制: Claude Code CLI；Auto mode 标签页与权限管理相关。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.246)
