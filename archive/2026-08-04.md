🅰️ **Claude 产品更新详解**

**Focus view（专注视图）**
• 功能介绍：**Claude Code v2.1.221** 在 VSCode 中新增专注视图，将工具活动隐藏到可展开的每轮摘要后方，并显示实时的“工具运行中”指示器，可通过 **Ctrl+Alt+F** 或命令面板切换。

**Mask 模式（沙箱凭证文件屏蔽）**
• 功能介绍：新增 **mask** 模式，用于在 Linux 和 WSL 上安全处理凭证文件；沙箱化的命令读取一份哨兵副本（可截取整文件或通过正则提取部分片段），沙箱代理在出站时自动替换为真实凭证值；macOS 支持部分功能。
• 效果：防止 API 密钥、数据库密码等敏感凭证意外泄露到沙箱日志或命令输出中，提升沙箱执行的安全性，适用于需要调用外部服务但不愿暴露真实凭证的测试/部署场景。
• 使用限制：仅 **Claude Code**，平台 Linux / WSL（macOS 部分支持），沙箱模式生效。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)
