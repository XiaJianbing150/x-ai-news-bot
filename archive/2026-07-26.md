🅰️ **Claude 产品更新详解**

**Claude Opus 5 模型发布**
• 功能介绍：Anthropic 推出最新旗舰模型 **Claude Opus 5**，推理与复杂问题解决能力大幅提升，支持 100 万 token 上下文窗口，快速模式定价为输入 $10/Mtokens、输出 $50/Mtokens。
• 效果：用户可以在需要最深层次推理、超长文档分析、复杂代码生成等场景中获得前所未有的模型能力，在 **Claude Code** 中已作为默认 Opus 模型直接调用。
• 使用限制：可通过 Anthropic API（付费）或 **Claude Code** 使用；推测 **Claude Max** 订阅用户可在 web / 移动端体验。快速模式提供较低延迟，定价如上述。
[原文](https://www.anthropic.com/news/claude-opus-5)

**Anthropic Economic Index Connector**
• 功能介绍：新增经济指数连接器，用户可通过 Claude 用自然语言提问 Anthropic Economic Index 数据，直接获取指数数值与分析。
• 效果：研究人员、政策分析者无需离开对话即可查询经济指数，提升数据可访问性与分析效率。
• 使用限制：推测通过 **Claude API** 或 **Claude.ai** 中启用该连接器，可能需要特定权限或账号级别。
[原文](https://www.anthropic.com/news/anthropic-economic-index-connector)

**Claude Code v2.1.219**
• 功能介绍：此次更新在 **Claude Code** 中正式加入 **Claude Opus 5** 模型并设为默认；新增 **sandbox.network.strictAllowlist** 设置，可拒绝沙盒命令对非白名单主机的网络访问且不提示；添加 **DirectoryAdded** 钩子，当 /add-dir 或 SDK 注册新工作目录时触发；headless 模式的 stream-json 初始化事件中纳入 **mcp_server_errors** 字段，便于排查 MCP 配置错误。
• 效果：开发者可在最高性能模型下工作，同时获得更精细的沙盒网络控制和更好的工具链集成。
• 使用限制：需更新至 **Claude Code v2.1.219+**，任何已验证的 API 密钥或订阅均可使用新增功能。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)

**Claude Code v2.1.218**
• 功能介绍：**/code-review** 改为后台子代理执行，不再占用会话上下文；支持将堆叠的斜杠命令作为审查目标；**–ax-screen-reader** 模式下可播报单词和行的删除（Option+Delete, Ctrl+W 等）；修复了 Windows 路径中包含 Unicode 前缀被错误转码的问题。
• 效果：代码审查更流畅，屏幕阅读器用户获得更好的无障碍体验，Windows 路径处理更稳定。
• 使用限制：更新至最新版本后自动生效，适用于所有 **Claude Code** 支持的平台。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.218)

**Claude Code v2.1.217**

• 效果：提升交互友好性和可靠性，长时间会话更稳定。

**Claude Code v2.1.216**

**Health in ChatGPT**
• 功能介绍：美国符合条件的用户现在可以安全连接自己的医疗记录和 **Apple Health** 数据，在 **ChatGPT** 中获得个性化的健康洞察与解读。
• 效果：用户可借助 ChatGPT 更好地理解个人健康指标与趋势，相当于获得一个 AI 健康顾问，但仍需遵循医疗专业建议。

• 效果：企业可以快速构建符合自身品牌与合规要求的对话式 AI，降低部署成本，提高自动化水平。
• 使用限制：面向企业市场，需联系 OpenAI 获取接入；推测按席位或使用量计费，支持私有化部署或云。
[原文](https://openai.com/index/introducing-openai-presence)
