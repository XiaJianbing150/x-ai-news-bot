🅰️ **Claude 产品更新详解**

**Claude Code v2.1.139 – Agent view、/goal 命令与 /scroll-speed**
• 功能介绍：新增 **agent view (研究预览)**，将所有本机会话（运行中、等待输入、已完成）聚合为一个列表，支持 **/goal** 命令设定完成条件，Claude 会跨轮次持续工作直到目标达成；新增 **/scroll-speed** 调整鼠标滚轮滚动速度。
• 效果：开发者可从单一视图管理多个后台或前台 coding 会话；/goal 让长时间自动化任务无需反复确认，适合批量重构、测试修复等长链路。Agent view 补齐了多会话编排缺口，类似 Codex CLI 的任务监控能力。
• 使用限制：Claude Code（Research Preview），Pro / Max / Team / Enterprise 用户均可用；agent view 通过 claude agents 启动。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.139)

**Claude Code v2.1.142 – Fast mode 默认升级 Opus 4.7**
• 功能介绍：Fast mode 现在默认使用 **Opus 4.7**（此前为 Opus 4.6），可通过 CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1 强制回退。同步新增 **claude agents** 启动参数（--model, --effort, --permission-mode 等），灵活配置后台 session。
• 效果：默认更智能的模型能处理复杂代码生成与多步推理，同时保留快速响应。开发者可按场景分配不同模型给后台 agent，降低 token 成本。
• 使用限制：Claude Code，所有付费档均可用；Fast mode 在 API 和 Claude Code 中均提供研究预览。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.142)

**Claude Code v2.1.143 – 插件依赖强制与上下文成本预估**
• 功能介绍：**插件依赖强制执行**：claude plugin disable 若被其他已启用插件依赖时会拒绝，并给出可复制的一行 disable-chain 提示；claude plugin enable 会自动启用传递依赖。插件市场浏览窗新增 **projected context cost（每轮/每次调用 token 估算）**。
• 效果：避免意外破坏插件运行环境；开发者安装插件前可直观评估 token 开销，控制成本。
• 使用限制：Claude Code v2.1.143，所有用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.143)

**Claude Code v2.1.141 – Hook 桌面通知与 HTTPS 克隆**
• 功能介绍：Hook JSON 输出新增 terminalSequence 字段，支持发出桌面通知、窗口标题和铃声。新增 CLAUDE_CODE_PLUGIN_PREFER_HTTPS 用 HTTPS 克隆插件仓库（无需 SSH 密钥）。新增 ANTHROPIC_WORKSPACE_ID 用于 workload identity federation。
• 效果：开发者在后台任务完成/报错时能获得桌面级提示，避免频繁切换终端。HTTPS 克隆解决某些环境没有 GitHub SSH key 的问题。
• 使用限制：Claude Code v2.1.141。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.141)

🅾️ **OpenAI 产品更新详解**

**ChatGPT 个人财务体验（预览）**
• 功能介绍：面向美国 Pro 用户，新增 **个人财务洞察**，可安全连接金融账户，自动分析收支，并基于财务上下文回答问题。
• 效果：用户在同一个聊天界面就能掌握资金流向、制定预算，相当于内置轻量财务助手；隐私控制由用户选择连接哪些账户。
• 使用限制：ChatGPT Pro，仅限美国，预览阶段。
[原文](https://openai.com/index/personal-finance-chatgpt)

**Codex 入驻 ChatGPT 移动应用**
• 功能介绍：**Codex 从手机直接使用**，可在 ChatGPT App 中发起、监控、批准编码任务，实时跨设备。
• 效果：开发者用手机就能启动远程开发环境的工作，审核变更，打破必须坐在电脑前的限制；配合后台 Mac mini/服务器可组成“主机-卫星设备”工作流。
• 使用限制：ChatGPT App（iOS/Android），需 Codex 权限，当前随 Pro/Team/Enterprise 账号提供。
[原文](https://openai.com/index/work-with-codex-from-anywhere)

**Codex Hooks – 自定义任务自动化**
• 功能介绍：**Hooks** 允许在 Codex 任务关键节点插入自定义脚本，可用于运行验证器、扫描 prompt 密钥、日志记录、创建记忆等。
• 效果：团队可将代码审查、安全扫描等流程嵌入 Codex 循环，实现内部规范自动执行，提升工程可靠性。
• 使用限制：Codex CLI / API，需通过 hook 配置文件启用。
[原文](https://x.com/sama/status/2055034714231345475)

**Codex 支持 Windows 安全沙箱**
• 功能介绍：OpenAI 构建了 **Windows 沙箱**，使 Codex 能在受限环境内安全运行编码任务，控制文件访问和网络。
• 效果：Windows 用户无需担心 agent 误操作系统关键文件，企业环境也可合规使用。
• 使用限制：需 Codex 应用最新版，Windows 系统。
[原文](https://openai.com/index/building-codex-windows-sandbox)

**ChatGPT 敏感性对话上下文识别**
• 功能介绍：安全更新使 ChatGPT 能**更好地识别长时间对话中的风险上下文**，动态调整回复策略。
• 效果：在涉及自我伤害、暴力等敏感话题时，模型能更早感知并触发安全干预，提升对话安全性。
• 使用限制：ChatGPT 所有用户，后台模型安全层生效。
[原文](https://openai.com/index/chatgpt-recognize-context-in-sensitive-conversations)
