🅰️ **Claude 产品更新详解**

**Agent View（研究预览）**
• 功能介绍：Claude Code v2.1.139 新增 agent view，一个统一面板，列出所有会话——运行中、等待你操作或已完成。运行 claude agents 即可打开。
• 效果：在一个视图中同时监控多个 Claude Code 任务，不再需要在终端间频繁切换，适合持续集成和长时间运行的后台工作。
• 使用限制：Claude Code Pro / Max / Team / Enterprise，终端及 VS Code / JetBrains 插件均可使用。当前标注为研究预览。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.139)

**/goal 自动完成目标**
• 功能介绍：同样在 v2.1.139 中推出 /goal 命令，可设置一个完成条件，Claude 会跨多轮自动持续工作，直到目标达成。在交互模式、-p 模式和远程控制中均可用，并会显示实时的耗时/轮次/令牌数面板。
• 效果：用户可以一次性描述最终目标，Claude Code 不再问“还需要我做什么吗”，而是自行判断是否完成，减少人工来回确认，提升自动化开发流程的连贯性。
• 使用限制：Claude Code 所有付费计划，包括交互式终端会话及 Agent SDK 的 -p 模式。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.139)

**/scroll-speed 滚动速度调节**
• 功能介绍：v2.1.139 新增 /scroll-speed 命令，可调整鼠标滚轮在终端中的滚动速度。
• 效果：解决在长输出结果中滚动过快或过慢的问题，让开发者根据自己的习惯精细控制输出浏览体验。
• 使用限制：Claude Code 所有支持的终端，无计划限制。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.139)

**Hook 终端序列通知**
• 功能介绍：v2.1.141 在 Hook 的 JSON 输出中新增 terminalSequence 字段，允许 Hook 脚本发出桌面通知、修改窗口标题或终端响铃，无需依赖控制终端。
• 效果：在长时间运行的 Agent 任务中，开发者可以收到“任务完成”或“需要干预”的桌面弹出通知，而不是一直盯着终端。
• 使用限制：Claude Code 所有支持 Hook 的环境（Pro / Max / Team / Enterprise）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.141)

**Claude Agent SDK 插件 HTTPS 克隆支持**
• 功能介绍：v2.1.141 新增 CLAUDE_CODE_PLUGIN_PREFER_HTTPS 环境变量，在没有 GitHub SSH 密钥的环境中，可通过 HTTPS 克隆插件仓库。
• 效果：简化在 CI/CD 环境或受限开发环境中安装和管理插件的过程。
• 使用限制：所有 Claude Code 及 Agent SDK 使用环境。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.141)

**后台 Agent 调度标志 & Fast Mode 模型升级**
• 功能介绍：v2.1.142 新增一系列 claude agents 标志（--add-dir、--settings 等），允许精细配置派发的后台会话；同时 Fast Mode 默认模型从 Opus 4.6 升级为 Opus 4.7，可通过环境变量固定回 Opus 4.6。
• 效果：开发者可以更灵活地启动后台 Agent 并控制权限、目录和设置；Opus 4.7 在编码推理上更强，Fast Mode 速度基本不变。
• 使用限制：Claude Code Pro / Max / Team / Enterprise，Fast Mode 对 Opus 4.7 的研究预览已在 API 和 Claude Code 中可用。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.142)

**插件依赖管理与上下文成本预估**
• 功能介绍：v2.1.143 实施插件依赖强制检查：claude plugin disable 会在其他插件依赖时拒绝操作，并给出完整的禁用链提示；同时 /plugin marketplace 浏览面板中新增每轮和每次调用的上下文 token 预估。

🧰 **Claude / GPT 实战玩法**

**让 LLM 直接输出 HTML 实现可视化**
Andrej Karpathy 分享技巧：在提问末尾加一句 “structure your response as HTML”，然后将生成的 HTML 保存为文件并在浏览器中打开，可获得带有格式、列表甚至图表的回答。他进一步成功让模型输出幻灯片式的 HTML。Karpathy 认为音频是更适合人类的输入模态，而视觉（图像/动画/视频）才是 AI 首选输出——大脑有三分之一是并行处理的视觉皮层，应当被充分利用。这个技巧适用于 Claude 和 ChatGPT。
[原文](https://x.com/karpathy/status/2053872850101285137)
