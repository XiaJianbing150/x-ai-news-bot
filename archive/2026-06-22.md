**📰 Anthropic & OpenAI 速报 · 2026-06-22 Monday**

**🅰️ Claude 产品更新详解**

**流停滞提示优化 (v2.1.185)**
• 功能介绍：API 流式响应超时的提示信息从“No response from API · Retrying in …”改为“Waiting for API response · will retry in …”，静默触发时间从 10 秒延长至 20 秒。
• 效果：降低用户在等待时对“无响应”的困惑，更准确地传达系统正在重试的状态。
• 使用限制：所有使用 Claude Code 的用户；CLI 环境（macOS / Linux / Windows）。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.185)

**自动模式安全防护增强 (v2.1.183)**
• 功能介绍：在自动模式下，**Claude Code** 会主动拦截可能对本地工作造成破坏的命令，包括：git reset --hard / git checkout -- . / git clean -fd / git stash drop（除非用户明确要求丢弃工作），git commit --amend（除非 commit 由当前会话的 agent 创建），以及 terraform destroy / pulumi destroy / cdk destroy（除非用户指定了具体的栈）。同时，当请求使用的模型已被弃用或自动更新时，会给出明确警告。
• 效果：防止自动化流程意外破坏本地工作产物或基础设施；提示用户注意模型版本变化，避免能力与预期的偏差。
• 使用限制：Claude Code 自动模式；适用所有用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.183)

**/config 快捷语法与沙箱 Apple Events 支持 (v2.1.181)**
• 功能介绍：新增 **/config key=value** 语法，可从提示符直接修改任意设置（例如 /config thinking=false），适用于交互模式、-p 模式及远程控制。新增 **sandbox.allowAppleEvents** 开关（需主动启用），允许沙盒内命令在 macOS 上发送 Apple Events。新增 **CLAUDE_CLIENT_PRESENCE_FILE** 环境变量，指向标记文件后可抑制移动端推送通知（用于本机操作时免打扰）。内置 Bun 运行时升级至 1.4，并改进了长消息的流式输出。
• 效果：快速切换思考模式；在 macOS 下解锁更丰富的自动化能力；减少手机端无关通知；提升长响应场景下的流畅度。
• 使用限制：Claude Code 所有用户；sandbox.allowAppleEvents 需 macOS 并显式启用；环境变量配置建议用于开发者。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.181)

**连接中断修复与多平台细节修正 (v2.1.179)**
• 功能介绍：修复流式连接中断时部分响应丢失和 spinner 卡住的问题，现在部分已完成内容会被保留而不会显示原始错误。修复 WSL2 下在 Windows Terminal 和 VS Code 中的鼠标滚轮滚动（v2.1.172 回归问题）。修复沙箱 denyRead/allowRead glob 在大型目录树时导致 Bash 工具描述过大、会话不可用的问题。修复反馈调查中单数字回复被误捕获的问题。
• 效果：网络抖动时保持可用性；WSL2 用户重新获得完整滚动体验；大型项目沙箱规则不再使会话崩溃。
• 使用限制：Claude Code 所有用户。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.179)

**权限规则参数匹配与嵌套技能/目录支持 (v2.1.178)**
• 功能介绍：权限规则新增 **Tool(param:value)** 语法，可匹配工具输入参数（支持 * 通配符），例如 **Agent(model:opus)** 可阻止创建 Opus 子代理。支持嵌套的 **.claude/skills** 目录，同名时显示为 <dir>:<name> 以区分。对于嵌套的 **.claude/** 目录，agent、workflow 和 output-style 以最接近当前工作目录的为准，项目级设置会合并。
• 效果：精细控制子代理模型使用，限制成本；多层级项目组织时可灵活划分技能与配置，避免命名冲突。
• 使用限制：Claude Code；权限规则需在配置文件中编写。
[原文](https://github.com/anthropics/claude-code/releases/tag/v2.1.178)
